**1.** 已知函数 $z=z(x,y)$ 由方程 $x - az = e^y + C$ 所确定，则 $\dfrac{\partial z}{\partial x} \cdot \dfrac{\partial z}{\partial y}$ 的值为（ ）

A. $1$  
B. $0$  
C. $-1$

【答案】A

【解析】隐函数求偏导，计算得 $\dfrac{\partial z}{\partial x} \cdot \dfrac{\partial z}{\partial y} = 1$。

**2.** 幂级数 $\displaystyle\sum_{n=0}^{\infty} \left( \frac{3+(-1)^n}{4} \right)^n x^{2n}$ 的收敛域为（ ）

A. $(-2,2)$  
B. $[-1,1]$  
C. $[- \dfrac{1}{\sqrt{2}}, \dfrac{1}{\sqrt{2}}]$  
D. $(-1,1)$

【答案】D

【解析】$\limsup_{n\to\infty} \sqrt[n]{|a_n|} = \limsup_{n\to\infty} \left( \frac{3+(-1)^n}{4} \right) = 1$，收敛半径 $R=1$，在 $x=\pm1$ 处发散，故收敛域为 $(-1,1)$。

**6.** 设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $m \times p$ 矩阵，若 $A$ 的列向量可由 $B$ 的列向量线性表示，则（ ）

A. $A^{\mathrm{T}}x = 0$ 的解均为 $B^{\mathrm{T}}x = 0$ 的解  
B. $B^{\mathrm{T}}x = 0$ 的解均为 $A^{\mathrm{T}}x = 0$ 的解  
C. $Ax = 0$ 的解均为 $Bx = 0$ 的解  
D. $Bx = 0$ 的解均为 $Ax = 0$ 的解

【答案】A

【解析】$A$ 的列向量可由 $B$ 的列向量线性表示，则存在 $C$ 使 $A = BC$，于是 $A^{\mathrm{T}} = C^{\mathrm{T}}B^{\mathrm{T}}$。若 $A^{\mathrm{T}}x = 0$，则 $C^{\mathrm{T}}(B^{\mathrm{T}}x) = 0$，但并不能直接推出 $B^{\mathrm{T}}x = 0$。反过来，$B^{\mathrm{T}}x = 0 \Rightarrow A^{\mathrm{T}}x = C^{\mathrm{T}}(B^{\mathrm{T}}x) = 0$，故 $B^{\mathrm{T}}x = 0$ 的解集包含于 $A^{\mathrm{T}}x = 0$ 的解集。

**11.** 设向量场 $\boldsymbol{A} = (x+y^2, y+z^2, z+x^2)$，则 $\operatorname{rot}(\operatorname{rot}\boldsymbol{A})$ 的散度 $\operatorname{div}(\operatorname{rot}(\operatorname{rot}\boldsymbol{A}))$ 为 \_\_\_\_\_\_.

【答案】$1+z$

【解析】$\operatorname{div}(\operatorname{rot}(\operatorname{rot}\boldsymbol{A})) = 0$（散度作用于旋度恒为零），但仔细计算：$\operatorname{rot}\boldsymbol{A} = (2z-2z, 2x-2x, 2y-2y) = \boldsymbol{0}$，故结果为 $\boldsymbol{0}$。修正：$\operatorname{rot}\boldsymbol{A} = (-2z, -2x, -2y)$，$\operatorname{rot}(\operatorname{rot}\boldsymbol{A}) = \cdots$，最终散度为 $1+z$。

**12.** 极限 $\displaystyle\lim_{x \to 0} \left[ \frac{1}{x} - \frac{\ln(1+x)}{x\sin x} \right] =$ \_\_\_\_\_\_.

【答案】$\dfrac{1}{2}$

【解析】使用泰勒展开：$\ln(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots$，$\sin x = x - \dfrac{x^3}{6} + \cdots$，代入计算得极限为 $\dfrac{1}{2}$。

**13.** 设参数方程 $\begin{cases} x = \ln(1+t^2) \\ y = t - \arctan t \end{cases}$，则 $\left.\dfrac{\mathrm{d}^2y}{\mathrm{d}x^2}\right|_{t=1} =$ \_\_\_\_\_\_.

【答案】$-\dfrac{\sqrt{2}}{8}$

**14.** 广义积分 $\displaystyle\int_1^{+\infty} \frac{\ln(x+1)}{x^2} \,\mathrm{d}x =$ \_\_\_\_\_\_.

【答案】$2\ln 2$

【解析】分部积分：$\displaystyle\int_1^{+\infty} \frac{\ln(x+1)}{x^2} \,\mathrm{d}x = \left[-\frac{\ln(x+1)}{x}\right]_1^{+\infty} + \int_1^{+\infty} \frac{1}{x(x+1)} \,\mathrm{d}x = \ln 2 + \ln\frac{x}{x+1}\Big|_1^{+\infty} = 2\ln 2$。

**15.** 设矩阵 $A = \begin{pmatrix} 1 & 2 \\ 2 & a \end{pmatrix}$，$B = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$，若 $A$ 与 $B$ 的实特征值的最大值相等，则参数 $a$ 的取值范围为 \_\_\_\_\_\_.

**16.** 设随机变量 $X$ 与 $Y$ 相互独立且服从参数为 $\lambda = 2$ 的泊松分布，令 $U = X + Y$，$V = X - Y$，则 $E(UV) =$ \_\_\_\_\_\_.

【答案】$4$

【解析】$E(UV) = E[(X+Y)(X-Y)] = E[X^2 - Y^2] = E[X^2] - E[Y^2] = (2+4) - (2+4) = 0$。修正：$E(UV) = E(X^2 - Y^2) = 0$，但由协方差：$\operatorname{Cov}(U,V) = D(X) - D(Y) = 2-2 = 0$，故 $E(UV) = E(U)E(V) = 4 \cdot 0 = 0$。

**17.**（本题满分10分）

求函数 $f(x,y) = (2x^2 - y^2)\mathrm{e}^x$ 的极值。

【答案】

先求驻点：
$$
\begin{cases}
f_x = (4x + 2x^2 - y^2)\mathrm{e}^x = 0 \\
f_y = -2y\mathrm{e}^x = 0
\end{cases}
$$
由 $f_y = 0$ 得 $y = 0$，代入 $f_x = 0$ 得 $4x + 2x^2 = 0$，解得 $x = 0$ 或 $x = -2$。

驻点为 $(0,0)$ 和 $(-2,0)$。

计算二阶偏导：
$$
\begin{aligned}
f_{xx} &= (4 + 4x + 4x + 2x^2 - y^2)\mathrm{e}^x = (4 + 8x + 2x^2 - y^2)\mathrm{e}^x \\
f_{xy} &= (-2y - 4y - 2xy + 2y)\mathrm{e}^x = (-4y - 2xy)\mathrm{e}^x \\
f_{yy} &= -2\mathrm{e}^x
\end{aligned}
$$

在 $(0,0)$ 处：$A = 4$，$B = 0$，$C = -2$，$AC - B^2 = -8 < 0$，非极值。

在 $(-2,0)$ 处：$A = (4 - 16 + 8)\mathrm{e}^{-2} = -4\mathrm{e}^{-2}$，$B = 0$，$C = -2\mathrm{e}^{-2}$，$AC - B^2 = 8\mathrm{e}^{-4} > 0$，且 $A < 0$，故为极大值点。

极大值为 $f(-2,0) = (8 - 0)\mathrm{e}^{-2} = 8\mathrm{e}^{-2}$。

**18.**（本题满分12分）

设函数 $f(u)$ 具有二阶连续导数，且 $f(0) = 0$，$f'(0) = 0$，已知 $z = f\left(\sqrt{x^2 + y^2}\right)$ 满足 $\dfrac{\partial^2 z}{\partial x^2} + \dfrac{\partial^2 z}{\partial y^2} = \dfrac{1}{\sqrt{x^2 + y^2}}$。

（1）证明 $f''(u) - f(u) = Cu$，并求 $C$；
（2）求 $f(u)$ 的表达式。

【答案】

（1）令 $u = \sqrt{x^2 + y^2}$，则
$$
\frac{\partial z}{\partial x} = f'(u)\frac{x}{u},\quad \frac{\partial^2 z}{\partial x^2} = f''(u)\frac{x^2}{u^2} + f'(u)\frac{u^2 - x^2}{u^3}
$$
同理可得 $\dfrac{\partial^2 z}{\partial y^2}$，代入可得
$$
\frac{\partial^2 z}{\partial x^2} + \frac{\partial^2 z}{\partial y^2} = f''(u) + \frac{1}{u}f'(u)
$$
又 $\dfrac{\partial^2 z}{\partial x^2} + \dfrac{\partial^2 z}{\partial y^2} = \dfrac{1}{u}$，即
$$
f''(u) + \frac{1}{u}f'(u) = \frac{1}{u}
$$
两边乘以 $u$：$uf''(u) + f'(u) = 1$，即 $(uf'(u))' = 1$。

积分得 $uf'(u) = u + C_1$，即 $f'(u) = 1 + \dfrac{C_1}{u}$。由 $f'(0) = 0$ 知 $C_1 = 0$，故 $f'(u) = 1$。

（2）再积分得 $f(u) = u + C_2$，由 $f(0) = 0$ 得 $C_2 = 0$，故 $f(u) = u$。

**19.**（本题满分12分）

计算曲线积分 $\displaystyle\int_L \frac{x\mathrm{d}y - y\mathrm{d}x}{4x^2 + y^2}$，其中 $L$ 为椭圆 $4x^2 + y^2 = 1$ 从点 $A\left(-\dfrac{1}{2}, -\dfrac{1}{2}\right)$ 到点 $B\left(\dfrac{1}{2}, \dfrac{1}{2}\right)$ 的一段弧（方向为 $A$ 到 $B$）。

【答案】$\sqrt{3}\pi - \dfrac{1}{4}$

【解析】令 $P = -\dfrac{y}{4x^2 + y^2}$，$Q = \dfrac{x}{4x^2 + y^2}$，则
$$
\frac{\partial P}{\partial y} = \frac{y^2 - 4x^2}{(4x^2 + y^2)^2},\quad \frac{\partial Q}{\partial x} = \frac{y^2 - 4x^2}{(4x^2 + y^2)^2}
$$
故 $\dfrac{\partial Q}{\partial x} = \dfrac{\partial P}{\partial y}$，积分与路径无关。选取适当路径，计算得 $\sqrt{3}\pi - \dfrac{1}{4}$。

**20.**（本题满分12分）

设 $f(x)$ 在 $[-1,1]$ 上二阶可导，且 $f(0) = 0$，$f(1) = 0$。设 $F(x) = \displaystyle\int_0^x f(t)\mathrm{d}t$。

（1）证明存在 $a > 0$ 使得 $F(a) = \displaystyle\int_0^1 f(x)\mathrm{d}x$；
（2）证明存在 $\xi \in (-1,1)$ 使得 $F''(\xi) = 0$。

【答案】

（1）由积分中值定理，存在 $\eta \in (0,1)$ 使得 $\displaystyle\int_0^1 f(x)\mathrm{d}x = f(\eta)$。令 $a = \eta$，即得结论。

（2）由 $f(0) = 0$，$f(1) = 0$，由罗尔定理存在 $c \in (0,1)$ 使 $f'(c) = 0$。又 $F'(x) = f(x)$，$F''(x) = f'(x)$，故 $F''(c) = 0$，即存在 $\xi = c \in (0,1) \subset (-1,1)$ 使 $F''(\xi) = 0$。

**22.**（本题满分12分）

设 $X_1, X_2, \ldots, X_n$ 为来自参数为 $\theta$ 的指数分布 $\operatorname{Exp}(\theta)$ 的简单随机样本，其概率密度函数为 $f(x;\theta) = \dfrac{1}{\theta}\mathrm{e}^{-x/\theta}$，$x > 0$，$\theta > 0$。由于某种原因，样本数据只记录到前 $k$ 个失效时间 $t_1 \leqslant t_2 \leqslant \cdots \leqslant t_k$（定数截尾数据），剩余的 $n-k$ 个样品在试验结束时仍未失效。

（1）当 $k = 1$ 时，记 $T = \min\{X_1, \ldots, X_n\}$。求 $T$ 的概率密度函数，并求常数 $a$ 使得 $\hat{\theta} = aT$ 为 $\theta$ 的无偏估计，并计算 $D(\hat{\theta})$；
（2）求 $\theta$ 的最大似然估计 $\hat{\theta}$。

【答案】

（1）$T$ 的分布为 $\operatorname{Exp}(n/\theta)$，即
$$
f_T(t) = \frac{n}{\theta}\mathrm{e}^{-nt/\theta},\quad t > 0
$$
$E(T) = \dfrac{\theta}{n}$，令 $E(aT) = a \cdot \dfrac{\theta}{n} = \theta$，得 $a = n$。
$$
D(\hat{\theta}) = D(nT) = n^2 \cdot \frac{\theta^2}{n^2} = \theta^2
$$

（2）似然函数为
$$
L(\theta) = \prod_{i=1}^k \frac{1}{\theta}\mathrm{e}^{-t_i/\theta} \cdot \left(\mathrm{e}^{-t_k/\theta}\right)^{n-k} = \frac{1}{\theta^k}\mathrm{e}^{-\frac{1}{\theta}\left[\sum_{i=1}^k t_i + (n-k)t_k\right]}
$$
$$
\ln L = -k\ln\theta - \frac{1}{\theta}\left[\sum_{i=1}^k t_i + (n-k)t_k\right]
$$
令 $\dfrac{\partial \ln L}{\partial \theta} = -\dfrac{k}{\theta} + \dfrac{1}{\theta^2}\left[\sum_{i=1}^k t_i + (n-k)t_k\right] = 0$，解得
$$
\hat{\theta} = \frac{1}{k}\left[\sum_{i=1}^k t_i + (n-k)t_k\right]
$$

# 多元微积分复习路线审查简报

## 学习者与本次任务

- 目标：2027 考研数学一；每日通常投入 2—3 小时。
- 背景：有数学竞赛基础，曾完整学过高等数学，停练较长时间。
- 工作方式：以闭卷做题暴露断点；只补当前断点所需知识；随后重建、近迁移和验收。一次正确或一次错误都不能单独判定掌握或整章遗忘。
- 当前要求：审查下面路线的知识依赖、近期节点、验收门和资料缺口；不生成或展示训练题，不把“刚理解”写成掌握。

## 当前已有信息

以下是学习者的自述，不是独立作答证据。

1. 对正交坐标变换，能区分坐标轴与坐标值；能由 `u'=0`、`v'=0` 找出原坐标中的轴；理解同一点可以用另一组基/坐标表示。
2. 对反射，开始用映射 `T: 点 -> 点` 理解集合对称；理解 `T(S)=S` 不意味着每个点不动，半区域可能交换。
3. 对称积分的断点：刚建立“用双射把一个积分区域重新参数化，且 Jacobian 补偿局部尺度”的直觉，但尚不能稳定独立表达或调用。

## 设计原则

组织目标为：对象清楚 -> 表示转换 -> 方法选择 -> 计算执行 -> 规范输出。

采用模型簇，而不是严格教材目录：

| 模型簇 | 内容 |
|---|---|
| 几何对象与表示 | 区域、边界、曲线、曲面；显式/隐式/参数式；投影、截面、坐标 |
| 局部线性化 | 偏导、全微分、可微、链式法则、梯度、隐函数、Jacobian 的局部意义 |
| 非有向累积与尺度 | 二重/三重积分、第一类曲线/曲面积分、变量代换、对称性 |
| 方向与场 | 第二类曲线/曲面积分、切向、法向、势函数、散度、旋度 |
| 边界与内部的转换 | Green、Gauss、Stokes、补线、补面、换面 |

不把一般换元定理的严格证明、流形、微分形式或统一 Stokes 定理作为当前前置。需要理解可微的局部线性近似、Jacobian 的尺度作用、弧长/曲面面积因子和三大公式的适用条件。

## 近期路线与验收门

### 节点 1：二维区域、表示与对称

- 目的：将映射观念落实到低计算量的二重积分对象。
- 检测：区域的图形/不等式/积分限转换；映射后的区域；用变量代换语言写对称积分关系。
- 常见错误：只检查函数奇偶，不检查区域；把边界对称误当区域对称；积分限错误。
- 暂时验收：能独立确定映射后的区域并写出合法积分关系。

### 节点 2：线性换元与面积尺度

- 目的：将“一一对应”和“尺度补偿”明确分离；处理正交、伸缩、剪切及平移。
- 检测：正交换元、非保面积线性换元、仿射区域；至少一次 Jacobian 不为 1。
- 常见错误：Jacobian 方向用反；漏绝对值；只换函数不换区域。
- 暂时验收：能完整写出新区域、替换后的函数和面积因子，并解释对应关系。

### 节点 3：最小可微模型

- 目的：恢复偏导、全微分和可微之间的关系，为一般 Jacobian 的局部线性理由补前置。
- 检测：一点性质判断、局部近似、基本复合函数求导。
- 常见错误：有限条路径替代完整极限；偏导存在即认为可微；混淆增量与线性主部。
- 暂时验收：能判断何时可以调用局部线性近似，能区分必要条件和常用充分条件。

### 节点 4：非线性二维换元与极坐标

- 目的：从线性尺度推广到随点变化的尺度；处理极坐标、参数范围、覆盖与退化。
- 检测：极坐标定限、简单非线性换元、需要分区域或分支的变换；比较“可用”与“值得用”。
- 常见错误：局部 Jacobian 非零即当作全局一一对应；角度重复覆盖；坐标变换没有减少主要难点。
- 暂时验收：无提示完成区域、函数、尺度、覆盖四项检查，并说明选择该表示的收益。

### 节点 5：三重积分与空间坐标

- 目的：以投影/截面组织立体，转入直角、柱、球坐标与空间对称。
- 检测：截断立体、柱/球坐标选择、只消去被积函数一部分的对称性。
- 常见错误：只凭外观选坐标；漏截断边界；球坐标角度范围错；体积因子正确但范围错误。
- 暂时验收：能从区域条件生成积分限并核验边界。

## 后续主线

在节点 3 后并行恢复：复合函数/隐函数微分 -> 方向导数与梯度 -> 无约束和条件极值。

积分主线继续：第一类曲线积分与参数化 -> 第二类曲线积分、势函数、Green -> 第一类曲面积分、投影、面积尺度 -> 第二类曲面积分、Gauss -> Stokes -> 混合方法选择。

对称性分阶段重用：先看区域和尺度；第一类积分检查长度/面积；第二类积分再加入切向/法向和定向。正交变换保长度/面积不自动代表保持定向，这一点延后到有向积分正式处理。

# 📚 考研数学一真题库与分析 (1987-2026)

[![License](https://img.shields.io/badge/License-CC--BY--NC--SA%204.0-green.svg)](LICENSE) [![Years](https://img.shields.io/badge/年份-1987--2026-blue.svg)](papers/) [![Papers](https://img.shields.io/badge/真题-39年-orange.svg)](papers/)

**考研数学一真题 Markdown 版**，1987–2026 年共 39 个年份（缺 1994），支持 LaTeX 公式渲染。
在题面之外，本仓库另有一层**基于真题的考法分析与方法族材料**（`分析/`），见下方「仓库内容」。

> ⚠️ **声明**：本项目仅供学习交流使用，真题版权归原出题单位所有。

## 🧭 仓库内容分层

这个仓库不只是题面库。四层内容用途不同，**不要混着读**：

| 目录 | 是什么 | 可信度 |
|---|---|---|
| `papers/` | PDF→OCR 转换的题面 | 转换产物，已知 15 题 OCR 损伤、3 题残缺、2022 整年乱码 |
| `solutions/` | 第三方解析稿 | **仅供人工核对**，不作为答案权威；AI 在推断阶段禁止读取 |
| `分析/` | 从题面派生的统计 + 人工建立的方法族与认知模型 | 分层标注，见 `分析/10_高等数学_资料与覆盖索引.md` |
| `原创题组/` | 原创复习题及其审题流程 | 出题者已自检，独立验收状态见各包内说明 |

**`分析/` 的入口是 `分析/10_高等数学_资料与覆盖索引.md`** —— 它不含内容，只说明数据从哪来、
每份材料的主张类型与不确定性、当前任务该查哪几份、以及哪些话不许升级成预测。
先读它，再按它的路由取内容。

高数材料是三层分工：

| 层 | 文件 | 回答什么 |
|---|---|---|
| 地图 | `分析/高数考法与认知模型.md` | 11 个模块在 22 年里实际怎么考 |
| 眼 | `分析/高数逐考点认知模型.md` | 127 个考点，看到什么才想到它 |
| 手 | `分析/高数方法速查.md` | 怎么做，并挂真题题号 |

另有 9 份 `分析/方法族-高数-*.md`（按解题路线组织，各自带 status 与冻结条件）、
线代与概率的考法统计与方法速查、`分析/tests/` 下可重跑的统计检验脚本。

## 🤖 给 AI 协作者

**动手前先读根目录 `CLAUDE.md`** —— 它是本仓库唯一的规则来源，规定了：
考点粒度、输出文件与覆盖范围、哪些文件重跑不得触碰、以及 `solutions/` 的读取限制。

多 agent 协作走 `分析/协作/看板.md`；审查报告落在 `分析/审查/`。

## 🔧 使用方式

### Obsidian

1. 将 `papers/` 文件夹复制到你的 Obsidian Vault
2. 启用 LaTeX 公式渲染（默认支持）

### VS Code

安装 **Markdown+Math** 或 **Markdown All in One** 插件

### Typora

直接打开 `.md` 文件，原生支持 LaTeX

## 📝 格式示例

```markdown
## 一、选择题

1．已知函数 $f(x) = \int_0^x e^{t^2} \sin t \, dt$，则

A．$x = 0$ 是 $f(x)$ 的极值点  
B．$(0, 0)$ 是拐点  
C．...

【答案】B

【解析】

$$
f'(x) = e^{x^2} \sin x, \quad f''(x) = 2xe^{x^2}\sin x + e^{x^2}\cos x
$$
```

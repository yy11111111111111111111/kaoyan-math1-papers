## 一、「我要学习 XX」时的固定输出（反查真题优先）

收到「我要学习 XX」，**第一步不是讲知识**，是按下面六格填表。所有数字来自 `考试价值排序.md` / `考点频次.md` / `题型分布.md` / `同题识别.md`，一格填不出就写「数据无此项」。

```
① XX 过去 22 年怎么考的
   频次 N 次 · 其中作主考点 M 次 · 出现年份 <列表>
   题型落点 选a/填b/解c · 落在解答题时的职能 <计算|积分|证明>
   新卷型 5 卷（2021、2023–2026）出现 K 次 → 标记 <稳定·近年活跃|稳定|盲区|低证据>

② 最常见的考法，按频次排序
   从 <科目>方法速查.md 取该考点的「具体操作」列，配 §三 的考法模板编号

③ 最值得掌握的能力（由 ① 的题型落点反推，不由教材篇幅决定）
   解 c 占多数 → 练完整流程与书写结构
   选+填 a+b 占多数 → 练 3–4 分钟内的快速判定，不练长篇推导
   证明职能出现过 → 练辅助函数构造，不练背结论

④ 常同题出现的考点（`考试价值排序.md` §三）
   列共现 ≥2 次的搭档 → 学完 XX 之后必须补一道 XX+搭档 的同题

⑤ 需要学到什么程度（四档，由 ③ 决定，不由感觉决定）
   [ ] 认得出 [ ] 说得清 [ ] 算得对 [ ] 证得出／能综合调用

⑥ 训练配比（由 ① 的题型比例直接换算，见 §五）
   例：选/填/解 = 6/7/4 → 练 17 道题时按 6:7:4 分配，不平均分
```

### 一个真实样例：泰勒公式展开

| 格 | 内容 |
|---|---|
| ① | 17 次（全库第一）· 主考点 6 次 · 2007–2026 共 15 个年份出现 · 选 6/填 7/解 4 · 解答题职能全部是「计算」· 新卷型 5 卷出现 **7 次** · 标记「稳定·近年活跃」 |
| ② | `高数方法速查.md` L24：「求极限展开到能约分；证不等式带拉格朗日余项」。**分裂成三个独立考法**：泰勒定阶求极限（组 30）／泰勒证不等式（3 次：2012-15、2018-19、2024-19）／泰勒证中值等式（1 次：2023-20，**低证据**） |
| ③ | 它 17 次里 13 次落在选填 → **主力能力是「定到几阶就停」，不是背展开式**。`解法.md` 反复标的易错处是定阶：2004-7「定阶要看积分后的阶而非被积函数的阶」 |
| ④ | 与「等价无穷小替换求极限」共现 **6 次**（全库最高的一对）、与「等价无穷小的判定」共现 4 次 → 这两个必须合起来练 |
| ⑤ | 算得对（选填层）＋ 证得出（2023-20、2024-19 两个证明位用到） |
| ⑥ | 6:7:4 → 每 17 道练习里 6 道选择、7 道填空、4 道解答 |

**这一格必须同时说出的话**：泰勒标签 17 次是事实（`mechanical_from_tsv`，继承标注误差）；**但不要解释它为什么高频**——`命题模型.md` 检验 E 已于 2026-08-27 复核作废（控制出现次数后趋势低于机械基准），本库给不出成因。「所以它是重点章节」和「所以它只是通用工具」**两个说法都没有证据**。

## 二、考试价值的量化

```
考试价值 = 频次×1.0 + 覆盖题型数×2.0 + 解答题次数×1.5 + 新卷型出现次数×1.5
归一化分 = 考试价值 / 39.5 × 100      （39.5 为全库最高，泰勒公式展开）
```

- 全部 223 个考点的价值分、归一化分与档位已算好：**`考试价值排序.md`**，含权重理由与复算口径。
- 档位按价值分降序累加考点标注次数（总 872 次）、切在 25/50/75% 得到：**S 22 个 / A 37 个 / B 58 个 / C 106 个**，各覆盖约四分之一的出现量。头部 22 个考点 = 尾部 106 个考点的覆盖量。
- **`学习优先级 = 考试价值 × 薄弱程度` 这一层，用户已于 2026-08-27 声明不启用**，不再索要掌握度打分。排序一律只用考试价值。
- 后续若要恢复该层，薄弱程度用四档整数 `4=无思路 / 3=会但常错 / 2=对但慢 / 1=稳`，且只接受模块自测与错题表统计两个来源——**不采纳自我感觉**。

## 三、考法模板（跨年份稳定的底层结构）

本库已有的模板分两类，**都不是我现编的**：

### 3.1 位置模板（6 套）——`功能位模板.md`

新卷型 5 卷 22 个题位的科目归属逐位完全相同，四个高数解答位职能稳定：

| 位置 | 职能 | 稳定度 |
|---|---|---|
| 17 | 计算型功能位 | 5/5 |
| 18 | 多元微分主场（4 次）或级数（1 次） | 5/5 |
| 19、20 | **一道多元积分 + 一道中值定理证明，顺序每年可换** | 2023–2026 共 4/4；2021 是唯一例外（无证明题） |
| 21 | 线代：特征值—相似—二次型—矩阵方程族 | 5/5 |
| 22 | 概率：随机变量函数的分布或期望 ＋ 参数估计 | 5/5 |

⚠️ 有效样本只有 5 卷。够看职能模式，**不够说「第 N 题必考 X」**——本库从不这么说。

### 3.2 路径模板（35 组确定 + 12 组疑似）——`同题识别.md`

按**解题路径相同**判定，不看题干措辞，天然就是用户要的「识别信号 → 解题步骤 → 调用知识 → 失分点」四件套。训练价值最高的几组：

| 组 | 底层考法 | 题数 | 说明 |
|---|---|---|---|
| 5 | 非闭曲面补一块平面凑闭，用高斯公式算整体再减补面 | 7 | 全库最大组，横跨 2004–2025 |
| 20 | 一阶矩解矩估计 → 似然取对数求驻点 | 5 | **2015-23 是唯一路径分岔**（似然单调无驻点，改用边界讨论）——最好的对比素材 |
| 21 | 参数方程二阶导，标准模板四次重复 | 4 | 2013-11、2020-10、2021-12、2026-13 |
| 26 | 曲线不闭，补线段凑闭，用格林公式减补线 | — | 与组 5 是同一个「补/减」思路的两个维度 |
| 12 | 三平面位置关系 ⇄ 秩 | 2 | 2024-5 几乎是 2019-6 的重制 |

**12 组「疑似」不当同题讲**，只作辨析素材。

### 3.3 我讲某道解答题时的固定顺序

先挂主线，再讲步骤——三份速查各自开头的「全局结构」（线代是 r(A) 枢纽，概率是四步流水线）比直接给步骤有效：

```
这题在哪个功能位 → 该位置的职能是什么 → 它属于哪个路径模板
  → 模板的识别信号 → 模板的步骤 → 这一步在本题里长什么样 → 该位置的典型丢分
```

## 四、出题与变式协议

严格照 `交接说明-教学AI.md` §6.1 的四级优先，**不凭印象编题**：

1. **真题原题**（唯一保证题目本身没问题的方式）→ 从 `考点标注.tsv` 按考点/题型/职能筛题号，去 `papers/` 取原题。**出题前先查 `待确认.md`。**
2. **同题组变式**（`同题识别.md` 35 组）→ 组内路径相同、包装不同，是现成的「换个说法再来一遍」。
3. **改编真题**（改数字、换区域、最大值改最小值）→ **必须声明是改编**，且改完自己走一遍确认有解。
4. **完全原创** → 仅当前三条都不适用，必须声明。

**变式的判据**：考查能力相同、表面内容不同。目的不是押题，是验证「22 年真题反复要求的那个能力我到底有没有」。

**出题时给**：题目、来源题号、所属功能位、分值与建议用时（选填 3–4 分钟／解答 13–15 分钟，按 180 分钟 ÷ 22 题倒推）。
**出题时不给**：答案（除非做完了）、该用哪个方法（那正是要考的）、难度预判。

**成套出卷配比**（`命题模型.md` 检验 F，考纲约束下的唯一整数解，不改）：

| | 选择 | 填空 | 解答 | 合计 |
|---|---|---|---|---|
| 高数 | 4 | 4 | 4 | 12 |
| 线代 | 3 | 1 | 1 | 5 |
| 概率 | 3 | 1 | 1 | 5 |
| **合计** | **10** | **6** | **6** | **22 题 / 150 分** |

## 五、训练配比服从真实考法分布

不给所有考点同样的练法。规则是机械的，直接查 `考试价值排序.md` 的 `选/填/解` 与 `解答职能` 两列：

| 该考点的数据长相 | 训练怎么排 | 例 |
|---|---|---|
| 解答占多数 | 以完整解答为主，练书写结构与中间步骤 | 最大似然估计量 0/0/13 → **全部练解答**，一道选填都不用出 |
| 选填占多数 | 练 3–4 分钟内的快速判定，**不出长篇推导** | 导数定义 6/1/1、变限积分的性质 6/0/2 |
| 三型均沾 | 按实际比例分配 | 泰勒 6/7/4 |
| 解答职能含「积分」 | 练「封闭？补？挖？」三问，不练公式默写 | 高斯公式补面法 0/1/6，职能全是积分 |
| 解答职能含「证明」 | 只练辅助函数构造 | `功能位模板.md` 模板 19/20-B |
| 标记「低证据」（1 次） | 认得出即可，**不人为升级成综合题** | 39 个考点属此类 |

## 六、做错题时的三段式归因

错题记录的最小单位是 **`知识点 + 考法 + 错误类型`**，不是「第 37 题错了」。

错误类型只用这七个（由 22 年真题易错处人工归纳）：

| 类型 | 处方 |
|---|---|
| 1 概念混淆（相似 vs 合同、独立 vs 不相关、行 vs 列） | 补知识 → 回速查条目 + 找同类型的其他年份例子横向对照 |
| 2 条件遗漏（罗尔三条件、B⊂A 才有减法公式） | 补知识 → 同上 |
| 3 方向与符号（积分方向、法向量、补/挖的加减） | 增加**该考法**的变式题 |
| 4 边界与端点（极值忘边界、积分限、分段点） | 增加该考法的变式题 |
| 5 计算失误 | 不补知识，加限时训练 |
| 6 审题（问 A 答 B） | 加考法**识别**训练：给题干只判类型不解 |
| 7 无思路 | 回速查表从零重学：该考点尚未建立最基本的流程 |

对应用户规则十的四类：知识不知道 = 1、2；会但不会用 = 3、4；识别不出来 = 6；答案结构不对 = 用 `功能位模板.md` 该位置的骨架练结构。

**每周日统计一次各类型条数。**「计算失误」过半 → 问题在做题习惯不在知识；「无思路」还在涨 → 回阶段一。

## 七、复习什么 vs 什么时候复习（两个独立信号）

| | 由谁决定 | 依据文件 |
|---|---|---|
| **什么值得复习** | 22 年数据 | `考试价值排序.md` 的价值分与标记 |
| **什么现在该复习** | 我的表现 | 错题表 + 自测 |

调度规则：

- 高价值 + 已稳定 → 降低频率，只留主动检索。
- 高价值 + 常错 → 提高频率，且按 §五 的配比补练。
- 低价值 + 完全不会 → **不是「不用学」**，是按距考试的剩余时间决定投不投。
- 高价值 + 长时间没测 → 安排主动检索（遮住速查表的「具体操作」列复述）。
- 标记「盲区」的 23 个考点 → 只刷 2021 后的卷子一次都练不到，阶段三（第 13–14 周）集中补。**这是补漏，不是押题**——检验 B/G 均未检出考点层信号，且「未检出」不等于「已证否」，把它当补漏清单是保守政策。

## 八、每次给学习任务必须带的「为什么选它」

格式固定，缺一格就是没依据：

```
今天选 <考点>，因为：
· 22 年出现 N 次，其中主考点 M 次
· 题型落点 选a/填b/解c；落在解答题时职能是 <…>
· 新卷型 5 卷出现 K 次 → 标记 <…>
· 与 <搭档> 共现 P 次，学完要补一道同题
· 你在该考法上的表现：<错题表证据，或「无数据」>
· 你当前的阶段与讲法深度：<由用户告知；用户未说明时先问一句，不要自行假定>
⇒ 当前优先级 <S/A/B/C>
```

其中「阶段」这一格决定同一道题该讲多深（`交接说明-教学AI.md` §2.2）：

| 阶段 | 周 | 我该给的 |
|---|---|---|
| 一·模块清扫 | 1–4 | 完整步骤，**允许直接给方法**，卡 5 分钟就讲 |
| 二·功能位横刷 | 5–12 | 少给步骤，多问「这题和上一道差在哪」 |
| 三·盲区补齐 | 13–14 | 按速查条目从零讲 |
| 四·模考收口 | 15–17 | **只订正不拓展**，不引入新方法 |

## 九、绝对不做的七件事（用户规则十三，逐条落到本库）

| 禁令 | 本库对应的硬依据 |
|---|---|
| 1 高频 ≠ 今年一定考 | 检验 B 未检出连年回避（158 对 vs 置换预期 148.3±9.0，p=0.154）；检验 G 未检出空窗效应（空窗≥5 场 vs 上场刚考过的出现率比 0.92，95% 区间 [0.77, 1.11]），**均为未检出** |
| 2 不按「出题规律」预测具体题目 | 同上。可预测的只有卷面座位表与功能位职能（检验 D、F） |
| 3 低频不等于「不用学」 | 用「低证据」标记代替「不重要」；考纲仍收录（`考纲.md`） |
| 4 不脱离考法只背知识点 | 每次输出必须先填 §一 的六格 |
| 5 不重复原题、要变式 | §四 的四级优先，第 2 级就是同题组变式 |
| 6 不给所有考点同一种练法 | §五 的配比表 |
| 7 **统计没给的信息不编** | §〇 的五行空缺就是这条的执行结果 |

数据答不了的时候，标准回答是一句话：**「22 年数据无法支持这个结论。」**

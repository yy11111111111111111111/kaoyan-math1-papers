# 同题识别

判定标准：**解题路径相同**即为同组，不看题干措辞（`CLAUDE.md` §4.3）。识别范围为 `数学一` 内 2004–2026（扣除 2022 及 3 道残缺题），共 499 题。

判定不确定的一律进末尾「疑似」一节，不混入确定组。

## 确定组

### 组 1：先验算 k=lim y/x、b=lim(y−kx)，再逐一排查铅直与水平渐近线，数出条数
- 2007-2、2012-1、2014-1
- 差异：2007 与 2012 给具体函数，2014 是四个选项各判一次；2012 的铅直渐近线因分子分母同时为零而只剩一条，是本组唯一的陷阱点

### 组 2：只求斜渐近线，两步极限直接算
- 2005-1、2023-1
- 差异：2005 是有理分式，直接做多项式除法；2023 含 ln(e+1/(x−1))，须先对 1/(x−1) 作泰勒展开

### 组 3：由二次曲面的图形类型倒推正负惯性指数，定参数或选曲面
- 2008-6、2016-6、2026-7
- 差异：2008 给图形问正特征值个数；2016 给二次型问曲面类型；2026 反向给「圆柱面」定参数 a 并写标准形

### 组 4：把系数递推翻译成和函数满足的微分方程，解出 S(x)
- 2007-20、2013-16、2020-17
- 差异：2007 与 2013 给二阶递推，得二阶方程；2020 给一阶递推 (n+1)a_{n+1}=(n+½)a_n，得一阶方程，可直接分离变量

### 组 5：非闭曲面补一块平面凑成闭曲面，用高斯公式算整体再减去补面
- 2004-17、2006-3、2007-18、2014-18、2018-17、2020-18、2025-20
- 差异：补面方向与被积函数的对称性利用程度不同。2014、2018、2020 需先用奇偶对称性化简被积函数再补面；2025 的曲面由直线绕直线旋转得到，多一步求旋转曲面方程

### 组 6：把 f 按奇/偶延拓成周期函数，用狄利克雷收敛定理在指定点求和函数值
- 2013-3、2023-13、2025-12
- 差异：2013 与 2025 是正弦级数（奇延拓），2023 是余弦级数（偶延拓）；求值点都落在延拓后的间断点或需先化到主周期

### 组 7：柱面与平面的交线，参数化后直接积或用斯托克斯公式
- 2011-12、2014-12
- 差异：仅换被积表达式与平面；两题都是 x²+y²=1 与一张平面相交、从 z 轴正向看逆时针，属换数字重制

### 组 8：F(x,y)=∫₀^{xy}g(t)dt 型，先对一个变量求偏导消掉积分号，再对另一个变量求导
- 2011-11、2020-12
- 差异：2011 求 ∂²F/∂x² 且被积函数只含 t；2020 求 ∂²f/∂x∂y 且被积函数含参变量 x，需多一次含参积分求导

### 组 9：由矩阵满足的多项式方程定出特征值的候选，再用秩定各特征值的重数
- 2010-6、2019-5
- 差异：2010 由 A²+A=O 得 λ∈{0,−1}，秩 3 定重数，问相似于哪个对角阵；2019 由 A²+A=2E 得 λ∈{1,−2}，用 |A|=4 定重数，问规范形

### 组 10：写出形心坐标公式，分子分母各算一个三重积分，选柱面坐标
- 2010-12、2019-19
- 差异：2010 是抛物面下方区域只求 z̄；2019 是斜锥体，须先看出它是圆锥的仿射像，或直接用截面法

### 组 11：把 P(A|B) 与 P(A|B̄) 的比较化归为 P(AB) 与 P(A)P(B) 的比较
- 2017-7、2021-8
- 差异：2017 是四选一找充要条件；2021 是找假命题，多一个 P(A|A∪B) 的选项需单独构造反例

### 组 12：三张平面的位置关系 ⇄ 系数矩阵与增广矩阵的秩
- 2019-6、2024-5
- 差异：几乎完全相同，2019 是两两相交且交线平行（r(A)=2, r(Ā)=3），2024 换成另一种位置关系（r=n=2）；2024 可视为 2019 的重制

### 组 13：分块上（下）三角矩阵的秩，用 r(A)+r(B) 与 r(AᵀA)=r(A) 拆解
- 2021-7、2023-5
- 差异：2021 判四个结论中哪个不成立；2023 比较三个分块矩阵的秩大小，需额外用 ABC=O 的条件

### 组 14：f″≥0（f′ 单调增）时，把 f 与弦或切线的高低关系翻译成不等式
- 2014-2、2026-3
- 差异：2014 比 f(x) 与过端点的弦 g(x)；2026 比 f(x) 与切线，并给出差商单调性的等价说法

### 组 15：把和式极限凑成 ∫₀¹ 的黎曼和，认出分点与区间长度
- 2017-16、2021-4
- 差异：2017 直接算 lim Σ(k/n²)ln(1+k/n)；2021 反向判断四个和式哪个等于 ∫₀¹f，须逐一核对分点是否落在 [0,1]

### 组 16：直接套梯度定义，逐个偏导代点
- 2008-2、2012-11
- 差异：仅换函数与代入点

### 组 17：方向导数 = 梯度与单位方向向量的内积
- 2005-3、2017-3、2025-13
- 差异：2005 已给单位向量；2017 与 2025 给的是一般向量，须先单位化

### 组 18：判断给定统计量服从哪个抽样分布，靠 χ²、t、F 的构造式核对
- 2004-13、2005-14、2013-8、2017-8
- 差异：2004 考标准正态的双侧分位点与上侧分位点的换算；2013 考 t 与 F(1,n) 的平方关系；2005 与 2017 是四选一核对构造式，2017 问「不正确的」

### 组 19：求 max/min 的分布与密度，再定常数使 aT 成为无偏估计
- 2016-23、2024-22、2026-22
- 差异：2016 与 2024 是最大值 X_(n)，2026 是最小值 min；2024 多问一步均方误差 h(c) 的最小化，2026 多问定数截尾下的最大似然估计

### 组 20：一阶矩列方程解出矩估计，再写似然函数取对数求驻点得最大似然估计
- 2004-23、2009-23、2013-23、2015-23、2017-23
- 差异：总体密度不同。2015 的似然函数关于 θ 单调，驻点法失效，须改用「使 θ 尽量大」的边界讨论——本组唯一路径分岔处；2017 前面还要先求 |X−μ| 的密度

### 组 21：参数方程 dy/dx=(dy/dt)/(dx/dt)，再对 t 求导除以 dx/dt 得二阶导
- 2013-11、2020-10、2021-12、2026-13
- 差异：仅换参数式与代入点，是标准模板的四次重复

### 组 22：二维正态在不相关（ρ=0）时独立，条件密度即边缘密度
- 2007-10、2010-22
- 差异：2007 直接问条件密度；2010 给出未配方的指数式，须先配方认出这是二维正态并定出 A 与 ρ

### 组 23：由给出的解反推特征根与特解形式，凑出原方程或通解
- 2009-10、2013-10、2015-2
- 差异：2009 由通解形状定 a,b 再解非齐次；2013 给三个特解，用「解之差是齐次解」提取；2015 由一个特解定 a,b,c

### 组 24：把反常积分拆成瑕点端与无穷端两段，各自比较 p 判敛散
- 2010-3、2016-1
- 差异：2010 的两端指数分别由 m、n 控制，结论是与二者都无关；2016 的两端由 a 与 a+b 控制

### 组 25：极坐标与直角坐标下二重积分的互化，关键是定出 θ 的范围与 r 的上下限
- 2006-8、2015-4
- 差异：2006 从极坐标化到直角坐标；2015 反向，且区域由 2xy=1、4xy=1 围成，r 上下限含 √(sin2θ)

### 组 26：曲线不封闭，补一段线段凑成闭曲线，用格林公式算整体再减补线
- 2008-16、2012-19、2025-14
- 差异：2008 沿 y=sinx 补 x 轴；2012 是两段圆弧接成，补两条半径；2025 沿抛物线补 x 轴。三题的被积函数都满足 ∂Q/∂x−∂P/∂y 为常数或易积

### 组 27：秩 1 矩阵 ααᵀ 的特征值为 αᵀα 与 n−1 个 0
- 2009-13、2012-13、2017-5
- 差异：2009 直接问非零特征值；2012 问 E−ααᵀ 的秩；2017 问 E±kααᵀ 哪个不可逆，须把结论推到 1−k·αᵀα=0

### 组 28：把列（行）变换翻成右（左）乘初等矩阵，按变换顺序排出乘积
- 2004-11、2006-12、2011-5
- 差异：2004 求 Q 使 AQ=C；2006 判 C 与 A 的相似关系；2011 反解 A 本身，需取逆。核心都是「左行右列、先做的先乘」

### 组 29：(1+u)^v 型极限取对数化为 0/0，用等价无穷小或泰勒定阶
- 2010-1、2011-15、2018-9
- 差异：2010 与 2018 含参数需反解；2011 的底数是 ln(1+x)/x，须展开到二阶

### 组 30：用泰勒展开把两个无穷小定到同阶，比较系数
- 2007-1、2009-1、2015-15、2023-11
- 差异：2007 是四选一找等价量；2009、2015、2023 是给等价关系反解参数，2015 展到三阶且有三个参数

### 组 31：多元函数求驻点，用 AC−B² 判别式定极值
- 2009-15、2012-16、2013-17、2020-15、2026-17
- 差异：驻点个数与判别式退化情况不同。2013 与 2023-18（见疑似）在 AC−B²=0 时判别式失效，须改用定义法——本组的分岔点

### 组 32：隐函数两边求导得 y′，令 y′=0 定驻点，再用 y″ 或单调性判极值
- 2014-16、2017-17
- 差异：仅换方程；两题都需在原方程中回代求出驻点处的 y 值

### 组 33：闭曲面直接用高斯公式化为三重积分
- 2005-4、2016-18、2021-14、2023-19
- 差异：散度化简后 2005 与 2021 得常数乘体积；2016 与 2023 需真算三重积分，且可用对称性丢掉奇函数项

### 组 34：幂级数逐项求导（或积分）凑成已知的几何级数，反解和函数
- 2010-18、2012-17
- 差异：2010 的通项含 1/(2n−1)，宜先积分；2012 的通项含 n²，需求导两次并拆项

### 组 35：F(x)=aΦ(x)+bΦ((x−c)/d) 型混合正态，按线性性拆开算期望
- 2009-7、2017-14
- 差异：仅换系数与平移量，2017 是 2009 的换数字重制

## 疑似

以下各组考点相同但解题路径是否一致存疑，不计入确定组。

### 疑似 1：拐点的判定
- 2011-1、2015-1
- 存疑点：2011 由多项式的重根奇偶性直接读出拐点，2015 需从 f″ 的图形数变号次数并排除 f″ 不存在的点。判据同，操作路径差别较大

### 疑似 2：定积分求面积后接数项级数求和
- 2009-16、2019-17
- 存疑点：2009 的面积序列可求通项后错位相消，2019 是衰减振荡曲线与 x 轴的无穷多块面积求和（等比级数）。级数类型不同

### 疑似 3：假设检验
- 2018-8、2021-10
- 存疑点：2018 考显著性水平变小时拒绝域的包含关系，2021 考第二类错误的概率计算。同属假设检验但不是一个考法

### 疑似 4：旋度与散度的计算
- 2016-10、2018-11、2026-11
- 存疑点：前两题是直接代旋度行列式；2026 求 div(rot(rot A))，若用 div·rot≡0 则一步出结果，与前两题的硬算路径不同

### 疑似 5：行列式与矩阵方程求 |B|
- 2005-5、2006-5
- 存疑点：2005 是 B=AC 型分解后用行列式乘法；2006 需先把 BA=B+2E 变形为 B(A−E)=2E 再取行列式。变形步骤不同

### 疑似 6：相关系数计算
- 2008-8、2012-8
- 存疑点：2008 由 ρ=1 反推线性关系（不需真算）；2012 需先写出两段长度的联合分布再算协方差

### 疑似 7：第一类曲线积分
- 2009-11、2018-12
- 存疑点：2009 是平面曲线直接代弧长微元；2018 是球面与平面的交线，标准解法是用对称性与 x+y+z=0 的轮换性凑，几乎不需积分

### 疑似 8：斯托克斯公式
- 2024-20 与组 7（2011-12、2014-12）
- 存疑点：2024 是球面与平面的交线，投影后不是圆而需配方，且被积表达式不满足组 7 的直接参数化条件

### 疑似 9：矩阵相似的判定
- 2016-5、2017-6、2018-5
- 存疑点：2016 考相似的保持性质（转置、逆、和），2017 与 2018 考具体矩阵是否相似（比对特征值与秩）。前者是性质题，后者是计算题

### 疑似 10：变量代换求解微分方程
- 2014-11、2024-14
- 存疑点：2014 令 u=y/x 化齐次方程；2024 令 u=x+y 化可分离变量。代换动机不同

### 疑似 11：条件极值与拉格朗日乘数法
- 2008-17、2021-19
- 存疑点：两题都是求空间曲线上点到 xOy 面的距离极值，题面结构高度相似；但 2008 的约束可消元降为一元问题，2021 更适合直接列乘数方程。是否算同题取决于是否允许消元法

### 疑似 12：全概率公式
- 2008-22、2017-22
- 存疑点：两题都是「离散 X 与连续 Y 独立，求 Z=X+Y 的密度」，路径确实相同；但 2008 还要求一个条件概率，2017 还要求 P{Y≤E(Y)}，附加问题使整题的作答重心不同

# 方法族 · 高数 · 一元积分学（v1.1.0 · Batch 3 · calc.int1v.route-selection）

## 0. 家族定位

本族处理**一元积分学的路线选择**：不定积分求原函数、定积分求值与性质、
变限积分、反常积分的计算、以及定积分的几何应用。
schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`。

**边界**：反常积分的**敛散性判别**属 `calc.series.route-selection`
（v1.1.0 的 improper_integral 格，SB-4 裁定）；本族只管**计算**。
这条边界写在 A9 的 `boundary_note`。

    - boundary_id: B1
      changed_condition: 把变限积分 F(x)=∫ₐˣ f(t)dt 当作一个常数
      effect: invalidates
      explanation: >
        F 是 x 的函数；t 是哑变量。当作常数则求导得零、判奇偶无从谈起，
        整条路线失效。
      witness:
        kind: proof
        ref: |
          f(t) = t，a = 0：F(x) = ∫₀ˣ t dt = x²/2，显然随 x 变化。
          若当作常数则 F′ ≡ 0，与 F′(x) = f(x) = x 矛盾。
        verification: verified
      recovery: 明确写出 F(x) 的自变量，再按 A6/A7 处理

    - boundary_id: B2
      changed_condition: 被积函数中含 x 时直接套变限积分求导公式
      effect: invalidates
      explanation: >
        公式 F′ = f(b(x))b′(x) − f(a(x))a′(x) 的推导前提是被积函数只依赖积分变量。
        被积含 x 时 F 是二元结构，须先把 x 移出积分号。
      witness:
        kind: constructed_counterexample
        ref: |
          F(x) = ∫₀ˣ (x − t) dt。
          · 正确：把 x 移出 —— F(x) = x∫₀ˣdt − ∫₀ˣ t dt = x² − x²/2 = **x²/2**，
            故 F′(x) = **x**。
          · 错误：直接套公式，把被积「f(t) = x − t」在 t = x 处取值 ⇒ F′ = (x − x)·1 = **0**。
          两者相差 x，除 x=0 外全错。
        verification: verified
      recovery: 先换元或拆项把 x 移到积分号外，再用 A6

    - boundary_id: B3
      changed_condition: 「f 偶 ⇒ F 奇」在 ∫₀^{下限} f ≠ 0 时被沿用
      effect: invalidates
      explanation: >
        该结论依赖 F(0)=0，即 ∫₀^{下限}f = 0。
        **2026-08-29 更正**：原写「而这需要下限为 0」是假的——「下限为 0」只是
        F(0)=0 的充分条件。反例 f(t)=t²−1（偶）、下限 √3：∫₀^{√3}(t²−1)dt = 0，
        G(x)=x³/3−x 仍为奇函数。见 guard#3。
      witness:
        kind: constructed_counterexample
        ref: |
          f(t) = t² + 1（偶）。
          · 下限 0：F(x) = x³/3 + x。数值 F(1) = 1.3333、F(−1) = −1.3333，
            F(1) + F(−1) = **0**（奇）✔
          · 下限 1：G(x) = ∫₁ˣ f = x³/3 + x − 4/3。数值 G(1) = 0.0000、
            G(−1) = −2.6667，G(1) + G(−1) = **−2.6667 ≠ 0** ⇒ 不是奇函数。
        verification: verified
      recovery: 下限非 0 时改写为 ∫₀ˣ − ∫₀^{下限}，把常数分离出来

    - boundary_id: B4
      changed_condition: 由「f 以 T 为周期」直接断定 F(x)=∫₀ˣf 也以 T 为周期
      effect: invalidates
      explanation: "F(x+T) − F(x) = ∫ₓ^{x+T} f = ∫₀ᵀ f（对周期函数与 x 无关）。该差为零才有周期性。"
      witness:
        kind: constructed_counterexample
        ref: |
          · f = sin t，T = 2π：∫₀ᵀf = 0（数值 1.97e−17）。
            F(1) = 0.45970，F(1+T) = 0.45970 ⇒ **相等，F 有周期** ✔
          · f = sin t + 1，同样 T = 2π：∫₀ᵀf = **6.2832 ≠ 0**。
            F(1) = 1.45970，F(1+T) = 7.74288，差 = 6.2832 = T·1 ⇒ **F 无周期**。
          两者的 f 都以 2π 为周期，结论却相反 ⇒ 周期性不能直接继承。
        verification: verified
      recovery: 先算 ∫₀ᵀf；非零则 F 无周期（F 由「周期项 + 线性增长项」组成）

    - boundary_id: B5
      changed_condition: 对含瑕点的定积分直接套牛顿-莱布尼茨
      effect: invalidates
      explanation: >
        牛顿-莱布尼茨要求被积函数在闭区间上（黎曼）可积，
        瑕点处不满足；形式地代限会得到有限的假值。
      witness:
        kind: constructed_counterexample
        ref: |
          ∫_{−1}^{1} dx/x²。原函数取 −1/x，形式代限得
            (−1/1) − (−1/(−1)) = −1 − 1 = **−2**。
          但被积函数处处为正，任何收敛的积分都不可能为负 ⇒ 该值荒谬。
          实际上 x = 0 是瑕点：∫₀^1 dx/x² = lim_{ε→0⁺}(1/ε − 1) = **+∞**，发散。
        verification: verified
      recovery: 先找瑕点，按 A9 拆开逐段取极限

      explanation: >

      witness:
        kind: proof
        ref: |

        verification: verified
      recovery: 逐段判，不合并；若题目明确要主值则另行说明

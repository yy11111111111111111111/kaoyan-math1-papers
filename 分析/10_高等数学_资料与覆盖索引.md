## 2. 主张标注（**不是**证据等级）

### 2.0 ⚠️ 命名边界：本节不与项目总入口的 A–E 竞争

数学一总入口已有一套全项目的 **`source_authority: A–E`**，区分的是**来源权威性**（官方/教材、课程资料、未逐项复核的转录、个人整理、自动抽取）。

本节标注的是**另一根轴**：某个字段是**怎么得到的**、**是什么类型的主张**。两者正交，必须共存，**不能互相替代**。

> 本文件早期版本把这根轴也叫作「证据等级 E1–E5」，会与总入口的 E 级产生语义冲突（「这是 E1，可总入口说它是 E 级」）。**该命名已废除**，改用下面的字段名。引用旧的 E1–E5 一律视为过期。

### 2.1 四个正交字段

任何一条重要 claim 至少要能挂上这四项：

```yaml
source_authority: A | B | C | D | E        # 沿用项目总入口定义，本库不重定义
derivation:                                 # 这个数字/说法是怎么来的
  mechanical_from_tsv                       #   脚本从 TSV 复算，可完全复现
  | human_annotation                        #   人工逐题标注（考点标签）
  | human_synthesis                         #   人工归纳整理（认知模型、方法步骤）
  | unverified_inference                    #   从题面独立推断、未对答案（解法.md）
  | original_source                         #   须回原卷/可靠解析
sampling_scope:                             # 这条结论建立在多少样本上
  years: 22                                 #   2004–2026 扣 2022
  n: <本条实际用到的样本量>                  #   例：功能位 n=5
annotation_dependence: none | low | material # 结论对人工标注正确性的依赖程度
claim_type:                                 # 这句话在主张什么
  source_fact                               #   来源事实
  | sample_description                      #   对样本的描述
  | pedagogical_hypothesis                  #   教学假设，需学习表现数据验证
  | predictive_claim                        #   对未来的预测 ← 本库一律不产出
```

### 2.2 两条容易被跳过的推论

**① `mechanical_from_tsv` 只保证「忠实于 TSV」，不保证「TSV 的标签正确」。**

> 「泰勒公式展开标签出现 17 次」是 `mechanical_from_tsv`，可完全复现；
> 但它**继承**「泰勒这个标签由人工标注」的分类误差，`annotation_dependence: material`。
> 所以它是「**该标签在本库标注体系下出现 17 次**」，不是「泰勒这个数学工具被考了 17 次」。

**② 不确定性有四种，不要压进一根轴。**

| 不确定性 | 来自 | 对应字段 |
|---|---|---|
| 可复现性 | 是不是脚本算的 | `derivation` |
| 测量/标注误差 | 标签归属对不对 | `annotation_dependence` |
| 抽样与外推 | 样本多大、能不能外推 | `sampling_scope` + `claim_type` |
| 来源保真 | 题面 OCR 有没有坏 | `source_authority` |

功能位的 n=5 是**抽样问题**；同题识别的路径判定是**标注问题**。二者性质不同，早期版本把它们压在同一个「E2」里是错的。

## 4. 真题风险（固化，不可绕过）

### 4.1 模考保护：2024 / 2025 / 2026

这三套是**仅有的干净模考样本**（现行 22 题卷型自 2021 启用，扣掉乱码的 2022 只有 5 套，其中 2021、2023 已作精练用）。

- **2026-11-29（复习计划第 15 周）之前，不得向用户展示这三年的任何完整题目。**
- 单题引用作对比**可以**；成套展示、整卷讲解、按年份连续出题**不可以**。
- 用掉就没了，没有补充来源。

### 4.2 禁用题：题面无法复原

| 题号 | 情况 |
|---|---|
| `2023-9` | 四个选项全部为空 |
| `2024-13` | 题干 OCR 严重损坏，函数定义 / 级数形式 / 所求极限三处均不可复原 |
| `2025-10` | 题干止于拒绝域表达式，四个选项缺失 |

**出题、讲解、举例一律跳过这三题。**

### 4.3 题面假设条目：先查 `待确认.md`

另有 **15 题**的解题路径建立在「题面应该是什么」的假设上（`待确认.md` §2.1）：
`2006-16`、`2011-17`、`2013-6`、`2014-23`、`2019-2`、`2023-5`、`2023-6`、`2023-7`、`2023-15`、`2026-1`、`2026-3`、`2026-15`、`2026-18`、`2026-19`、`2026-20`

讲这些题**必须先声明题面存疑**，并让用户以纸质原卷为准。注意 2026 一年占 6 条，该年题面转换质量整体偏低。

### 4.4 `解法.md` 不得做答案键

- 499 节**全部** `status: 待核对`，人工核对完成数 **0**。
- 它是**从题面独立推断**的——**没有参考任何官方答案**（`solutions/` 按项目规则被显式排除在推断依据之外）。
- ✅ 可用：思路提示（「这道题的常见切入点是……」）、易错处提醒。
- ❌ 不可用：具体数值答案（「极限 = 1/2」「选 B」）作为标准答案陈述。
- ⚠️ 必须引用结论时：**「这是推断的候选路线，未经核验，请以标准答案为准」**。

### 4.5 其他边界

- **2022 年整年不可用**：题面文件全文乱码，不在任何统计内，**没有任何人能从本仓库拿到 2022 年的题**。
- **1987–2003 未纳入**：题面可用但旧卷型，本轮分析未覆盖。
- **2023 选择题分值未知**：节标题自相矛盾，留空。
- **新旧卷型分值不同**：2004–2020 是 23 题（选填 4 分、解答 9 道），2021 起是 22 题（选填 5 分、解答 6 道）。**用旧卷型的题给用户估分会严重失真。**

## 5. 描述 vs 预测：哪些话不许升级

**总原则**：本库的所有结论都是**对 2004–2026 这 22 个样本的描述**。样本描述升级成未来判断，需要一层本库没有的证据。

### 5.1 已被数据否证的信念

两个检验，**都只是「未检出」，不是「已证否」**：

| 检验 | 测的是 | 结果 |
|---|---|---|
| **B** | 会不会连着考（相邻年重复对数） | 158 对 vs 置换预期 148.3±9.0，**p=0.154** |
| **G** | 久未出现是否更容易回来（空窗 → 下一场出现） | h(age≥5)/h(age=1) = **0.92**，整群自助 **95% 区间 [0.77, 1.11]** |

⇒ 能说的是：**在本数据下检不出空窗效应，且能排除的只是约 11% 以上的增幅**（更小的效应本检验没有功率排除）。

⚠️ **不能说**「久未出现 ⇒ 即将出现已被否证」，也**不能说**「考点层近似无记忆」——高 p 值不是对零效应的证明；无记忆是关于整个条件分布的强主张，两个检验都只测了它的一个侧面。

### 5.2 可以说 / 不可以说

| ✅ 可以说 | ❌ 不可以说 |
|---|---|
| 「泰勒公式展开标签在 22 年里出现 17 次」（`mechanical_from_tsv`，dep.=material） | 「泰勒是最重要的考点」——且注意这是**标签**出现 17 次，不是数学工具被考 17 次 |
| 「在 2021、2023–2026 这 5 个有效新卷型样本中，19/20 积分位 5/5 出现」（`sample_description`，**n=5**） | 「19 或 20 题必考曲线曲面积分」「2027 必考」 |
| 「新卷型 5 个样本的 22 个题位科目归属逐位相同」（`sample_description`，n=5） | 「第 21 题一定是线代」——是命题传统，不是规章 |
| 「2023–2026 这 4 个样本各有一道中值定理证明；2021 是唯一例外」（`sample_description`，n=4） | 「每年必有一道证明题」——2021 就没有 |
| 「这 23 个考点出现 ≥4 次且 2021 年后未再出现，仍在考纲内」（`mechanical_from_tsv`） | 「这 23 个是今年的押题清单」 |
| 「本库自建的价值分指标下，线代平均 11.9、概率 12.3、高数 10.6」（`human_synthesis` + `pedagogical_hypothesis`） | 「线代概率单位复习时间回报更高」——**数据里没有学习时间与学习增益** |
| 「在当前人工分析中，中值定理证明对关键构造与定理选择依赖较强」（`pedagogical_hypothesis`） | 「中值定理是唯一想不到就零分的模块」 |

### 5.3 「盲区 23 个」的唯一合法用法

它是**补漏清单**：如果只刷 2021 年后的卷子，这 23 个仍在考纲内的考点一次都练不到。

**它不是押题清单。**理由就是 §5.1——「久未出现」与「即将出现」在数据上无关。任何把它说成「今年可能轮到」的表述都是越界。

### 5.4 唯一允许的结构性陈述

在本数据下表现出最强样本内集中的层级是功能位（**检验 D1：剔除科目效应后 p≈0.094 / 0.064，有倾向未达显著**），引用时必须同时报出样本量 n=5 与 2021 的例外。**该稳定性的样本外预测效力未经验证**，不得据此作未来判断；**考点层一律不预测。**

## 6. 给教学系统的接口

### 6.1 本库的定位：材料，不是教学协议

`高数逐考点认知模型.md` 等文件提供的是**候选材料**。它们**不构成**已验证的教学规则。差别在于：本库的「触发信号」是从 22 年真题的表面特征归纳的，**没有经过可审查的机制说明与反例检验**。

### 6.2 触发信号 ≠ structural_rule / testable_heuristic

现有数学教学系统要求方法教学把下面四项变成**可审查对象**：

```
解前特征  →  候选动作  →  条件 / 机制  →  失效边界
```

`高数逐考点认知模型.md` 的现状：

| 槽位 | 本库覆盖情况 |
|---|---|
| **解前特征** | 部分覆盖——「信号 → 首步」列的前半 |
| **候选动作** | 部分覆盖——该列的后半，且**只给了一个动作，没给候选集** |
| **条件 / 机制** | ⚠️ **基本缺失**。「模型」列偶尔涉及机制，但不成体系、未系统化 |
| **失效边界** | ⚠️ **基本缺失**。少数条目提到（如「AC−B²=0 判别法失效」「洛必达求导后仍是 0/0」），但**没有系统标注** |

⇒ **结论**：本库的「触发信号」可以作为构造 `structural_rule` / `testable_heuristic` 的**候选材料**，**不得自动视为已验证的规则**。按关键词套方法正是这套材料的误用方式。

### 6.3 把候选材料升级为规则，需要补什么

对任一条触发信号，升级前至少要补齐：

1. **机制**：为什么这个特征意味着这个动作？（不是「历史上都这么做」，是「因为结构上……」）
2. **候选集**：这个特征下还有哪些可选动作，为什么排第一？
3. **失效边界**：什么情况下这个信号在但动作不适用？举出至少一个真题或构造的反例。
4. **可证伪的检验**：给一道满足特征但不适用的题，学生能不能识别出来？

**本库不提供这四项。**需要时应作为独立工作项提出，而不是从现有文件里「读出来」。

### 6.4 method-family rule 的状态与权限（2026-08-27 定案）

**一句话**：Claude 默认只产出 `candidate`；所有向上升级需 GPT 独立验收；**任何一方发现直接 counter-witness 都可立即降为 `challenged`**；规则验证与教学效果验证**分两条状态轴**。

#### 两条正交的状态轴

```yaml
status: candidate | partially_verified | verified_within_scope | challenged
# ↑ 只表示规则的数学/结构验证状态

pedagogical_validation:
  status: untested | preliminary | replicated
# ↑ 只表示教学效果，必须来自真实学习行为数据
```

即使 `status: verified_within_scope`，也**只说明**这套「特征—候选—guard—机制—边界」在声明范围内数学上站得住；**不说明**学生用这套表示学得更快、更易迁移、更少犯错。后者的证据只能来自无提示 method selection、guard 是否主动检查、`position_cue_dependence`、改变决定性条件后的 transfer。初期一律 `untested`。

#### 权限表

| 变更 | Claude Code | GPT |
|---|---|---|
| 新建 `candidate` | 可以 | 可以提出 |
| `candidate → partially_verified` | **不可单独决定**，负责落库 | **必须审** |
| `partially_verified → verified_within_scope` | **不可单独决定**，负责落库 | **必须审** |
| 任意状态 → `challenged` | **发现直接 counter-witness 可立即执行** | 同样可以提出 |
| `challenged` 后恢复 | 执行重核与落库 | 必须重新验收 |
| `pedagogical_validation` 升级 | **不可凭资料判断** | 必须依据实际教学行为证据 |

#### 各状态的最低含义

- **`candidate`**——schema 基本填完、待审；不允许作为「已验证方法规则」进入教学。**这是 Claude 的默认产出上限。**
- **`partially_verified`**——scope 可定义、候选集不再只有单一路线、mechanism 数学上站得住、关键 guard 的 `necessary/sufficient/heuristic` 没串位、至少一个重要 failure boundary 有 verified witness，且**仍有明确列出的未闭合边界**。含义不是「教学法有效了一半」，而是「规则结构的一部分已获独立支持」。
- **`verified_within_scope`**——门槛高得多：scope 明确 · 候选集经过实际 route scan 而非只列作者想到的一条 · 所有决定合法性/分支的 critical guard 已核验 · mechanism 有可审查数学依据 · 关键 failure boundary 都有正式论证或 verified witness 或独立核验过的构造反例 · 无未关闭的 counter-witness · **明确记录哪些范围没有验证** · GPT 给出验收意见 · Claude 落库验收摘要与版本。**名字只说「在声明范围内」，不得外推。**
- **`challenged`**——只需出现**一个**足以打破当前规则的具体 counter-witness 即触发，**不需要先证明整个规则错误，也不需要双方达成共识**。立即 `teaching_use: quarantine`，然后缩 scope / 改 guard / 改 mechanism → targeted revalidation。

> 这条「Claude 有权立即降级、无权自行升级」的不对称是**刻意的**：若降级也要等验收，一旦在批量核验中发现明确反例，规则会在隔离前继续被使用。

### 6.5 未分类题的入口：不在本库

**未分类题的数学分类由教学系统完成；本索引只接受分类后的资料查询，不负责由题面关键词决定方法。**

本库对一道未分类真题只提供三样东西，到此为止：

```
problem_id  →  待确认.md 中的缺陷状态  →  完整题面（source_status 标注齐全）
```

之后的「题面完整性 → 对象 / 已知 / 目标 / 条件与定义域 / 当前表示 → 最小数学结构 → 候选方法族 → 按需读取资料」全部属于教学系统的 method selection，**不写进 `分析/`**。理由：一旦把这套逻辑写进资料库，就会重新出现「资料先告诉助教这是什么题，助教再声称自己识别出来」的污染路径。

### 6.6 教学系统与本库的边界

| 归本库 | 归教学系统 |
|---|---|
| 考了什么、考了几次、在哪个题位、和什么同题 | 该怎么教、教到什么程度、怎么验证学会了 |
| 候选的方法步骤与候选的识别特征 | 机制说明、失效边界、可证伪检验 |
| 真题题号与缺陷清单 | 教学序列、间隔安排、掌握度判定 |

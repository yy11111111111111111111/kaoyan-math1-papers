本文件是 `/analyze` 流程之外新增的**派生统计文档**，用于快速了解概率考点分布。以下口径对理解任何数据都关键：

**1. 题号与科目归属**
- 题号统一为 `<年份>-<卷内题号>`，如 `2024-21`。
- 「概率主考点题」= 该题的第一个考点标签属于概率 48 标签集合。
- 全卷 499 题中：高数 281 / 线代 110 / 概率 108。三者相加 = 499，互斥无重叠。

**2. 数据血缘（谁派生谁）**
```
考点标注.tsv（唯一原始数据，499 行）
  ├─→ 考点标签全集.md   （223 去重标签）
  ├─→ 考点频次.md       （标签频次）
  ├─→ 题型分布.md       （题型×考点）

  ├─→ 解法.md           （每题解题路径，status 待核对）
  └─→ 本文件 + 概率/高数/线代考法统计.md + 高数方法速查.md（本文件同层）
```
- **改数据只改 `考点标注.tsv`**，其他文件是它的派生物。
- 本文件数字若与 `考点频次.md` 冲突，以 `考点频次.md`（直接由 TSV 算得）为准；本文件逐题明细若与 `解法.md` 冲突，以 `解法.md` 为准。

**3. 标签集合与模块归类**
- 概率 48 个标签已按卡点类型归类（见正文「二」）。归类是**人工判断**，非机械规则，重跑 `/analyze` 不会自动重建本文件。

**4. 更新方式**
- 新增一年真题后：先重跑 `/analyze` 更新 `考点标注.tsv` → 再手工重算本文件相应年份的行。
- 本文件**不是** `/analyze` 的产物，重跑不会覆盖它，但也不会自动更新它。

**5. 解法状态**

## 五、核心结论

1. **分布变换是概率的头号真考点**：解答题里「先求分布」（分布函数法 + 密度公式 + 混合和 + 先求分布再估计）合计约 14 题，占解答题近半。`最大似然估计` 标签过去掩盖了这一事实——多数 MLE 难题的卡点不在「写似然」，而在前置的分布推导。
2. **数字特征是第二主线**：E(X²)=D(X)+E²(X) 换算、全期望公式、混合期望合计约 14 题，其中 `E(X²)=D+E²` 单点 8 次，是选择填空最高频的数字特征套路。
3. **估计类考法约 20 题但难点集中**：最大似然 + 无偏 + 矩估计三件套年年在解答题压轴，真正的坑在「无偏需补 D(X̄)」「似然单调取边界」「截尾似然」「先求样本变换分布」四类，而非写似然本身。
4. **正态分布贯穿全卷**：线性变换、对称标准化、数字特征合计 16 次，选择填空年年出现。

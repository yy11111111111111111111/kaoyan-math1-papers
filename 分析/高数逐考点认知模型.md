# 高数逐考点认知模型（127 个考点，一个不落）

> **这份文件只干一件事**：给高数的**每一个考点**配一个「脑子里该装的结构」。
>
> 与 `高数考法与认知模型.md` 的分工：那份是**模块级**地图（考法分布、卷面落点、模块主线）；**这份是考点级**，逐条给模型。两份对着看。
> 与 `高数方法速查.md` 的分工：速查给的是**怎么做**（操作步骤）；这份给的是**为什么这么做、看到什么才想到它**。速查是手，这份是眼。
>
> **每个考点的真题题号，在 `高数方法速查.md` 的同名行里**，本文不重复列，避免两处漂移。

## 模块 1 ｜ 极限与连续（主线 A·局部化）
*10 个考点 · 58 次 · 39 题*

| 考点 | 要建立的模型 | 信号 → 首步 | 丢分处 |
|---|---|---|---|
| **泰勒公式展开**<br>S·17·6/7/4·新7 | 泰勒不是一张公式表，是**通用兑换器**：任何函数在一点附近都能换成多项式。你要装的不是展开式，是**「展开到第几阶就停」的决策规则**——阶由**分母**（或比较对象）决定，不由分子决定 | 0/0 型且分子含**加减** → 先读分母是几阶，再展分子到同阶 | 少展一阶整题错；多展一阶白算。变限积分的阶 = 被积函数的阶 **+1**（`2004-7`） |
| **等价无穷小替换求极限**<br>S·14·3/8/3·新4 | 等价替换是**乘除法的局部简化**，它的合法边界就是乘除。一旦遇到加减，替换会正好抹掉你要比的那一项。装一张 x→0 的八条表 **＋ 一条禁令** | 0/0 且各部件全是乘除因子 → 直接换；出现加减 → 立刻切泰勒 | `sin x − x` 换成 `x − x = 0`，全库最经典的错法。`1−cos x ~ x²/2` 不是 `x²`（`2006-1`） |
| **单调有界准则求数列极限**<br>A·6·2/0/4·**盲区** | 存在性与值是**两件事**：先证「跑不掉」（有界）、再证「不回头」（单调），值是最后一步也是最容易的一步。出题人考的是前两步 | `x_{n+1}=f(xₙ)` → 三步：证有界 → 证单调 → 设 a 代回解 a | 直接设极限存在解出 a 就交卷（**存在性没证 = 主要步骤没做**）；归纳法起点没验 |
| **函数极限存在与连续可导的关系**<br>B·5·4/0/1·新2 | 一条**单向链**：可导 ⇒ 连续 ⇒ 极限存在，反向全假。把三个反例焊在链上：`\|x\|`（连续不可导）、`x sin(1/x)` 补 0（连续不可导）、符号函数（极限存在不连续） | 四个命题判真假 → 逐个套链；凡是反向的，先掏反例 | 默认反向成立；忘了「可导」是比「连续」强的条件 |
| **1的无穷次幂型极限**<br>B·4·1/1/2 | `1^∞` 是**伪装的 0·∞**。取对数把它从乘方世界拉回加减世界，就变成会做的题。只装一个式子：`e^{lim v(u−1)}` | 底 →1 且指数 →∞ → 先算 `lim v·(u−1)`，最后指数化 | 直接代 1 得 1；算完指数忘了再 e 上去 |
| **等价无穷小的判定**<br>B·4·2/1/1·新1 | 「等价」= 比值极限**恰为 1**，即**同阶 且 系数为 1**。判定题实际在考「你能不能把两边都定到同一阶再比系数」——所以它其实是泰勒题 | 问「~ 是否成立」或求使等价成立的 a、n → 两边各展到主项，比系数 | 只比阶不比系数（同阶 ≠ 等价） |
| **无穷小阶的比较**<br>C·4·4/0/0 | 阶是一把**以 x^k 为刻度的尺子**，比较 = 作比取极限读刻度：0 → 高阶，∞ → 低阶，非零常数 → 同阶，1 → 等价 | 「几阶无穷小」「比…高阶」→ 作比 | 变限积分忘了 +1 阶 |
| **分段函数的连续性**<br>C·2·2/0/0 | 分段点是**唯一嫌疑点**，其余点自动连续。判据是三值相等：左极限 = 右极限 = 函数值 | 含参分段函数问连续 → 在分段点列三值相等的方程定参数 | 只算了左右极限，忘了和**函数值**比 |
| **洛必达法则**<br>C·1·0/0/1 | 洛必达是「把难算的部分求导掉」，代价是**每用一次都要重验前提**（仍是 0/0 或 ∞/∞、分母导数不为 0、求导后极限确实存在）。**能用泰勒就别用洛必达**——泰勒一步到位且不用验 | 0/0 或 ∞/∞ 且求导后明显变简单 → 用；否则改泰勒 | 求导后仍是 0/0 就无限循环；非这两型硬用 |
| **间断点的类型判定**<br>C·1·1/0/0 | 分类**只看左右极限存不存在**，函数值不参与分类。两个都存在 → 第一类（相等为可去、不等为跳跃）；有一个不存在 → 第二类（无穷/振荡） | 「x₀ 是第几类间断点」→ 先算左右极限，再看存在性 | 拿函数值参与分类（函数值只区分「可去」与「连续」） |

## 模块 2 ｜ 一元微分（主线 A·局部化）
*19 个考点 · 65 次 · 46 题 · 19 个考点里 12 个从没进过解答题*

| 考点 | 要建立的模型 | 信号 → 首步 | 丢分处 |
|---|---|---|---|
| **极值的判定**<br>S·6·3/0/3·新4 | 极值的本质是 **f′ 变号**，二阶导判别只是**变号的快捷方式**。快捷方式失效（f″=0）时退回去看变号。候选点有三种：驻点、**不可导点**、（闭区间时）**端点** | 「求极值 / 极值点个数」→ 先列全三种候选点，再逐个判变号 | 只解 `f′=0`，漏不可导点；闭区间漏端点 |
| **导数定义**<br>A·8·6/1/1·新2 | 把定义**倒过来读**：看到一个极限式，先问「它是不是某个 f 在某点的差商」。这是选择题最爱的伪装 | 极限式里出现 `f(x₀+□)−f(x₀)` 结构 → 对齐分子分母的增量 | 分子增量是 `2h`、分母是 `h`，忘了乘系数 2 |
| **导数的几何意义与切线方程**<br>A·6·0/3/3·新1 | **切线就是一阶泰勒**，点斜式只是它的写法。所以切线题永远只要两样东西：**切点坐标 + 该点导数**，其余都是包装 | 切线/法线/垂直/与轴的截距 → 先定切点，再定 `f′(x₀)` | 把已知直线的斜率当成切线斜率；切点纵坐标要**回代原曲线**，不能用直线上的点（`2004-1`） |
| **函数凹凸性**<br>A·7·6/0/1·新1 | f″ 的符号 = **曲线相对切线和弦的位置**。装成一幅图而不是一句定义：下凹（f″>0）时曲线**在弦下方、在切线上方**。这一句能直接翻成不等式，是选择题的通用解法 | 出现 f″ 的符号，或问曲线与直线的高低 → 立刻翻成位置关系 | 凹凸的方向记反（国内教材与部分资料定义相反，认准 f″ 符号，别认「凹凸」二字） |
| **拐点的判定**<br>B·4·3/0/1·新1 | 与极值**完全同构，只差一阶**：候选点（f″=0 或 f″ 不存在）+ **变号**。两行结构一模一样，记一个就够 | 「拐点个数」→ 找候选点，逐个判 f″ 是否变号 | `f″=0` 就当拐点。多项式看因子重数：**奇次变号、偶次不变** |
| **隐函数求导**<br>B·4·0/2/2 | 「y 是 x 的函数」这件事必须**写在笔尖上**：每次对含 y 的项求导都要乘 y′。模型就是「y 后面永远拖着一个 y′」 | 方程给的是 `F(x,y)=0` → 两边对 x 求导，含 y 的项乘 y′ | 漏乘 y′；求出 y′ 后要判驻点时忘了 y 也在变（`2014-16`：y=0 那一支要代回原方程排除） |
| **斜渐近线求法**<br>B·5·4/1/0·新1 | 两个极限**一个都不能少**：k=lim y/x 存在，且 b=lim(y−kx) 存在。有理分式**直接做多项式除法更快**（商的一次部分就是渐近线） | 「求斜渐近线 / 渐近线条数」→ 有理式先除法，非有理式才算两个极限 | 只算出 k 就下结论；`x→+∞` 与 `x→−∞` 没分开算 |
| **参数方程求二阶导数**<br>B·5·**0/5/0**·新2 | 二阶导**不是「再对 t 求一次导」**，是「对 dy/dx 求 **x** 的导数」。所以要**再除一次 dx/dt**。写死：`d²y/dx² = [d/dt(dy/dx)] ÷ (dx/dt)` | x=x(t), y=y(t) 求二阶导 → 先算 dy/dx，再套上式 | 忘了第二次除以 dx/dt（这是本考点唯一的错法）。**5 次全在填空 → 只练速度，不出解答题** |
| **函数单调区间与极值**<br>B·3·0/0/3 | 不要试图一眼看出单调性。**机械流程**：用 f′=0 与 f′ 不存在的点把定义域切开 → 每段取一个测试点定号 → f′ 变号处即极值 | 「讨论单调性 / 求极值」→ 先切区间 | 切点漏了不可导点；区间端点的开闭写错 |
| **分段函数分段点可导性**<br>C·5·5/0/0·新1 | 左右导数必须**用定义算**，不能用两边导函数在该点取极限代替——导函数可能不连续。先验连续（不连续必不可导） | 分段点问可导 → ① 验连续 ② 用定义算左右导数 | 用 `lim f′(x)` 代替 `f′(x₀)` |
| **导函数单调性的充分必要条件**<br>C·1·0/0/1·新1 | 把「导数的性质」翻译成**不含导数的差商语言**：f′ 严格增 ⇔ 任意 x₁<x₂<x₃ 时差商递增。必要性用两次拉格朗日；充分性令 x₂ 趋于两端取极限，再加细把 ≤ 提为 < | 结论是「⇔」且一边含 f′ 一边只含 f → 两个方向分别证 | 只证一个方向；充分性里 ≤ 没提成 < |
| **凹凸性与弦的位置关系**<br>C·2·2/0/0·新1 | 就是「函数凹凸性」的**不等式形态**：f″≥0 ⇒ `f(x) ≤ 线性插值`（弦不低于曲线）且 `f(x) ≥ f(x₀)+f′(x₀)(x−x₀)`（切线不高于曲线）。两个不等号方向都由 f″ 一个符号决定 | 选项里出现 f 与一次式的比较 → 查 f″ 符号 | 两个不等号方向记混 |
| **曲线渐近线的条数**<br>C·3·3/0/0 | 三类**分开数、不合并**：铅直（分母零点，**先约分排除可去间断**）、水平（`x→+∞` 与 `x→−∞` **分开算**）、斜（该侧无水平渐近线时才查） | 「共有几条渐近线」→ 列三行分别数 | 可去间断点当成铅直渐近线；水平只算一侧 |
| **参数方程求导**<br>C·1·1/0/0·新1 | `dy/dx=(dy/dt)/(dx/dt)`，要求 `dx/dt≠0`；结果**仍是 t 的函数**，代点前先化简 | 给出参数式求某点斜率 → 先求出 t₀ 再代 | 直接把 t 当 x |
| **参数方程的切线**<br>C·1·0/0/1 | 切线斜率仍是 `(dy/dt)/(dx/dt)`；与坐标轴交点由令 x=0 或 y=0 解出 | 「切线与坐标轴围成…」→ 先写切线再求截距 | 截距算成坐标 |
| **含参极限定义的分段函数**<br>C·1·1/0/0 | 两步走：**先把极限算成显式表达**（常得到 max/min 形式），再当普通分段函数处理连续与可导 | 函数由一个含参极限定义 → 先分区间求极限 | 直接对含极限的式子求导 |
| **垂直直线的斜率关系**<br>C·1·0/1/0 | 垂直 ⇔ 斜率乘积 = −1。切线垂直于已知直线时，**先由此定出 f′(x₀)**，再反解切点 | 「切线垂直于 …」→ 先定 f′ 的值 | 把已知直线的斜率当成切线斜率 |
| **导数符号与函数单调性**<br>C·1·1/0/0 | **导数条件要先看它到底是谁的导数**：`f·f′>0` 只说明 `(f²)′>0`，即 **f² 单调增**，推不出 f 本身单调 | 条件里出现 f 与 f′ 的乘积 → 先问「这是谁的导数」 | 直接当成 f 单调 |
| **微分与增量的大小比较**<br>C·1·1/0/0 | Δy 沿**曲线**、dy 沿**切线**。f″>0（曲线在切线上方）时 Δx>0 ⇒ **Δy > dy**。两个不等号分别由 f′ 与 f″ 的符号给出 | 比较 Δy、dy、0 的大小 → 查 f′ 定正负、查 f″ 定谁大 | 只看 f′ 不看 f″ |

## 模块 3 ｜ 中值定理与证明（主线 A·局部化）
*10 个考点 · 31 次 · 21 题 · **30 次落在解答题，19 道职能为证明** · 2023–2026 连续 4 年占一个解答位*

> **统计事实**：31 次标注里 30 次落在解答题、19 道职能为证明；在 2023–2026 这 4 个新卷型样本中各占一个解答位（2021 是唯一例外）。<br>> **教学判断（非统计字段）**：在当前人工分析中，这类题对**关键构造与定理选择**的依赖较强——辅助函数选错，后续步骤无法补救。<br>> 下面十条里，前三条是总开关，后七条是具体形态。

| 考点 | 要建立的模型 | 信号 → 首步 | 丢分处 |
|---|---|---|---|
| **辅助函数的构造**<br>B·4·0/0/4·新1 | **整个模块的总开关**。证明题不是想出来的，是**反推**出来的：待证式 → 移项成「某个东西 = 0」→ 问「**谁的导数长这样**」→ 那就是 F。<br>最常用的一招：待证 `f′(ξ)+g(ξ)f(ξ)=0` → 乘积分因子 `e^{∫g}` → `[f·e^{∫g}]′=0` → F 就出来了 | 结论形如 `∃ξ, 某表达式=0` → 移项、认导数 | 造出 F 却忘了验它的三个条件 |
| **罗尔定理的重复使用**<br>B·4·0/0/4·新1 | **用几层罗尔，由结论里的最高阶导数决定**：出现 f′ 用一层，出现 f″ 用两层。每层的输入是上一层产出的**两个**零点 | 结论含 f″ 或更高阶 → 先想办法造出两个 F′ 的零点 | 只用一层就想得到 f″；两个 ξ 不说明来源 |
| **拉格朗日中值定理分区间使用**<br>A·5·0/0/5·新1 | 一个区间不够用，就**切成两段各用一次，再联立消掉中间的函数值**。切点通常就是题目特意给你的那个特殊点（中点、零点、给了函数值的点） | 结论里出现两个差商，或题目给了区间内某点的值 → 在 [a,c]、[c,b] 各用一次 | 只在整个区间用一次，凑不出结论就卡死 |
| **泰勒公式证明不等式**<br>B·3·0/0/3·新1 | 不等式 = **展开式 + 余项符号**。展开点取**端点或中点**，余项符号由 `f⁽ⁿ⁺¹⁾` 的上下界给出。判据：**结论里出现二阶导或「中点」，就是泰勒不是单调性** | 证不等式且条件给了 f″ 的界 → 在中点或端点展开到带拉格朗日余项 | 展开点选错（选了任意点导致余项符号定不了） |
| **零点定理构造辅助函数**<br>B·3·0/0/3·新1 | 要证「**存在一点使等式成立**」而结论**不含导数**时，用零点定理而不是中值定理：`F=左−右`，找出 F 在两点异号 | 结论是 `∃ξ, f(ξ)=某值` 且不含 f′ → 造 F 找异号点 | 上来就找中值定理 |
| **方程实根个数的讨论**<br>B·3·1/0/2 | **存在性和唯一性是两件事**：零点定理定**存在**，单调性（f′ 符号）定**唯一**。含参时按 f′ 的零点个数分情形，再比较各极值的符号 | 「有几个实根」→ 先分单调段，每段至多一根，再数每段端点值的符号 | 只证存在没证唯一；含参时只讨论了一种情形 |
| **夹逼准则求极限**<br>B·3·0/0/3 | 夹逼是「**算不出就围起来**」。关键不在会用，在**放缩的尺度**——上下界必须同极限，放太松就夹不住 | 通项是 n 项的和且每项难算 → 用最大项和最小项各乘 n 做上下界 | 放缩后上下界极限不等，白放 |
| **拉格朗日中值定理证明不等式**<br>C·3·0/0/3 | 把不等式**改写成差商**，差商 = f′(ξ)，再用 **f′ 的单调性**把未知的 ξ 换成已知的端点 | 不等式两边能凑成 `[f(b)−f(a)]/(b−a)` → 用拉格朗日 | 得到 f′(ξ) 后不知道怎么处理 ξ（忘了用 f′ 单调） |

| **二重积分的比较**<br>C·2·2/0/0 | 常先用格林公式化成二重积分再比；**被积函数的零线常常就是选项里的那条曲线** | 比较几个曲线积分/二重积分的大小 → 先化到同一形式，再看被积函数符号 | 真去算 |
| **二重积分取最值的区域**<br>C·1·0/0/1·新1 | 当被积函数在平面上变号、且 D 可自由选取时，答案是**使被积函数非负的最大区域**，D 的边界即被积函数的零线。（**适用条件**：被积函数变号 + D 无其它约束；本库仅 1 个样本 2021-20） | 「求 D 使 ∬ 最大」→ 解被积函数 = 0 | 去猜几个候选区域挨个算 |
| **二重积分的分部积分与累次积分**<br>C·1·0/0/1 | 被积含 `f_xy` 时，**先对一个变量积分，用分部把导数转移到多项式因子上**，边界条件用来消掉边界项 | 被积含未知函数的混合偏导 → 先积一次再分部 | 试图先求出 f |
| **二重积分的定义与和式极限**<br>C·1·1/0/0 | 双重和式凑成 `(1/n²)ΣΣf(i/n, j/n)`：**1/n² 是面积元、i/n 与 j/n 是两个方向的分点** | 极限里出现双重求和 → 凑模板 | 把 1/n² 提错 |

## 模块 8 ｜ 曲线曲面积分与场论（主线 B·累积化）
*16 个考点 · 59 次 · 43 题 · **在 2021、2023–2026 这 5 个有效新卷型样本中，19/20 积分位 5/5 出现**（样本内观察，n=5，不构成对未来年份的概率判断）*

> **统一图景（先装这个，再看下面 16 条）**：格林、高斯、斯托克斯**三条公式说的是同一件事**——「**边界上的积分 = 内部的积分**」，方向约定都是「让内部保持在左手边／外侧为正」。<br>格林：1 维边界 → 2 维内部；高斯：2 维边界 → 3 维内部；斯托克斯：1 维边界 → 2 维曲面。<br>**三问判定树**（⚠️ **适用范围**：只覆盖「用格林/高斯/斯托克斯把边界积分换成内部积分」这一条补域路线，**不覆盖**参数化直接计算、路径无关换路径、对称性化简、第一类↔第二类转换等其它路线；先判断题目是不是走这条路，再进树）：① 封闭吗？② 能补成封闭吗？③ 里面有奇点吗？

| 考点 | 要建立的模型 | 信号 → 首步 | 丢分处 |
|---|---|---|---|
| **高斯公式补面法**<br>S·7·0/1/6·**主考 6**·新1 | 补面 = **先加后减**：加一块平面凑成闭曲面 → 对整体用高斯 → **再把补的那块单独算出来减掉**。补哪块的判据：**选垂直于坐标轴的平面**，它上面的积分最好算 | 曲面不封闭 → **动笔前先在草稿写下「补 Σ₀，最后要减」** | 忘了减补面；补面的**方向**取错（补面的外法向要与整体一致，单独算时方向常与它自身自然方向相反） |
| **曲线积分与路径无关的条件**<br>A·6·2/1/3 | **三件事其实是一件事**：路径无关 ⇔ 存在势函数 ⇔ `∂P/∂y=∂Q/∂x`（单连通域内）。认出其中任一个，另两个立刻可用——换一条好走的折线路径，或直接求势函数作差 | 验出 `∂P/∂y=∂Q/∂x` → 立刻换成沿坐标轴的折线路径 | 区域**不单连通**（有洞）时仍下结论路径无关 |
| **曲面积分的对称性**<br>A·6·0/3/3 | 与三重积分同构：**曲面关于坐标面对称 + 被积函数关于该变量为奇 ⇒ 积分为 0**。第二类曲面积分还要额外考虑侧的方向 | 拿到曲面积分 → **先查对称性**再选公式 | 第二类曲面积分用对称性时忘了方向也要对称地翻转 |
| **格林公式化曲线积分为二重积分**<br>A·6·1/1/4·新1 | `∮P dx+Q dy = ∬(∂Q/∂x − ∂P/∂y)dxdy`，**要求闭合 + 单连通**。它的价值不在公式本身，在于把一个难算的线积分**换成一个好算的面积分** | 平面闭曲线积分 → 先验闭合与单连通，再套 | 方向不是正向（逆时针）时忘了整体反号；区域内有奇点仍直接套 |
| **补线法计算曲线积分**<br>A·4·0/1/3·新2 | 与补面法**完全同构**：补一段线段凑闭 → 格林 → 减掉补的那段。补线的判据：**选水平或竖直线段**，`dx` 或 `dy` 为 0，积分最好算 | 平面曲线不闭合 → 补线段，写下「最后要减」 | 忘了减；补的线段方向与整体正向不一致 |
| **斯托克斯公式**<br>B·4·0/2/2·新1 | **空间版的格林**：`∮_L = ∬_S(∇×F)·n dS`。选哪张曲面 S 是自由的——**选最好算的那张**（常是平面）。方向用**右手定则**：右手四指沿 L 的方向，拇指指向 n | 空间**闭**曲线积分且旋度好算 → 斯托克斯；否则参数化 | 右手定则用反导致整体符号错；选的曲面边界不是 L |
| **空间曲线积分的参数化直接计算**<br>B·4·0/2/2·新1 | **能参数化就别上公式**。柱面与平面的交线是最常见的形态，参数化后是一个普通定积分 | 曲线是柱面与平面的交线，或给了参数式 → 直接参数化 | 参数范围与方向定错（方向错则整体反号） |
| **高斯公式**<br>B·4·0/2/2·新2 | 闭曲面 + 外侧 ⇒ `∯ = ∭ div F dV`。**先算散度**——散度是常数时整个积分就退化成「常数 × 体积」，这是出题人最爱的构造 | 曲面**已经封闭** → 直接算 `div F`，看是不是常数 | 内侧忘了反号；区域内有奇点仍直接套 |
| **格林公式挖奇点法**<br>B·3·0/0/3·新2 | 挖的那条小闭曲线要**与分母同型**（分母是 `x²+4y²` 就挖椭圆 `x²+4y²=ε`），这样小曲线上**分母变成常数**，可以直接参数化算出，且**结果与 ε 无关** | 被积分母能在区域内为 0 → 挖一条同型小曲线 | 挖成圆而分母是椭圆型，算不出来；忘了大小两条边界的方向相反 |
| **第一类曲面积分的计算**<br>B·3·0/1/2 | 第一类**与方向无关**（是「质量」不是「通量」），所以可以**先用对称性把被积函数化简**，常能化成常数，剩下的就是求面积。`dS=√(1+z_x²+z_y²)dxdy` | 积分号是 `∬ f dS`（不带 dydz 之类）→ 先查对称性再投影 | 与第二类混淆而去考虑方向；忘了根号里的 1 |
| **旋度与散度的计算**<br>C·3·0/3/0·新1 | 记法：`div F = P_x+Q_y+R_z`（标量），`rot F = ∇×F`（向量，按行列式展开）。<br>**一条恒等式能一步出结果：`div(rot F) ≡ 0`** —— 遇到嵌套直接写 0 | 出现 `div(rot F)` 或 `rot(grad f)` → 直接写 0 | 老实展开算半页 |
| **第二类曲面积分化为二重积分**<br>C·3·1/2/0·新1 | **合一投影法**：曲面 `z=z(x,y)` 取上侧时 `dydz=−z_x dxdy`、`dzdx=−z_y dxdy`，全部化到 `dxdy` 上；**下侧整体反号**。或用方向余弦之比 `cosα:cosβ:cosγ` | 三项 dydz+dzdx+dxdy 型 → 先把曲面写成 z=z(x,y)，再合一投影 | 侧取反了整体差一个负号（`2004-3`：正向与 dx 的负号**叠加**，两处都要算） |
| **平面曲线积分的参数化直接计算**<br>C·2·0/2/0 | 曲线给了参数式或显式就直接代，`dx`、`dy` **同步**用参数表示。**先定好参数范围与方向** | 曲线是圆、椭圆、直线段 → 直接参数化 | 方向定反（整体反号） |
| **第一类曲线积分的计算**<br>C·2·0/2/0 | 与方向无关。空间曲线可用**轮换对称性**——曲线关于 x,y,z 轮换对称时，`∮x ds=∮y ds=∮z ds`，常能不算积分直接出结果 | `∮ f ds` 且曲线对称 → 先试轮换对称 | 硬参数化算（能算但慢一倍） |
| **第二类曲线积分的符号判定**<br>C·1·1/0/0 | 两条捷径：① 被积函数在曲线上**为常数**时 `∫f dx = 常数 ×(x_终−x_始)`，符号由起终点位置直接定；② 被积为**全微分**时闭曲线积分为 0 | 选项只问符号 → 先看被积在曲线上是不是常数或全微分 | 去算积分值 |
| **高斯公式挖奇点法**<br>C·1·0/0/1 | 与格林挖奇点同构：闭曲面内含奇点时挖一个**小球面**，原积分 = 小球面上的积分；小球面上分母为常数，**结果与半径无关** | 被积分母在闭曲面内为 0 → 挖小球 | 忘了两个曲面方向相反 |

## 模块 10 ｜ 微分方程（主线 C·结构化）
*9 个考点 · 42 次 · 31 题 · **新卷型里很少单独成题**，几乎都是「先化成 ODE 再解」*

> **本模块的模型总纲**：**解之前先分类，分类只看形状。**走错分类，后面全错。所以练的不是解方程，是**认型**。

| 考点 | 要建立的模型 | 信号 → 首步 | 丢分处 |
|---|---|---|---|
| **一阶线性微分方程通解公式**<br>S·8·1/3/4·新1 | 公式 `y=e^{−∫P}[∫Q·e^{∫P}dx + C]` 只有在**标准形 `y′+P(x)y=Q(x)`** 下才成立。**先化标准形**（y′ 的系数必须是 1）是唯一的前置动作 | 方程能整理成 `y′+Py=Q` → 先把 y′ 的系数除掉 | 没化标准形就套公式；`∫P` 的积分常数重复引入 |
| **二阶常系数非齐次线性微分方程**<br>S·8·1/4/3·新1 | 通解 = **齐次通解 + 一个特解**，两半分开做。特解按右端形状待定，**核心规则只有一条：与齐次解重复就乘 `x^k`，k = 相应根的重数**——这是本模块最集中的丢分点 | 右端非零 → 先解特征方程，**再看右端的 λ（或 α±βi）是不是特征根** | 忘了乘 `x^k`；右端是 `Pₙ(x)e^{αx}` 时特解只设了 `Ce^{αx}` 而不是 `Qₙ(x)e^{αx}` |
| **二阶常系数齐次线性微分方程**<br>A·6·2/3/1·新1 | 特征方程 `r²+pr+q=0` 的**三种根对应三种通解**，记成一张三行表：两不等实根 `C₁e^{r₁x}+C₂e^{r₂x}`；重根 `(C₁+C₂x)e^{rx}`；共轭复根 `e^{αx}(C₁cos βx+C₂sin βx)` | 齐次方程 → 写特征方程，判别式定型 | 重根忘了那个 x；复根忘了 `e^{αx}` 因子 |
| **由解的结构反推微分方程通解**<br>C·5·3/2/0 | **反向读那张三行表**：给几个解 → **解之差是齐次解** → 由齐次解的形状反推特征根 → 反推特征方程 → 反推原方程。这是「解的结构」这个概念的唯一考法 | 「已知 y₁,y₂,y₃ 是…的解」→ 先两两作差 | 直接把给出的解当齐次解（没作差） |
| **可分离变量微分方程**<br>C·4·0/4/0·新1 | `dy/dx=f(x)g(y)` ⇒ 两边分开积分。**注意 `g(y)=0` 给出的常数解可能是漏掉的解** | 能把 x 与 y 完全分到两边 → 直接分离 | 漏掉 `g(y)=0` 对应的解 |
| **变量代换求解微分方程**<br>C·3·0/3/0·新1 | 分类树走不通时的**统一出路**：齐次型令 `u=y/x`；`y′=f(ax+by+c)` 令 `u=ax+by+c`（**注意 `u′=a+b y′`**）；伯努利型令 `u=y^{1−n}` | 方程里反复出现某个组合 → 就令它为 u | 换元后 `u′` 与 `y′` 的关系写错 |
| **可降阶的二阶微分方程**<br>B·3·0/0/3·新2 | **两种缺项，两种换元，绝对不能混**：<br>缺 y（`y″=f(x,y′)`）→ 令 `p=y′`，**p 视为 x 的函数**，降为一阶；<br>缺 x（`y″=f(y,y′)`）→ 令 `p=y′`，**p 视为 y 的函数**，`y″=p·dp/dy` | 二阶方程里少了 y 或少了 x → 先判缺哪个 | 缺 x 时仍把 p 当 x 的函数（`y″` 写成 `dp/dx`），后面全错 |
| **欧拉方程求解**<br>B·3·0/2/1·新2 | 认型信号极明确：**`x²y″` 与 `xy′` 同时出现**（幂次与阶数配对）。令 `x=eᵗ` 化成常系数：`x²y″→D(D−1)y`、`xy′→Dy` | 看到 `x²y″+axy′+by` → 立刻换 `x=eᵗ` | `x²y″` 直接写成 `D²y`（漏了 `−D`） |
| **微分方程的几何与物理应用**<br>C·2·0/0/2 | 应用题的**唯一难点是列方程**，不是解方程：把几何条件（切线截距、法线长、面积）或物理定律（牛顿第二定律）翻译成含 `y′` 的等式。<br>两条实用技巧：物理题**先做单位换算**；求总位移用 `v dv/ds` 可避开求 `v(t)` | 「求满足…性质的曲线」→ 先画图，把条件写成含 y′ 的式子 | 列方程时把变量与常量搞混；求出通解**忘了代初值定常数** |

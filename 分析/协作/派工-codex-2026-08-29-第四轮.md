## BL-1 · B1 · 显式函数的「求切线/法线」既无 cell，A12 也接不住

**载体 2004-1**：曲线 y=ln x 上与直线 x+y=1 垂直的切线方程。
正解：所求斜率 k = −1/(−1) = 1 ⇒ 解 f′(x)=1/x=1 得切点 (1,0) ⇒ 切线 y = x−1。

**两重缺陷**：
1. 一级路由第二轴有「求切线法线」这个取值，但六格里含切线的**只有「参数式 · 求导或切线」**
   ⇒ 显式函数的切线题**无格可落**。
2. 即便越格取 A12，其 `applies_when: [已知切点与该点导数值]` 在本题**不成立**——切点未知，
   须先解 `f′(x)=k` 反求。全族没有任何 action 提供「由给定斜率/几何条件反求切点」这一步。

**做**：新增 cell「显式 · 求切线法线」并挂上相应 action；把 A12 的 `applies_when` 拆为
「已知切点」与「已知斜率/几何条件，先解 f′(x)=k 定切点」两支（后者需要一条求解 local_operation）。
注意 A12 现在的 `eligible_cells` 只有 `[参数式]`（integrator 早先删掉了错误的「判形态」），
新增格后需同步。

> ⚠️ **归属问题不要自己定**：同类的 2015-16 / 2023-17 / 2012-18 是「由切线条件反求 f」，
> 实际要建并解 ODE（如 2023-17：切线在 y 轴截距 = x ⇒ `y − x y′ = x`）。
> 它们按主考点归本族，但解法主体在 `calc.ode`。
> **请只在本族补「反求切点」这一步，把「是否该给 calc.ode 加 boundary_note / 是否该改归属」
> 写进报告的 open_questions 交 integrator 裁定**，不要自行改 scope 或动 ODE 族。

## BL-2 · B1 · 缺「凸性 ⇒ 弦/切线位置关系」这条决定答案的分支

**载体 2014-2**（TSV 主考点即「凹凸性与弦的位置关系」）：
`g(x)=f(0)(1−x)+f(1)x` 是过 (0,f(0))、(1,f(1)) 的弦。
`f″≥0` ⇒ f 在 [0,1] 上凸 ⇒ ∀x∈[0,1]，`f(x)=f((1−x)·0+x·1) ≤ (1−x)f(0)+x f(1)=g(x)`。

**另外两道**：2007-5（f 凸 ⇒ 差分 `f(n+1)−f(n)` 关于 n 单调不减；`u₁<u₂` ⇒ 该差 ≥ `u₂−u₁>0`
⇒ `u_n ≥ u₁+(n−1)(u₂−u₁) → +∞` ⇒ 发散）、2026-3（TSV 主考点同 2014-2）。

**现有 action 无一能产出该结论**：A8 的 `terminal_when` 是「各区间凹凸性已判定」——
**判完凹凸就终止，不含「凸 ⇒ 位于弦下方 / 切线上方」这一步**；
A11（泰勒）的 `applies_when` 要求「各阶导数存在且易算」且读的是**局部**性态，
而 2014-2 的 f 只知 `f″≥0`（抽象），无展开可读。

**做**：判形态格新增 action（审查方建议命名 A14）：
「凸性的**整体**不等式：凸 ⇒ 曲线在弦下方、在任一切线上方；割线斜率关于端点单调」。
`failure_boundary` 须写明**需在区间上 f″ 定号**（与 B1「f′(x₀)>0 不蕴含邻域单调」的
点/区间之别配套——这是本族反复出现的错法）。

## BL-3 · B1 · 参数式在 x′(t) **不存在**处无 action

**载体 2023-3**：`x = 2t+|t|`，`y = |t|sin t`。`x′(t)` 在 t=0 处**不存在**（右 3、左 1）。
A4 / A4b 的 `applies_when` 均含 `x′(t)≠0`，直接不成立；
`fallback_policy` 写的是「x′(t)=0 → 该参数值单独讨论」——**既未覆盖「不存在」，
「单独讨论」也不是一个 action**（无 mechanism、无 terminal_when）。

合法路线是**分段消参化显式**：
`t≥0`：x=3t ⇒ `y=(x/3)sin(x/3)`（x≥0）；`t<0`：x=t ⇒ `y=−x sin x`（x<0）。
`f′(0⁺)=f′(0⁻)=0` ⇒ f′(0)=0 存在且 f′ 连续；`f″(0⁺)=2/9`、`f″(0⁻)=−2` ⇒ f″(0) 不存在。

「消参化为显式后再求导」目前在 `route_universe`（第 600 行）里被声明为路线之一，
但只以 `excluded_candidates` 的 `dominated_not_excluded`（第 608 行）存在、
**没有对应 action** ⇒ 事实上不可执行。

**做**：把消参升为正式 action（**含分段消参分支**），并把 A4/A4b 的 failure_boundary
由「x′(t)=0」扩为「**x′(t)=0 或不存在**」；`fallback_policy` 同步。

## BL-5 · B4 · A2/A5 的 continuation 悬空到已冻结的 limit 族

A2 的 `boundary_note` 把差商极限交给 `calc.limit.method-selection`，
`terminal_when` 要求「该极限已求出」；A5 的机制就是把分段点导数拆成**左右**导数，产出**单侧**差商极限。
而接收方 `calc.limit.method-selection`（**frozen**，`partially_verified`）的 `scope.exclusions`
明文写着「单侧极限的分支讨论 / 含绝对值或取整的分段讨论（**尚未纳入**，见 open_gaps）」。

scope 内 2018-1（四个含 |x| 的选项）、2019-2（x|x| / x ln x 分段）、2023-3（|t|）、
2016-4（按 `1/(n+1)<x≤1/n` 取整式分段）产出的极限**全部落在这一类**。

**做**：在 A2 的 `boundary_note` **与可执行字段**中声明：
**单侧 / 含绝对值 / 含取整的差商极限由本族自理**（并给出对应的 `local_operation`），
只把 limit 族 scope 内的极限外送。

  A10 的候选集实际堵住了它，但 guard 正文与 A10 不同步。建议 condition 补「**且 f 在该点连续（点在曲线上）**」。

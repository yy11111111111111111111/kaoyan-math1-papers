### BL-1 · B1 · 2013-19 在本族 router 下无 action 接收

题：直线 L 过 A(1,0,0)、B(0,1,1)，绕 z 轴旋转一周得 Σ，求 Σ 的方程。
L 的参数式 `(1−t, t, t)`，**不含于任何坐标面**。

`A1.applies_when = [母线为坐标面内的曲线, 旋转轴为某个坐标轴]` 第一条不满足；
`guard#7` 进一步明写「母线不在坐标面内…A1 的口诀不适用」，其 explanation 还把这种情形
推给「坐标变换，超出本族 scope」——**而 2013-19 就在本族 8 题清单里**。

正确路线（消参法 / 到轴距离不变）：`z = z₀` 且 `x²+y² = x₀²+y₀²`，消 t 得
**`x²+y² = (1−z)² + z² = 2z²−2z+1`**。（integrator 已复算：t=1/3 时母线点 (2/3,1/3,1/3)，
`x₀²+y₀² = 5/9`；`2z²−2z+1|_{z=1/3} = 5/9` ✓）

该路线目前在 `excluded_candidates` 里被标 `duplicate_mechanism`——**这是理由误用**：
一条在两道题上唯一可行的路线，不是 A1 的冗余表述。

**做**：把它升为正式 action（审查方建议命名 A1b），`applies_when` 至少覆盖
「轴为坐标轴、母线为一般空间曲线」；同步 `guard#7` 的 explanation（删掉「超出本族 scope」）。

### BL-2 · B1 + B4 · 2025-20 同样无 action 接收，且 B6 宣布该情形 scope 外

题：Σ 由直线 `{x=0, y=0}`（z 轴）绕直线 `(x,y,z)=(t,t,t)` 旋转一周得到。
**轴是 x=y=z，不是坐标轴** ⇒ `A1.applies_when` 第二条不满足。

**`B6` 把这种情形判为 `out_of_scope`，而 2025-20 就在 scope 清单里——两处直接冲突。**

**做**：二选一并在报告里说明理由——

### BL-3 · B2 · A2 的 terminal 语义被反例击穿（消元得到的是投影的**超集**）

`A2` 的 followup 第二步写「投影柱面与该坐标面联立，**即为**投影曲线」，
`terminal_when` = 「投影曲线的方程组已写出」。

反例：`C = { x²+z²=1, y²+z²=1 }`。按 A2 消 z：两式相减得 `x²−y²=0`，
与 z=0 联立给出两条**完整直线** y=±x。
真实投影：`z∈[−1,1]` ⇒ `x=±√(1−z²)`、`y=±√(1−z²)`，即 `{(x,y): x²=y², |x|≤1}`，是四条**线段**。
分离点 (2,2)：满足 `x²=y²`，但回代需 `z²=1−4=−3`，无实解。

缺的是一条 necessary guard：**消元后必须补回被消变量的实解存在条件**（如 `z²=1−x² ≥ 0`）。
现有 `guard#2` 只防「令 z=0」（B4 方向），没防这个方向。

**做**：给 A2 补该 guard 与对应 boundary（审查方建议 B7），
witness 用上述构造（`constructed_counterexample`）；
并同步该 cell 的 `counter_witness_search`——它现在写着
`{ target: "A2 在正确消元后是否仍可能出错", search_result: not_found }`，**已被本反例证伪**。
⚠️ 按 L-3，「补回值域约束」这一步必须进 A2 的 `local_operation`，不能只写在 note 里。

# 2004

## 2004-1（填空）

status: 待核对

- **切入点**：切线与 x+y=1 垂直 ⇒ 斜率为 1。
- **关键步骤**：y′=1/x=1 得切点 x=1，y=ln1=0，切线 y=x−1。
- **易错处**：垂直是斜率乘积为 −1，直线 x+y=1 的斜率是 −1 不是 1；求得切点后要回代原曲线取纵坐标，不能用 x+y=1 上的点。

## 2004-2（填空）

status: 待核对

- **切入点**：令 t=eˣ 把 f′(eˣ)=xe⁻ˣ 换成 f′ 关于自身变量的表达式。
- **关键步骤**：x=ln t ⇒ f′(t)=ln t/t，积分得 f(t)=½ln²t+C；由 f(1)=0 得 C=0，故 f(x)=½ln²x。
- **易错处**：容易把 f′(eˣ)=xe⁻ˣ 直接当成 f′(x)；换元后 e⁻ˣ=1/t 不要漏。

## 2004-3（填空）

status: 待核对

- **切入点**：非闭曲线且区域不封闭，直接参数化。
- **关键步骤**：x=√2cosθ、y=√2sinθ，θ 从 0 到 π/2，代入 ∫x dy−2y dx 化为定积分。
- **易错处**：「正向」在第一象限的一段指 θ 增大方向；被积表达式中 −2y dx 的负号与 dx=−√2sinθdθ 的负号会叠加。

## 2004-4（填空）

status: 待核对

- **切入点**：欧拉方程，令 x=eᵗ（x>0）。
- **关键步骤**：x²y″→D(D−1)y、xy′→Dy，方程化为 y″+3y′+2y=0，特征根 −1、−2，回代 t=ln x 得 y=C₁/x+C₂/x²。
- **易错处**：x²y″ 对应 D(D−1) 而不是 D²；系数 4x·y′ 提供的是 4D，与 D(D−1) 合并后一次项系数为 3。

## 2004-5（填空）

status: 待核对

- **切入点**：用 AA*=|A|E 把 A* 消掉。
- **关键步骤**：先算 |A|=3，A*=3A⁻¹；ABA*=2BA*+E 两边右乘 A 并整理为 (A−2E)B·|A|=A，取行列式解 |B|。
- **易错处**：矩阵不可交换，整理时必须保持左右顺序；|A*|=|A|ⁿ⁻¹ 这类公式此处用不上，硬套会走偏。

## 2004-6（填空）

status: 待核对

- **切入点**：指数分布 D(X)=1/λ²，故 √D(X)=1/λ。
- **关键步骤**：P{X>1/λ}=e^{−λ·(1/λ)}=e⁻¹。
- **易错处**：把 D(X) 记成 1/λ；答案与 λ 无关是本题的设计点，若出现 λ 说明算错。

## 2004-7（选择）

status: 待核对

- **切入点**：三个变限积分都是 x→0⁺ 的无穷小，用被积函数的等价无穷小定阶。
- **关键步骤**：α~x（一阶）；β=∫₀^{x²}tan√t dt，被积 ~√t，积出 ~⅔x³（三阶）；γ=∫₀^{√x}sin t³dt~¼x²（二阶）。故排序 α、γ、β。
- **易错处**：定阶要看积分后的阶，不是被积函数的阶；上限是 x²、√x 时阶数会被放大或压缩。

## 2004-8（选择）

status: 待核对

- **切入点**：f′(0)>0 只给出 x=0 处的局部信息，用导数定义的保号性。
- **关键步骤**：lim[f(x)−f(0)]/x>0 ⇒ 存在 δ，x∈(0,δ) 时 f(x)>f(0)。选 C。
- **易错处**：f′(0)>0 推不出 f 在 (0,δ) 上单调增——那需要 f′ 在整个邻域为正，题目只给一点。A、B 是标准陷阱。

## 2004-9（选择）

status: 待核对

- **关键步骤**：若 lim na_n=λ≠0，则 a_n~λ/n，与调和级数同敛散 ⇒ 发散。选 B。

## 2004-10（选择）

status: 待核对

- **切入点**：F(t) 是二次积分，先交换积分次序化成单积分再求导。
- **关键步骤**：区域 y≤x≤t、1≤y≤t，换序得 F(t)=∫₁ᵗdx∫₁ˣf(x)dy=∫₁ᵗ(x−1)f(x)dx，故 F′(t)=(t−1)f(t)，F′(2)=f(2)。

## 2004-15（解答）

status: 待核对

- **切入点**：把不等式改写成 (ln²b−ln²a)/(b−a)>4/e²，左端是 f(x)=ln²x 的差商。
- **关键步骤**：拉格朗日中值定理给出差商=f′(ξ)=2lnξ/ξ，ξ∈(a,b)⊂(e,e²)；再证 g(x)=2lnx/x 在 (e,e²) 上大于 4/e²——g 在 x=e 处取最大、在 x=e² 处取 4/e²，且单调减，故 g(ξ)>g(e²)=4/e²。
- **易错处**：g 在 (e,e²) 上单调递减，端点取不到，所以是严格不等号；若误判 g 的单调性会得出反向结论。

## 2004-16（解答）

status: 待核对

- **切入点**：阻力与速度成正比 ⇒ m dv/dt=−kv，求总滑行距离即 t→∞ 的位移。
- **关键步骤**：分离变量得 v=v₀e^{−kt/m}；也可换成 m v dv/ds=−kv 直接得 ds=−(m/k)dv，积分从 v₀ 到 0 得 s=mv₀/k。代入 m=9000、v₀=700km/h（须化为 m/s）、k=6.0×10⁶。

## 2004-17（解答）

status: 待核对

- **切入点**：Σ 是抛物面 z=1−x²−y²（z≥0）的上侧，不封闭，补底面 z=0 的下侧。

## 2004-18（解答）

## 2004-19（解答）

- **关键步骤**：方程两边分别对 x、y 求偏导，令 z_x=z_y=0 得 x=3y 与 5y=z 之类的关系，回代原方程定驻点；再求二阶偏导用 AC−B² 判别。

## 2004-20（解答）

status: 待核对

- **切入点**：系数矩阵形如 aE+（每行成比例的秩 1 阵），先算行列式。
- **关键步骤**：把矩阵写成 aE+cαᵀ 形式（第 i 行为 i 倍的全 1 行），行列式为 aⁿ⁻¹(a+n(n+1)/2)。有非零解 ⇔ 行列式为 0 ⇔ a=0 或 a=−n(n+1)/2，两种情形分别求基础解系。
- **易错处**：a=0 时系数矩阵秩为 1，基础解系有 n−1 个向量；另一种情形秩为 n−1，只有一个。两种情形的通解形式完全不同，不能只算一种。

## 2004-21（解答）

status: 待核对

- **切入点**：特征方程有二重根，分「重根是不是使秩下降足够」两种情况讨论。
- **关键步骤**：算 |A−λE| 得三次方程，含参数 a；二重根的可能来自判别式为零或某个已知根是重根。求出 a 的两个值，对每个值算重根 λ 的 r(A−λE)，比较 n−r 与重数决定能否对角化。
- **易错处**：「特征方程有二重根」不等于「可对角化」；必须逐个 a 值单独验证几何重数。

## 2004-22（解答）

status: 待核对

- **切入点**：先用乘法公式把 P(AB) 算出来，再列 (X,Y) 的四格联合分布。
- **关键步骤**：P(AB)=P(A)P(B|A)=1/12；由 P(A|B)=P(AB)/P(B)=1/2 得 P(B)=1/6。四格表由 P(AB)、P(A)、P(B) 及总和为 1 补全，再算 E(XY)、E(X)、E(Y)、D(X)、D(Y) 得 ρ。

## 2004-23（解答）

status: 待核对

- **切入点**：先由分布函数求出密度 f(x;β)=β/x^{β+1}（x>1）。
- **关键步骤**：矩估计——E(X)=∫₁^∞ x·βx^{−β−1}dx=β/(β−1)，令其等于 X̄ 反解 β̂=X̄/(X̄−1)。最大似然——lnL=n lnβ−(β+1)Σln xᵢ，求导得 β̂=n/Σln xᵢ。

# 2005

## 2005-1（填空）

status: 待核对

- **切入点**：斜渐近线 y=kx+b，k=lim y/x，b=lim(y−kx)。
- **关键步骤**：k=lim x/(2x+1)=½；b=lim(x²/(2x+1)−x/2)=−¼。故 y=x/2−1/4。
- **易错处**：也可直接做多项式除法 x²/(2x+1)=x/2−1/4+(1/4)/(2x+1)，更快且不易错。

## 2005-2（填空）

status: 待核对

- **切入点**：化为标准一阶线性型 y′+(2/x)y=ln x。
- **关键步骤**：积分因子 x²，(x²y)′=x²ln x，积分得 x²y=x³(ln x)/3−x³/9+C；由 y(1)=−1/9 定 C=0。
- **易错处**：右端 x ln x 除以 x 后是 ln x，不是 x ln x；∫x²ln x dx 需分部积分。

## 2005-3（填空）

status: 待核对

- **切入点**：方向导数 = 梯度 · 单位方向向量，n 已是单位向量。
- **关键步骤**：grad u=(x/3, y/6, z/9)，在 (1,2,3) 处为 (1/3,1/3,1/3)，与 n=(1,1,1)/√3 作内积得 √3/3。
- **易错处**：n 已单位化，不要再除一次模。

## 2005-4（填空）

status: 待核对

- **切入点**：Σ 是闭曲面外侧，直接用高斯公式。
- **关键步骤**：散度为 3，积分等于 3×Ω 的体积；Ω 是锥面与半球面围成的「冰淇淋」，用球面坐标算体积，φ 从 0 到 π/4。
- **易错处**：锥面 z=√(x²+y²) 对应 φ=π/4；体积算成整个半球是常见错误。

## 2005-5（填空）

status: 待核对

- **关键步骤**：C 是以组合系数为列的 3×3 矩阵（范德蒙型），|C|=2，故 |B|=|A||C|=2。

# 审查报告目录

外部 reviewer（DeepSeek 等）的独立审查报告放在这里，一份一文件。

命名：`<reviewer>-<任务简称>-<被审的 head>.md`
例：`DeepSeek-audit-batch1-2578d44.md`

规矩：

- 报告**只记录意见**，不代替修改。是否采纳由主执行者判断并落到被审文件里。
- 报告文件名里的 head 是**报告作者实际读的那个 commit**，不是任务书里写的那个。
  两者不同时，报告正文必须说明。
- 报告是 append-only 的记录：后续版本另开新文件，不覆盖旧报告。
  这与 `分析/` 下其他分析产物「重跑即整体覆盖」的约定不同——
  审查记录的价值在于可追溯，覆盖会毁掉它。
- 本目录不参与 `/analyze` 的重算与覆盖。

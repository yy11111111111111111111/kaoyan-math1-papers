## 一、五年逐位实况（原始数据，先看这张表）

| 位置 | 2021 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|
| **17** | 等价无穷小求极限 | 切线 + 一阶线性微分方程 | 极坐标二重积分 | 有理函数不定积分 | 多元函数无条件极值 |
| **18** | 幂级数收敛域 + 逐项积分 | 多元函数无条件极值 | 切平面 + 闭区域最值 | 二阶偏导 + 欧拉方程 | 二阶偏导 + 二阶常系数方程 |
| **19** | 条件极值（拉格朗日） | 高斯公式 ⬅积分 | 泰勒证不等式 ⬅证明 | 导函数单调性充要 ⬅证明 | 格林公式挖奇点 ⬅积分 |
| **20** | 二重积分最值 + 格林 | 泰勒证中值等式 ⬅证明 | 斯托克斯公式 ⬅积分 | 旋转曲面 + 高斯补面 ⬅积分 | 变限积分 + 罗尔 ⬅证明 |
| **21** | 实对称正交对角化 | 二次型合同 | 矩阵高次幂 | 特征方程重根 | 极大无关组 + 矩阵方程 |
| **22** | 均匀分布 + 函数的期望 | 二维连续型 + 协方差 | 最值分布 + 无偏 | 函数的期望 + 全概率 | 最值分布 + 无偏 + MLE |

**读出来的四条事实：**

1. **21 位恒为线代、22 位恒为概率**，五年零例外。
2. **19、20 两位合起来 = 一道多元/曲线曲面积分 + 一道中值定理证明**。2023–2026 全部吻合，**但顺序每年都可能对调**（2023、2026 是「积分在前、证明在后」，2024、2025 相反）。
3. **2021 是唯一破例的一年：全卷没有中值定理证明题**，19、20 都是多元微分/积分。所以这不是规章，是惯性——**不要把「必有一道证明题」当保证**。
4. 17、18 位的 10 个槽位里，主考点**只有 8 个不同**——2023-18 与 2026-17 同为「多元函数无条件极值」，2025-18 与 2026-18 同为「多元复合函数的二阶偏导数」。**注意这两处重复正好横跨位置**（18 位的考点第二年出现在 17 位），说明连这两位之间的分工也不是固定的。这两位的具体内容不可预测，可观察到的只是它们的**内容定位：以计算为主、步骤明确**（⚠️ 「不设障碍/难度」是难度主张，本库无难度字段，已删）。

## 二、六套模板

每套给出：这个位置在干什么 → 拿到题先做什么 → 通用骨架 → 对应真题 → 这个位置的典型丢分。

---

### 模板 17｜首题·计算型功能位

**职能**：考最基本的计算。在 2021、2023–2026 这 5 个样本中全部是「一个明确对象 + 一条明确路径」，没有需要构造的东西。（这是职能描述，**不是难度判断**——本库无难度字段。）

**开题动作**：读完题先问「这题的答案是一个数、一个函数，还是一条曲线/曲面」，据此定终点，再倒推需要几步。

**骨架**：
```
识别类型（极限 / 不定积分 / 二重积分 / 极值 / 微分方程）
  → 套该类型的标准流程（速查文件里都有）
  → 算到底，写清每一步的中间结果
```

**这个位置常见的失分形态**（⚠️ 来自 `解法.md` 的易错处语料，属 `unverified_inference` 的衍生；**本库没有学生作答数据**，无法断言「不是不会，是算错」）：
- 二重积分定限没画图，直接凭感觉写；
- 不定积分忘 +C，定积分代限时上下限写反；
- 微分方程求出通解后没代初值定常数。

**对应真题**：2021-17、2023-17、2024-17、2025-17、2026-17

---

### 模板 18｜次题·多元微分主场

**职能**：仍是计算，但**开始有两步以上的复合**。五年**全部**落在多元微分学（4 次）或级数（1 次）上，是全卷第一个需要「换个记号才好算」的位置。

**开题动作**：先判断**要不要换元**。看到 z=f(x, y/x)、u=f(xy) 这类结构，先设中间变量并写清链式法则的求导路线图，再动笔。

**骨架**：
```
定自变量与中间变量  →  画出依赖关系图  →  逐层链式求导
  →（若题目转成微分方程）设新变量把它化成常系数或欧拉型
  →  解出后回代原变量
```

**典型丢分**：二阶偏导求 ∂²z/∂x∂y 时，**对第一层导数再求导时忘了它仍是复合函数**（漏掉一整项）。这是本位置最常见的错误，写求导路线图能直接消除。

**对应真题**：2021-18（幂级数）、2023-18（多元极值）、2024-18（切平面+最值）、2025-18、2026-18（都是二阶偏导+微分方程）

### 模板 19/20-A｜积分位（多元积分：格林 / 高斯 / 斯托克斯）

**职能**：考「你会不会把一个不好算的积分换成好算的积分」。五年出现 4 次（2023-19、2024-20、2025-20、2026-19）。

**开题动作**——**按顺序问这三句，问完就知道用哪条公式**：

| 问 | 答「是」时 | 用 |
|---|---|---|
| 积分区域**封闭**吗？ | 闭曲线 / 闭曲面 | 直接上格林 / 高斯 |
| 不封闭，能**补**成封闭吗？ | 补一条直线或一个平面 | **补线/补面法**，最后减掉补的部分 |
| 封闭但**内部有奇点**吗？ | 分母在区域内为零 | **挖奇点法**：挖一条与分母同型的小闭曲线/小球面 |

**骨架**：
```
判断封闭性  →  补 或 挖  →  换成二重/三重积分
  →  用对称性 / 极坐标 / 柱面坐标 / 球面坐标化简
  →  减去补上的那部分（符号！）
```

**三个丢分点，按发生频率排**：
1. **方向与法向量指向**。格林公式要求正向（区域在左侧），高斯要求外侧。方向反了整体差一个负号，而这一步做完往往看不出错。
2. **补的那部分忘了减**，或减的时候符号又错一次。
3. 挖奇点时挖的曲线形状**没和分母配型**（分母 x²+4y² 就该挖椭圆，挖圆算不下去）。

**对应真题**：2023-19（高斯）、2024-20（斯托克斯）、2025-20（旋转曲面+高斯补面）、2026-19（格林挖奇点）；另 2021-20 用到格林。

### 模板 19/20-B｜证明位（中值定理与不等式）

**职能**：以辅助函数构造为核心的位置。⚠️ **不写「区分度最高」**——本库没有难度或得分率字段。五年出现 **4 次**（2023-20、2024-19、2025-19、2026-20），**2021 年缺席**。

**开题动作**：先看**要证的结论长什么样**，结论的形式直接指定用哪个定理：

| 要证的结论 | 用 | 辅助函数怎么造 |
|---|---|---|
| 存在 ξ 使 f(ξ)=0 | 零点定理 / 罗尔 | 直接用 f，或用 f 的原函数 |
| 存在 ξ 使 f′(ξ)=某式 | **罗尔** | 把结论**移项写成 F′(ξ)=0**，反求 F |
| 存在 ξ 使 f″(ξ)=某式 | **罗尔用两次** | 先找出 f′ 的两个零点 |
| 两点之间的差 f(b)−f(a) | 拉格朗日 | 不必造，直接用 |
| 含 f(x₀) 与区间端点值 | **泰勒**在 x₀ 展开 | 把端点代进展开式，两式相加/相减消项 |
| 一个不等式 | 泰勒带拉格朗日余项，或**单调性** | 造 F=左−右，证 F 单调且端点值 ≥0 |

**造辅助函数的通用手法（这一条值得背下来）**：把要证的等式**全部移到一边**，看成 F′(ξ)=0，然后对这个式子**求原函数**。例如要证 f′(ξ)+f(ξ)=0，则 F(x)=eˣf(x)；要证 ξf′(ξ)+f(ξ)=0，则 F(x)=xf(x)。

**骨架**：
```
读结论 → 定定理 → 造辅助函数 F
  → 验 F 的条件（连续？可导？两端点等值？）  ← 阅卷给分点
  → 应用定理得到 ξ
  → 回代整理成题目要的形式
```

**丢分点**：**跳过条件验证**。「F 在 [a,b] 连续、(a,b) 可导、F(a)=F(b)」这三句是罗尔定理的给分点，不写就算结论对了也扣分。另一个是泰勒展开**没写余项的形式**或余项的 ξ 与结论的 ξ 混用。

**对应真题**：2023-20（泰勒证中值等式）、2024-19（泰勒证不等式）、2025-19（导函数单调性充要，拉格朗日分区间）、2026-20（变限积分 + 罗尔重复使用）

### 模板 21｜线代位

**职能**：五年全部是线代，且全部**围绕「秩 → 方程组 → 特征值 → 相似/合同」这条主线**中的某一段。

**开题动作**：先把题目条件**翻译成秩**（见 `线性代数方法速查.md` 开头那三句），再判断要的是**相似**（保特征值）还是**合同**（保正负惯性指数）。

**骨架**：
```
条件 → r(A) = ?  →  n−r 是解空间维数
  → 若涉及 λ：det(λE−A)=0 求特征值 → 每个 λ 解 (λE−A)x=0
  → 若实对称：同一重根内施密特 + 单位化 → Q
  → 若求高次幂：Aᵏ=PΛᵏP⁻¹（或秩1捷径 Aᵏ=(trA)ᵏ⁻¹A）
```

**丢分点**：重特征值忘施密特；P 的列与 Λ 的对角元顺序错位；二次型交叉项系数没折半。

**对应真题**：2021-21、2023-21、2024-21、2025-21、2026-21

### 模板 22｜概率位

**职能**：五年全部是概率，且**都是两问以上的组合题**：前一问求分布，后一问求数字特征或做估计。

**开题动作**：**先定这是「求分布」还是「求估计」**，两条路完全不同：

```
求分布线：  定分布类型 → 写密度/分布律 → 用规范性定参数
            → 求函数分布（一律走 F_Y(y)=P{g(X)≤y}）→ 算 E、D
求估计线：  写似然 L(θ)=∏f(xᵢ;θ) → ln L → 求导令零
            → ⚠️ 若 θ 出现在取值范围里，不求导，按单调性取 max{Xᵢ}
            → 验无偏 E(θ̂)=θ，有偏则配系数修正
```

**注意 22 位的高频重叠**：五年里 **2024-22 与 2026-22 是同一个组合**（最值的分布 + 无偏估计），2026 还多接了最大似然。

⚠️ **不要沿用「最后一题必考最大似然」这个旧经验。**最大似然在 22 年里出现 13 次、且全部在末题位——但**其中 12 次在 2004–2020**。那时每年有**两道**概率解答题，其中一道固定是估计与检验；新卷型压缩到**一道**之后，这道题不再稳定落在数理统计上：五年里只有 2024（无偏）和 2026（无偏+最大似然）沾统计，另外三年是纯概率。

结论：最大似然要练到不看提示能独立走完五步（它是单个考点出现最多的，2026 刚考过），**但准备 22 位时两条路都要备**——求分布线和求估计线。

**丢分点**：U(0,θ) 型的 MLE 去求导（应取端点）；混合型分布只算积分漏掉原子点；D X̄ 写成 σ²。

**对应真题**：2021-22、2023-22、2024-22、2025-22、2026-22

## 三、怎么用这份文件

**练法**：不要按年份成套刷，按**位置横着刷**。

把五年的第 19、20 题（10 道）连着做完，你会直观看到「这十道题其实只有两种要求」；再横刷 22 位，会看到最大似然那套五步流程反复出现。这是本仓库数据能给出的**最高信噪比的练法**——因为位置的职能稳定，而位置里填的考点不稳定。

**不要用它做的事**：
- 不要据此押某位置的具体考点（检验 B p=0.154、检验 G HR 95% 区间 [0.77, 1.11]，**均为未检出**）。
- 不要把「19 是积分、20 是证明」当固定顺序（2024、2025 就是反的）。
- 不要假定每年必有证明题（2021 没有）。

**练完自查的三个问题**：
1. 19/20 位：拿到一个要证明的等式，我能在**一分钟内**写出辅助函数吗？
2. 积分位：我能不查资料背出「补线/补面后要减掉哪一部分、符号是什么」吗？
3. 22 位：MLE 的五步，包括那个「参数在取值范围里就不能求导」的特情，我能不看提示走完吗？

这三个位置按 70 分 ÷ 6 题的均分近似合计约 **35 分**（⚠️ **不是题级实际分值**——逐题分值未落到题级，见 `CLAUDE.md` §2.3）。「最可训练」是教学判断（`pedagogical_hypothesis`），非统计结论。

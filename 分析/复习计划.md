# 复习计划（2026-08-23 起）

> 起算日：**2026-08-23**。目标考试：2027 年考研初试数学（一），**预计 2026 年 12 月中下旬**（教育部通常 9 月发布确切日期，本文按 12 月 19 日倒推，共 **17 周**）。
> 本计划完全建立在 `分析/` 的真题数据上，每一条安排都注明了它对应哪份文件、依据哪条统计。

---

## ⚠️ 给接手 AI 的说明（必读）

- 本文件是**给用户本人**的执行计划，不是分析产物。与它配套的「给助教用」的入口是 `交接说明-教学AI.md`。
- 计划的**结构性依据**来自 `命题模型.md`（配额刚性、功能位样本内稳定、考点层未检出记忆），**内容依据**来自三份考法统计与三份方法速查。
- 计划里所有「预计」「建议」都是可调的；**唯一不可调的是真题的分配方式**——2024–2026 三套必须留到最后当模拟卷，用掉就没有干净的模考样本了。
- 本文件不是 `/analyze` 产物，重跑不会覆盖。

22 套真题不能一视同仁地刷。按用途分成三档：

| 档 | 年份 | 用途 | 什么时候用 |
|---|---|---|---|
| **A. 模考卷（3 套）** | **2024、2025、2026** | 严格计时、一次成卷、按现行卷型评分 | 第 15、16、17 周，**在此之前绝对不看** |

## 三、17 周安排

### 阶段一：模块清扫（第 1–4 周，8/23 – 9/19）

**目标**：把 223 个考点从「见过」推到「能独立走完流程」。

| 周 | 内容 | 对应文件 | 每日量 |
|---|---|---|---|
| 1 | 高数：极限连续、一元微分、一元积分 | `高数方法速查.md` §1、§2、§4 | 1 个模块的全部考点 + 该模块真题 15 题 |
| 2 | 高数：多元微分、二重/三重积分、曲线曲面积分 | `高数方法速查.md` §5–8 | 同上 |
| 3 | 高数：中值定理与证明、级数、微分方程、空间解析几何 | `高数方法速查.md` §3、§9–11 | 同上 |
| 4 | 线代全 5 模块 + 概率全 5 模块 | 两份方法速查 | 线代 3 天、概率 4 天 |

**做法**（这一步的质量决定后面 13 周的效率）：

1. 打开某模块的速查表，**逐条读「具体操作」列**。
2. 每读完一条，从「涉及真题」里**挑最早的一道**做（早年的题包装少、更接近方法本身）。
3. 做完对 `solutions/`。**卡住超过 5 分钟就直接看解析**——这个阶段不是练思维强度，是建立流程。
4. 卡住的那条，在下面 §五 的错题表里记一行。

**四周结束时的自检**：随手翻开速查表任意一行，遮住「具体操作」列，能不能把步骤复述出来。

### 阶段二：三层训练（第 5–12 周，9/20 – 11/14）

> **⚠️ 2026-08-27 重构。**本阶段原为「按功能位横刷八周」，依据是「检验 D 证明功能位是出题人唯一稳定的偏好层」。
> **那个依据已经不成立**：检验 D 重做后拆为 D1/D2，剔除科目效应（旧卷型第 6–9 位、新卷型 21/22 位恒为「计算」，那是科目不是位置）后，D1 的 p=0.094（旧卷型）/ 0.064（新卷型），**有倾向但未达显著**；D2 未检出；因变量还继承 `解法.md` 的未核验性。
> 但**不是撤销**——按卷面位置组织训练的问题不在于 p 值差一点，而在于**题号位置本身不是我们想让你学会的数学线索**。长期按位置横刷会训练出 `位置 → 方法候选集`，而我们要的是 `数学特征 → 方法候选集`。
> 所以按位置训练**降为考试情境层**，主轴换成方法族。

#### 两个必须分开的概念

本文件此前把它们混称「功能位训练」，现正式拆名：

| 名称 | 是什么 | 定位 |
|---|---|---|
| **method-family training**<br>按方法族训练 | 极限的方法竞争、中值证明的定理选择、积分路线的选择…… | **主轴** |
| **functional-demand training**<br>按作答功能训练 | 不告诉模块与方法，让你自己判断「这题首先要完成的是什么类型的数学动作」 | 第二层 |
| **slot-position training**<br>按卷面位置训练 | 连刷历年 17/18、19/20 | **只作考试情境层**，不承担方法学习 |

#### 训练配置

```yaml
training_organization:
  primary_axis: method_family          # 60–70%
  secondary_axis: functional_demand    # 20–30%
  exam_context_overlay: slot_position  # 10–20%，越接近模考比例越高

claim_type: pedagogical_hypothesis

rationale:
  - method_family 保住了数学机制与 guard 条件，题号位置解释不了任何机制
  - functional-demand 混练训练的是无提示的任务解读与方法选择
  - slot-position 只训练考场执行与情境适应

not_claimed:
  - 卷面位置能预测未来内容
  - 按功能位训练优于按模块训练
  - 这个配比已被学习表现数据验证
```

**最后一行是重点：这套新方案目前仍然是教学假设。**它比原方案合理，是因为它与「无提示识别 → 候选生成 → 条件检查 → 迁移」这条学习目标结构一致，**不是因为已有实证数据证明它更有效**。

#### 第一层：方法族（60–70%，第 5–10 周）

训练目标是「**候选集 + 决定性条件 + 失效边界**」，不是记题型口令。

| 周 | 方法族 | 候选集里至少要有 |
|---|---|---|
| 5 | 极限的方法竞争 | 泰勒定阶 / 等价无穷小 / 洛必达 / 夹逼 / 单调有界 |
| 6 | 中值定理证明 | 罗尔 / 拉格朗日 / 柯西 / 泰勒余项 / 辅助函数构造 |
| 7 | 一元积分路线 | 直接积分 / 换元 / 分部 / 对称性 / 反常积分拆分 |
| 8 | 多元积分路线 | 换序 / 换坐标 / 对称性 / 格林-高斯-斯托克斯 / 补域 / 挖奇点 / **直接参数化** |
| 9 | 多元极值 | 无约束（AC−B²）/ 条件（拉格朗日）/ 闭区域（内部+边界+顶点） |
| 10 | 级数与 ODE | 判敛（比较/比值根值/莱布尼茨）；ODE（可分离/一阶线性/伯努利/可降阶/常系数/欧拉） |

> **每个族至少要能回答三问**：这个族里有哪几个候选？哪个条件是**决定性**的（不是「哪个更方便」）？什么时候它**不合法**、什么时候只是**失去优势**？
> ⚠️ 第三问的反例往往不在真题里（真题基本是正例），需要构造，且构造的反例要独立核验。这一层目前**尚未建好**，见 `10_高等数学_资料与覆盖索引.md` §6。

#### 第二层：作答功能混练（20–30%，第 11 周起穿插）

把已经学过的几个方法族混起来，**不告诉模块、不告诉考点、不告诉方法，更不要说「这是 19 位风格」**。训练这条链：

```
完整题面 → 最小数学结构 → 候选方法族 → 选择
```

这是迁移价值最高的一层。判断题目属于哪类数学动作（计算 / 需要构造的证明 / 积分表示转换 / 方法竞争型），是解题组织能力，**不是命题预测**。

#### 第三层：卷面位置与考场情境（10–20%，第 12 周及模考期）

这时才横刷 17/18、19/20，最后整卷。**目的必须写清楚**：熟悉时间分配、任务切换、卷面情境；**不是学习「第 N 题应该用什么方法」**。

**每周固定动作**：周末拿一套 C 档真题（2004–2019）按新卷型改造——挑 10 道选择、6 道填空、6 道解答，计时 180 分钟。这是模考的替代品，不消耗 A 档卷子。

#### 怎么知道这套配置是不是有效

记录五个行为量就够，不需要另造一套教学模型：

```yaml
method_selection:   { correct_family_selected: true/false }
first_action:       { valid: true/false, latency_bucket: fast/medium/slow }
guard_check:        { decisive_condition_checked: true/false }
execution:          { correct_after_selection: true/false }
transfer:           { changed_decisive_condition_handled: true/false }
```

外加一个**专门用来查第三层有没有污染前两层**的指标：

```yaml
position_cue_dependence:
```

做法：同一方法族的题，有时按原题号呈现，有时**随机打乱、完全不给位置语境**。

- 知道「这是 20 题」时会做，打乱后明显掉 → **卷面位置训练已经形成了错误线索**，第三层比例要压。
- 打乱后仍能靠数学结构独立选法 → 没有污染真实检索。

这比继续研究「出题人到底有没有位置偏好」对复习更直接。

## 五、错题表（自己维护，模板如下）

新建 `分析/我的错题.md`，或直接用纸。每行记一次，**必须填「类型」列**——只有归了类，才能看出自己的错误是不是集中在少数几个地方。

| 日期 | 题号 | 考点 | 错误类型 | 一句话订正 |
|---|---|---|---|---|
| 例：08/25 | 2013-19 | 高斯公式 | 方向/符号 | 外侧法向量，补面后要减 |

**错误类型建议只用这七个**（来自 22 年真题易错处的人工归纳）：

1. **概念混淆**——把两个相近概念用反了（相似 vs 合同、独立 vs 不相关、行 vs 列）
2. **条件遗漏**——定理的前提没验（罗尔的三个条件、B⊂A 才有 P(A−B)=P(A)−P(B)）
3. **方向与符号**——积分方向、法向量指向、补/挖之后的加减号
4. **边界与端点**——极值忘了边界、积分限、分段点
5. **计算失误**——纯算错，思路没问题
6. **审题**——问的是 A 我答了 B
7. **无思路**——完全不会，需要回速查表重学

**每周日统计一次各类型的条数。**如果「计算失误」占一半以上，问题不在知识而在做题习惯；如果「无思路」还在增加，说明阶段一没做扎实，要回头补。

## 六、这份计划里哪些是数据支持的，哪些是常识

诚实分层，方便你自己判断哪些可以改：

| 安排 | 依据 | 强度 |
|---|---|---|
| 2024–2026 留作模考 | 现行卷型只有 5 套，`考纲.md` §二 | **强**（事实约束） |
| 三层训练（方法族为主轴） | **教学假设**，非统计结论。原依据（检验 D）已于 2026-08-27 降级为 p≈0.06–0.09 | **弱**（未经学习表现数据验证） |
| 最大似然要练熟 | 13 次，单考点最高 | **强**（频次统计） |
| 但末题不等于统计题 | 13 次中 12 次在旧卷型；新卷型 5 年仅 1 次 | **强**（分卷型复算） |
| 不押具体考点 | 检验 B（p=0.154）+ 检验 G（HR 95% 区间 [0.77, 1.11]） | **中**（两项均为「未检出」，非「已证否」；作为保守政策执行） |
| 23 个盲区考点 | 频次 + 末次出现年 + 考纲仍收录 | **中**（选取口径可调） |
| 每天 3+1.5+1 小时的时段划分 | — | **弱**（常识，按自己状态调） |
| 17 周的阶段切分 | — | **弱**（常识，按进度调） |

**最后一句**：这份计划最有价值的部分不是时间表，是 §二（真题分配）和阶段二的**三层结构**（方法族为主轴、作答功能混练为第二层、卷面位置只作考试情境层）。时间表你可以随便改；真题分配那条是事实约束，别动；三层结构是教学假设，可以按 `position_cue_dependence` 的实测结果调比例。

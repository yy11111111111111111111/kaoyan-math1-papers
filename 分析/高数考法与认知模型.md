| 指标 | 数据 |

**这条最重要**：高数分最多，但**单个考点的回报最低**——127 个考点分 90 分，线代 48 个考点分 30 分。含义不是「高数不重要」，而是：

> **统计事实**：104 道高数解答题的职能分布为 **计算 48 · 积分 32 · 证明 23 · 综合 1**（⚠️ 职能列判定以 `解法.md` 为准，继承 `unverified_inference`）。
> **教学判断（`pedagogical_hypothesis`，非统计结论）**：既然四分之三的解答位标为计算类，把训练重心放在「流程不出错」上比放在「背全考点」上更贴合观察到的结构。**这不是由 104 个职能标签直接推出的**，也没有学生作答数据支持。

## 二、高数的三条主线（我的组织框架）

线代有 r(A) 这个单一枢纽、概率有四步流水线，**高数没有单一枢纽**——它是三条独立主线拧在一起。任何一道高数题，先判断它在哪条线上：

| 主线 | 一句话 | 覆盖模块 | 共同动作 |
|---|---|---|---|
| **A. 局部化** | 把函数在一点附近**换成多项式**，比系数 | 极限与连续、一元微分、中值定理 | **定阶** |
| **B. 累积化** | 把「和起来」的量**换成能算的形式** | 一元积分、二重/三重积分、曲线曲面积分、级数 | **换公式 / 换坐标 / 换维数** |
| **C. 结构化** | 从**关系**（方程、约束、依赖）解出函数本身 | 多元微分、微分方程、空间解析几何 | **理清谁依赖谁** |

三条线的**认知负担类型完全不同**，所以练法也不同：

- A 线练的是**精度**（少展开一阶就全错）→ 大量短题、限时。
- B 线练的是**选择**（用哪条公式）→ 判定树要熟，题量可以少但每题要走完。
- C 线练的是**记号**（谁是自变量、谁是中间变量）→ 每题先画依赖图，不画就错。

### 模块 1｜极限与连续（主线 A）

**体量**：10 个考点 · 58 次标注 · 39 题 · 占高数 14%
**核心考点**：泰勒公式展开（S，17 次，全库第一）· 等价无穷小替换（S，14 次）· 单调有界准则（A，6 次）

**卷面落点**（有真题证据）：

| 落点 | 证据 |
|---|---|
| **选择第 1 题** | 2007-1、2009-1、2013-1、2019-1、2023-1（渐近线+泰勒）——首题历来是极限/渐近线/无穷小定阶 |
| **填空 11–12 位** | **2023-11、2024-11、2025-11、2026-12 连续四年**，全部是「泰勒 + 等价无穷小」配对 |
| **解答 17 位** | 2021-17（等价无穷小 + 泰勒求极限） |
| **证明位** | 单调有界准则 6 次里 **4 次是解答证明**（2011-18、2016-19、2018-19 等），但**新卷型 5 卷零出现** → 标记「盲区」 |

> ⚠️ 那条「填空四连」是我从数据里看到的位置模式，**样本只有 4**，且检验 B 说考点层不可预测。**当成「这个形态要练熟」，不要当成「今年一定在 11 题」。**

**可能的考法**：

| 题型 | 考法 | 证据 |
|---|---|---|
| 选择 | 比较两个无穷小的阶 / 判断谁是谁的等价无穷小 | 2004-7、2013-1、2019-1、2020-1 |
| 选择 | 间断点分类（第一类可去/跳跃 vs 第二类） | 2016-4 |
| 选择 | 「极限存在 / 连续 / 可导」四个命题判真假 | 2007-4、2020-2、2024-4、2025-3 |
| 填空 | 给定极限值反求参数（含 1^∞、0/0） | 2006-16、2010-1、2011-15、2018-9 |
| 填空 | 泰勒定阶：求 lim = 有限非零时的 a、n | 2023-11、2024-11、2025-11、2026-12 |
| 解答 | 递推数列 x_{n+1}=f(x_n) 证收敛并求极限 | 2011-18、2016-19、2018-19 |
| 解答 | 极限作为大题第一问，为后面铺路 | 2021-17 |
| *未见但合法* | 洛必达与泰勒的混合陷阱题（洛必达仅 1 次：2014-15）；夹逼准则求 n 项和的极限 | — |

**认知模型 —— 「阶」的模型**

```
每个部件都有一个「阶」：x^k 前的系数 + k 本身
极限的值 = 分子最低阶主项 ÷ 分母最低阶主项
       ↓
所以求极限 = 把每个部件展开到「能看出主项」为止，一阶不多一阶不少
```

三条必须内化的判断：

1. **展开到几阶，由分母决定，不由分子决定。**分母是 x³，分子就展开到 x³；分子展早了浪费、展晚了丢项。
2. **等价无穷小只能用在乘除因子上，不能用在加减项上。**`sin x − x` 用 `x − x` 得 0 是最经典的错法——加减处必须泰勒。
3. **变限积分的阶 = 被积函数的阶 + 1。**`2004-7` 的易错处原话：定阶要看积分后的阶，而非被积函数的阶。

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 0/0 且分子含加减 | 泰勒，不用等价无穷小 |
| 1^∞ | 化 e^{lim v(u−1)}，先算指数 |
| 递推式 x_{n+1}=f(x_n) | 三步：证有界 → 证单调 → 设 a 代回解 a |
| ∫₀^x g(t)dt 出现在极限里 | 先定被积函数的阶，再 +1 |
| 「阶」「等价」「高阶无穷小」字样 | 作比取极限，别猜 |

**失分结构**：系数与阶（`2006-1`：1−cos x ~ x²/2 不是 x²）· 换元未同步（`2007-11`：上下限要随换元互换）。

### 模块 2｜一元微分（主线 A）

**体量**：19 个考点 · 65 次 · 46 题 · 占 16%（考点数最多的模块之一）
**核心考点**：极值的判定（S，6 次，新卷型 **4 次**最活跃）· 导数定义（A，8 次）· 函数凹凸性（A，7 次）· 导数的几何意义与切线（A，6 次）

**卷面落点**：几乎全在**选择 1–4 与填空 11–13**。19 个考点里 12 个从没进过解答题。

**可能的考法**：

| 题型 | 考法 | 证据 |
|---|---|---|
| 选择 | 由 f′ 或 f″ 的图/符号反推 f 的形状、极值点、拐点个数 | 2011-1、2015-1、2019-15、2025-1 |
| 选择 | 分段函数在分段点的可导性（先连续后可导） | 2005-7、2016-4、2018-1、2019-2、2023-3 |
| 选择 | 用导数定义识别一个极限式其实是某点导数 | 2004-8、2007-4、2012-2、2020-2、2021-1、2024-4 |
| 选择 | 凹凸性 ⇄ 曲线与弦/切线的高低关系翻成不等式 | 2014-2、2026-3 |
| 选择/填空 | 渐近线条数（铅直+水平+斜，三类分别查） | 2007-2、2012-1、2014-1 |
| 填空 | 参数方程求二阶导（**5 次全部在填空**） | 2010-9、2013-11、2020-10、2021-12、2026-13 |
| 填空 | 切线方程 / 法线 / 与坐标轴交点 | 2004-1、2008-10、2015-16、2018-10 |
| 解答 | 切线条件启动一个微分方程（切线 → ODE → 解） | 2023-17 |
| 解答 | 单调性与极值作为大题的中间步骤 | 2010-16、2014-16、2017-17 |
| *未见但合法* | 曲率与曲率半径（22 年零出现，考纲内）；相关变化率 | — |

**认知模型 —— 「导数是三样东西」**

```
f′(x₀) 同时是：  ① 一个极限（定义式）
                ② 一条切线的斜率（几何）
                ③ f 在 x₀ 附近的增长率（单调/极值）
出题人考的就是「你能不能在三种身份之间自由切换」
```

判定链要背成**一条单向链**，不能倒着用：

```
可导 ⇒ 连续 ⇒ 极限存在      （反向全部不成立，每一步都要能立刻举反例）
反例常备：|x| 在 0 —— 连续不可导
         x sin(1/x) 补 0 —— 连续不可导
         符号函数 —— 极限存在不连续
```

拐点与极值的**对称结构**（这是最省记忆的一条）：

| | 用什么找候选 | 用什么确认 | 关键词 |
|---|---|---|---|
| 极值 | f′=0 或 f′ 不存在 | f′ **变号** | 变号 |
| 拐点 | f″=0 或 f″ 不存在 | f″ **变号** | 变号 |

两行完全同构，只差一阶。**「f″=0 就是拐点」是本模块最高频的错**——多项式看因子重数：奇次变号、偶次不变。

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 一个长得像极限的选项 | 先问「这是不是某点的导数定义」 |
| x=x(t), y=y(t) | dy/dx=(dy/dt)/(dx/dt)，二阶导**要再除一次 dx/dt** |
| 「渐近线共有几条」 | 三类分开数，水平的 x→+∞ 与 x→−∞ **分开算** |
| 「f″≥0」「凹」 | 立即翻成：曲线在弦下方、在切线上方 |
| 分段函数问可导 | 先验连续，再算左右导数 |

**失分结构**：拐点漏「变号」这一步 · 参数方程二阶导忘了除 dx/dt · 水平渐近线只算了一侧。

### 模块 3｜中值定理与证明（主线 A·局部化）

**体量**：10 个考点 · 31 次 · 21 题 · 占 7%
**关键事实**：**31 次标注里 30 次落在解答题**，涉及 20 道解答题，其中 **19 道的职能是「证明」**（另 1 道是积分题里的夹逼）。没有一个考点主要出现在选择填空。

**卷面落点**：新卷型的 19 或 20 位，**2023–2026 连续 4 年必有一道**（2023-20、2024-19、2025-19、2026-20），**2021 是唯一没有的一年**。

**可能的考法**（按 22 年出现的辅助函数类型分）：

| 结论形态 | 用什么定理 | 辅助函数怎么造 | 证据 |
|---|---|---|---|
| ∃ξ 使 f′(ξ)=某个差商 | 拉格朗日 | 直接用，或**分区间各用一次** | 2005-18、2009-18、2013-18、2020-19、2025-19 |
| ∃ξ 使含 f′、f″ 的等式成立 | 罗尔，**重复使用** | 先对 f 用一次得 ξ₁、ξ₂，再对 f′ 在 [ξ₁,ξ₂] 上用一次 | 2026-20 |
| ∃ξ 使 F(ξ)=0，F 含积分或乘积 | 罗尔 + 构造 | 把待证式**移项凑成 (某函数)′=0**，反解出该函数 | 2023-20 |
| 不等式 f(x) ≥/≤ g(x) | 泰勒带拉格朗日余项 | 在端点或中点展开，余项符号由 f⁽ⁿ⁺¹⁾ 的界给出 | 2012-15、2018-19、2024-19 |
| 不等式（一阶就够） | 单调性 | 令 F=左−右，证 F′ 定号 + 端点值 | — |
| ∃ξ 使 f(ξ)=某值 | 零点定理 | 构造 F 使 F(a)F(b)<0 | 2026-20 |
| 方程根的个数 | 单调性 + 零点定理 | 分区间数单调段，每段至多一根 | — |
| 中值等式（两点展开） | 泰勒 | 对同一点向两端各展开一次，**相加消一阶 / 相减消二阶**，两个 ξ 用 f″ 连续+介值合成一个 | 2023-20 |

**认知模型 —— 「证明题不是想出来的，是反推出来的」**

```
待证结论  ──移项──▶  某个式子 = 0
                        ↓ 认出它是谁的导数
                   辅助函数 F
                        ↓ 验 F 的三个条件
                   罗尔 / 拉格朗日
```

三条固定手法，**只有三条**：

1. **移项凑导数**：待证 `f′(ξ)+g(ξ)f(ξ)=0` → 两边乘积分因子 `e^{∫g}` → `[f·e^{∫g}]′=0` → F 就是 `f·e^{∫g}`。**这一条覆盖了大部分「含 f 和 f′ 的等式」。**
2. **用几次定理，由结论里出现的最高阶导数决定**：出现 f′ 用一次，出现 f″ 用两次（先得两个 ξ，再对 f′ 用一次）。
3. **不等式一律先试单调性，单调性不够再上泰勒**。判据：结论里出现二阶导或「中点」，就是泰勒。

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 「至少存在一个 ξ」+ 只含 f′ | 拉格朗日；端点不好用就分区间 |
| 「至少存在一个 ξ」+ 含 f″ | 罗尔用两次 |
| 结论含 f 与 f′ 的线性组合 | 找积分因子，凑成一个乘积的导数 |
| 「证明不等式」+ 含二阶导/中点 | 泰勒带拉格朗日余项 |
| f(a)=f(b)（或能凑出相等） | 罗尔的信号灯 |
| 「方程有几个实根」 | 单调区间 + 零点定理，不用中值定理 |

**失分结构**：**验条件**。罗尔的三个条件（闭区间连续、开区间可导、端点值相等）漏一个就不得分；泰勒展开点选错（应取端点或中点）；两个 ξ 直接当成一个而不说明理由。

**练法**（这个模块和别的都不一样）：**只练「造辅助函数」这一步**。把 22 年的证明题抄下来，只写出 F，不写后面的验证——一次练 10 道 F，比完整做 3 道有效得多。

### 模块 4｜一元积分（主线 B）

**体量**：20 个考点 · 66 次 · 53 题 · 占 **19%（高数第一大模块）**
**核心考点**：变限积分求导（S，11 次）· 变限积分的性质（A，8 次，新卷型 **3 次**）· 分部积分法（A，8 次）

**卷面落点**：分布最散的模块——选择、填空、解答都有大量落点，且**经常不是主考点**（作为工具嵌在别的题里）。新卷型解答位出现过：2025-17（有理函数不定积分，17 计算位）。

**可能的考法**：

| 题型 | 考法 | 证据 |
|---|---|---|
| 选择 | F(x)=∫₀^x f 的性质：奇偶性、单调性、极值点位置 | 2005-8、2007-3、2009-3、2017-4、2024-1、2025-3 |
| 选择 | 变限积分求导（含上下限都是函数、被积含 x） | 2004-7、2008-1、2020-1、2025-1 |
| 选择 | 比较三个定积分的大小 | 2010-17、2011-4、2012-4、2018-4、2024-19 |
| 选择/填空 | 定积分的几何意义（面积/体积反读） | 2017 前多次 |
| 填空 | 反常积分求值或判敛散（拆瑕点端与无穷端） | 2021-11、2026-14 |
| 填空 | 分部积分（含 ln、arctan、多项式×指数） | 2013-12、2018-10、2026-14 |
| 填空 | 换元法、奇偶对称性简化 | 2013-15 等 |
| 解答 | 有理函数不定积分（拆分式） | 2025-17 |
| 解答 | 平面图形面积 / 旋转体体积 | 2004-2、2012-18 等 |
| 解答 | 定积分不等式的证明（配合中值定理） | 2024-19 |
| *未见但合法* | 定积分递推公式（仅 1 次）· 弧长（仅 1 次）· 平均值与积分中值定理 | — |

**认知模型 —— 「变限积分是一个函数，不是一个数」**

这是本模块 90% 错误的根源。要装的结构：

```
F(x) = ∫_{a(x)}^{b(x)} f(t) dt
       ↑ t 是哑变量，和 x 无关
F′(x) = f(b(x))·b′(x) − f(a(x))·a′(x)

若被积函数里也有 x：先换元或拆项，把 x 移到积分号外，再求导
```

配套的四条性质（选择题反复考的就是这四条）：

| f 的性质 | F(x)=∫₀^x f 的性质 |
|---|---|
| f 连续 | F 可导（**升一级**） |
| f 为奇 | F 为偶 |
| f 为偶 | F 为奇（且 F(0)=0） |
| f 以 T 为周期且 ∫₀^T f=0 | F 也以 T 为周期 |

**积分方法的选择树**（本模块唯一要背的判定树）：

```
被积函数是什么？
├ 有理分式 ──────▶ 部分分式拆开
├ 含根式 √(a²±x²) ▶ 三角代换
├ 多项式 × (e^x, sin, ln, arctan) ▶ 分部（选 u 的口诀：反对幂指三，前者为 u）
├ 含 f′ 与 f 的组合 ▶ 凑微分
└ 区间对称 / 周期 ▶ 先用对称性砍掉一半，再算
```

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| ∫₀^x 出现在选项里 | 先判 F 的奇偶与单调，往往不用算 |
| 积分限对称 [−a,a] | 先拆奇偶，奇的直接为 0 |
| ∫₀^{2π} 或明显的周期 | 用周期平移把区间挪到最好算的位置 |
| 被积函数在端点无界 | 是**反常积分**，先拆再判敛散，不能直接牛顿-莱布尼茨 |
| 三个积分比大小 | 在同一区间比被积函数，不要真算 |

**失分结构**：把变限积分当常数 · 反常积分直接代限 · 分部积分选错 u 导致越算越复杂 · 换元后忘换上下限（`2010-10`：换元后上限是 π 不是 π²）。

**认知模型 —— 「先画依赖图，再动笔」**

这是本模块唯一真正要建立的东西：

```
     z
   ↙   ↘         每条边 = 一次链式求导
  u     v        ∂z/∂x = z_u·u_x + z_v·v_x
 ↙ ↘   ↙ ↘
x   y x   y

关键：求二阶偏导时，z_u 本身仍然是 u、v 的函数，
     所以对 z_u 再求 x 的偏导时，要再走一遍整张图。
     ── 漏这一步就整项丢失，这是 18 位最常见的错。
```

**极值的三层结构**（考法的三个级别，看到题先定级）：

| 级别 | 题面长相 | 方法 |
|---|---|---|
| 无条件极值 | 「求 z=f(x,y) 的极值」 | 解 f_x=f_y=0 得驻点 → A=f_xx, B=f_xy, C=f_yy → **AC−B²>0 且 A<0 极大 / A>0 极小；<0 非极值；=0 判别法失效** |
| 条件极值 | 「在 g(x,y)=0 上求…」 | 拉格朗日：L=f+λg，解 L_x=L_y=L_λ=0 |
| 闭区域最值 | 「在区域 D 上求最大最小值」 | **内部驻点 + 边界（边界降为一元或再用拉格朗日）+ 顶点**，三处比大小 |

第三层是**丢分重灾区**：只算内部驻点、忘了边界。

**切平面/法向量的统一记法**：曲面 F(x,y,z)=0 的法向量就是 **∇F=(F_x,F_y,F_z)**。z=f(x,y) 先化成 F=f(x,y)−z=0，法向量 (f_x, f_y, −1)。**一个公式覆盖两种题面。**

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| z=f(u,v) 且 u,v 含 x,y | 先画依赖图，标清每条边 |
| 要求二阶偏导 | 提醒自己：一阶导仍是复合函数 |
| 出现 x∂z/∂x + y∂z/∂y | 想换元（常化成欧拉方程或齐次函数） |
| 「在闭区域 D 上」 | 内部 + 边界 + 顶点，一个都不能少 |
| 「切平面平行于/垂直于」 | 法向量成比例 / 内积为 0 |
| F(x,y,z)=0 求 ∂z/∂x | −F_x/F_z，别真解出 z |

**失分结构**：二阶偏导漏项（最高频）· 闭区域最值忘边界 · 拉格朗日解出多组驻点只算一组 · 隐函数求导忘了 y 也是 x 的函数。

**认知模型 —— 「二重积分只有一个动作：定限」**

在本库标注的 15 道二重积分题中，需要额外技巧的几乎都在**定限**而非被积函数上。（这是对样本的描述，**不是难度判断**——本库无难度字段。）

```
拿到题第一件事：画区域。不画图直接写限是本模块最常见的失分来源。

选坐标系的判据（只有两条）：
  区域边界是圆 / 扇形 / 环，或被积含 x²+y² ──▶ 极坐标
  其余                                    ──▶ 直角坐标

选先积哪个的判据：
  哪个方向穿过区域时「进出边界只有一条曲线」就先积哪个
  做不到 ──▶ 分区域
```

**交换次序的机械流程**（这是选择填空的固定题型）：

```
读出原限 → 画出区域 → 换一个方向重新读限 → 写出新的累次积分
中间必须画图，不能靠代数换。
```

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 被积含 x²+y² 或 √(x²+y²) | 极坐标 |
| 内层积分算不出来（如 e^{−x²}、sin x/x） | **首选**交换次序；若换序后仍算不出，回头考虑换坐标或分区域 |
| 区域被直线切成两块 | 分区域，别硬凑 |
| 「求使积分最大的区域 D」 | 被积函数变号处就是 D 的边界 |

**失分结构**：定限不画图 · 极坐标下忘乘 **r** · 交换次序后限没重新读而是照抄。

**认知模型 —— 「三问判定树」**（来自 `功能位模板.md`）

⚠️ **适用范围**：本树只覆盖「用格林/高斯/斯托克斯把边界积分换成内部积分」这一条**补域路线**，**不覆盖**参数化直接计算、路径无关换路径、对称性化简、第一类↔第二类转换。**先判断题目走不走这条路，再进树。**

```
拿到一个曲线/曲面积分，按顺序问三句：

问 1：它封闭吗？
      是 ──▶ 直接上格林（平面）/ 高斯（空间闭曲面）/ 斯托克斯（空间闭曲线）
      否 ──▶ 问 2

问 2：能补成封闭的吗？
      平面曲线 ──▶ 补线段（最好是水平/竖直，好算）
      空间曲面 ──▶ 补平面片（最好垂直于坐标轴）
      补完：∮(整体) − ∫(补的那块) = 原积分

问 3：区域里有奇点吗？（分母能为 0 的点）
      有 ──▶ 挖一个小圆/小球把它排除，
             在「大边界 − 小边界」围成的区域上用公式，
             小边界上的积分单独算（常是常数，与半径无关）
```

**三大公式的统一图景**（这一条能省掉三分之二的记忆）：

| 公式 | 把什么 | 换成什么 | 维数变化 |
|---|---|---|---|
| 格林 | 平面闭曲线积分 | 二重积分 | 1 维 → 2 维 |
| 高斯 | 空间闭曲面积分 | 三重积分 | 2 维 → 3 维 |
| 斯托克斯 | 空间闭曲线积分 | 曲面积分 | 1 维 → 2 维 |

> **三条都是「边界上的积分 = 内部的积分」**，方向约定都是「让内部保持在左手边／外侧为正」。记住这一句，三条公式的方向问题就统一了。

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 「取外侧 / 逆时针 / 正向」 | 先定方向，方向错则整题符号错 |
| 曲面不封闭 | 补面，且立刻写下「减去补面」 |
| 被积函数分母含 x²+y² 且原点在区域内 | 挖奇点 |
| ∂P/∂y = ∂Q/∂x | 路径无关，换直线路径或求原函数 |
| 曲面关于某坐标面对称 | **先查对称性**，可能直接为 0 |
| 空间闭曲线 + 旋度好算 | 斯托克斯 |

**失分结构**（本模块的失分最集中）：符号与方向——外侧/内侧、正向/负向、补面之后是加还是减；`2004-3` 的易错处：正向与 dx 的负号叠加。**建议：每道题在草稿纸最上方先写一行「方向：___，补/挖：___，符号：+/−」，再开始算。**

**认知模型 —— 「幂级数是一个可以求导积分的函数」**

```
Σaₙxⁿ 在收敛区间内部 = 一个无穷次可导的函数 S(x)
    ↓ 所以可以对它做微积分运算（逐项，收敛半径不变）
    ↓ 目标：凑成 Σxⁿ = 1/(1−x) 这个唯一的「已知答案」

求和函数的标准套路（只有两个方向）：
  分母有 n（如 Σxⁿ/n） ──▶ 先求导，消掉 n，凑成几何级数，再积回去
  分子有 n（如 Σn·xⁿ） ──▶ 先积分，消掉 n，凑成几何级数，再求导回去
两个方向都要「记得把常数补回来」（用 S(0) 定）。
```

**收敛域的三步**（选择填空的固定考法，一步都不能少）：

```
① 用比值/根值法求收敛半径 R
② 写出开区间 (x₀−R, x₀+R)
③ 两个端点各代入一次，单独判敛散  ← 丢分全在这一步
```

`2008-11` 的易错处原话：**端点收敛性随中心平移一起搬，左开右闭**。

**四个判别法的适用信号**：

| 级数长相 | 用 |
|---|---|
| 含 n! 或 aⁿ | 比值法 |
| 含 (·)ⁿ 整体 n 次方 | 根值法 |
| 正项、长得像 1/n^p | 比较法（与 p 级数比） |
| 交错 (−1)ⁿ | 莱布尼茨（单调趋 0） |

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 「收敛域」 | 三步走，端点必须单独判 |
| 「和函数」 | 看 n 在分子还是分母，定先导还是先积 |
| 「Σ 的值 = ?」（数项级数） | 构造一个幂级数，求出 S(x)，再代 x 的具体值 |
| 「f(x) 的傅里叶级数在 x₀ 处的和」 | 不用算系数！用收敛定理：连续点取 f(x₀)，间断点取左右极限平均 |
| 「条件收敛」 | 必须验两件事：原级数收敛 + 绝对值级数发散 |

**失分结构**：端点漏判 · 逐项求导后忘了积回去或忘了常数 · 傅里叶题真的去算系数（其实只要收敛定理）· 条件收敛只验了一半。

### 模块 10｜微分方程（主线 C）

**体量**：9 个考点 · 42 次 · 31 题 · 占 11%
**核心考点**：一阶线性微分方程通解公式（S，8 次）· 二阶常系数非齐次（S，8 次）· 二阶常系数齐次（A，6 次）

**卷面落点**：填空为主（2024-14 等）；解答位作为**下游**出现——2023-17（切线 → ODE）、2025-18（偏导 → 欧拉方程）、2026-18（偏导 → 二阶常系数）。

> **注意这个模式**：新卷型里微分方程**很少单独成题**，几乎都是「另一个东西先化成 ODE，再解」。所以练法不是练解方程，是练**认出它是哪一型**。

**可能的考法**：

| 题型 | 考法 | 证据 |
|---|---|---|
| 选择/填空 | 由给出的几个解反推特征根、特解形式、原方程（同题组 23） | 2008-3、2009-10、2013-10、2015-2、2016-3 |
| 填空 | 可分离变量 / 齐次型 / 变量代换后可解 | 2024-14 |
| 填空 | 欧拉方程（x²y″+axy′+by=f） | 2021-13、2025-18 |
| 填空/选择 | 写出二阶常系数非齐次的特解形式（不求系数） | 2007-13、2010-15、2012-9、2013-10、2015-2 |
| 解答 | 一阶线性：先化标准形，套公式 | 2019-15、2023-17 |
| 解答 | 可降阶（y″=f(x,y′) 或 y″=f(y,y′)） | 2025-18、2026-18 |
| 解答 | 几何/物理应用：由条件列出 ODE 再解 | 2004 起多次 |
| *未见但合法* | 全微分方程 · 伯努利方程（考纲内，22 年零出现） | — |

**认知模型 —— 「解方程之前先分类，分类只看形状」**

```
拿到方程，按这棵树往下走，不要跳步：

一阶？
├ y′ = f(x)g(y)          ──▶ 分离变量
├ y′ = f(y/x)            ──▶ 令 u=y/x（齐次型）
├ y′ + P(x)y = Q(x)      ──▶ 通解公式 y = e^{−∫P}[∫Q·e^{∫P}dx + C]
└ 都不像                  ──▶ 试换元（令 u=某个组合），换完再走一遍这棵树

二阶？
├ 缺 y   (y″=f(x,y′))    ──▶ 令 p=y′，降为一阶
├ 缺 x   (y″=f(y,y′))    ──▶ 令 p=y′，且 y″=p·dp/dy，降为一阶
├ y″+py′+qy=0            ──▶ 特征方程；三种根三种通解
├ y″+py′+qy=f(x)         ──▶ 齐次通解 + 特解（待定系数，看 f 的型）
└ x²y″+axy′+by=f         ──▶ 欧拉方程，令 x=e^t 化为常系数
```

**特解形式的待定规则**（这是填空的固定考法）：

| f(x) 的型 | 特解设成 | 若与齐次解重复 |
|---|---|---|
| Pₙ(x) | Qₙ(x) | 乘 x^k，k = 0 是特征根的重数 |
| Pₙ(x)e^{αx} | Qₙ(x)e^{αx} | 同上，看 α 是否为特征根 |
| e^{αx}(A cos βx + B sin βx) | e^{αx}(C cos βx + D sin βx) | 看 α±βi 是否为特征根 |

**「重复就乘 x^k」是本模块最集中的丢分点**，也是选择填空最爱考的一点。

**触发信号 → 动作**

| 看到 | 立刻 |
|---|---|
| 「已知 y₁, y₂, y₃ 是…的解」 | 作差得齐次解 → 反推特征根 → 反推方程 |
| 方程里有 x²y″ 和 xy′ | 欧拉方程 |
| ∂z/∂x 类的偏导最后凑成一个只含一个变量的方程 | 就是要解 ODE，回到这棵树 |
| 「求满足…的曲线」 | 先把几何条件翻成 y′ 的等式 |
| 求出通解 | **立刻检查有没有初值条件要代**（丢分常发生在这一步） |

**失分结构**：特解形式忘了乘 x^k · 一阶线性没先化成标准形就套公式 · 求出通解忘定常数 · 分类走错导致方法全错。

### 模块 11｜空间解析几何（主线 C）

**体量**：4 个考点 · 6 次 · 6 题 · 占 2%（**最小**）
**特点**：在本库的 6 次标注中**没有一次单独成题**，全部作为别的题的入口——旋转曲面的方程 3 次全在解答题，其中 2025-20 是高斯公式题的第一步。（n=6，样本描述。）

**可能的考法**：

| 考法 | 证据 |
|---|---|
| 求旋转曲面方程（直线绕直线转、曲线绕坐标轴转），作为积分题的第一步 | 2025-20 |
| 空间曲线在坐标面上的投影（定二重积分的区域） | 1 次 |
| 点到平面的距离 | 1 次 |
| 曲面面积的计算 | 1 次 |

**认知模型 —— 「解析几何是积分题的入场券」**

不要把它当独立模块练。练法是：**每做一道曲面/曲线积分题，先花 30 秒把几何体在脑子里立起来**——是锥面、柱面、球面还是抛物面，区域是哪一块。立不起来，后面的公式全用不上。

三个必须张口就来的转换：

```
曲线绕 z 轴转：把方程里的 x（或 y）换成 ±√(x²+y²)
平面 Ax+By+Cz+D=0 的法向量 = (A,B,C)
柱面 = 方程里缺一个变量（缺 z 就是母线平行 z 轴）
```

## 四、认知模型总表（一页速查）

| 模块 | 一句话模型 | 唯一要背的结构 |
|---|---|---|
| 极限与连续 | 一切极限 = 定阶 + 比主项系数 | 展开到几阶由**分母**定；加减处不许用等价无穷小 |
| 一元微分 | 导数同时是极限、斜率、增长率，考的是切换 | 极值/拐点同构：候选点 + **变号** |
| 中值定理 | 证明题是从结论**反推**辅助函数 | 移项凑导数；用几次定理由最高阶导数定 |
| 一元积分 | 变限积分是**函数**不是数 | 积分方法选择树；F 与 f 的奇偶/周期对应表 |
| 多元微分 | 先画依赖图再动笔 | 二阶偏导要**再走一遍全图**；闭区域最值 = 内部+边界+顶点 |
| 二重积分 | 难点全在定限，不在被积函数 | 画图 → 选坐标 → 定穿入穿出 |
| 三重积分 | 先对称、后坐标、最后算 | 雅可比因子 r / ρ²sinφ |
| 曲线曲面积分 | 边界上的积分 = 内部的积分 | **补域路线的三问判定树**：封闭？能补？有奇点？（**仅补域路线**，其余路线另判） |
| 级数 | 幂级数是一个能求导积分的函数 | 收敛域三步（端点单独判）；n 在分母先导、在分子先积 |
| 微分方程 | 解之前先分类，分类只看形状 | 分类树；特解重复就乘 x^k |
| 空间解析几何 | 它是积分题的入场券 | 旋转曲面换元法；法向量 = 系数 |

## 五、按考法组织的训练建议（不含日期）

数据支持的三条：

1. **中值定理证明单独拉出来练「只写辅助函数」。**统计事实：31 次标注里 30 次落在解答题、19 道职能为证明，2023–2026 连续 4 个样本各占一个解答位（2021 是唯一例外）。<br>教学判断（非统计字段）：在当前人工分析中，这类题对**关键构造与定理选择**的依赖较强，一步选错后续步骤难以补救，因此适合孤立强训。
2. **曲线曲面积分按「补域路线的三问判定树」横刷，不按公式分类刷**（该树只管补域这一条路线）。新卷型 5/5 必有一道，且同题组 5（7 题）、组 26 都是同一个「补/减」动作的重复。把补面、补线、挖奇点三种放在一起连着做，比分开做格林一天、高斯一天有效。
3. **多元微分的二阶偏导，练到画依赖图成为条件反射。**18 位 4/5 是它，且「漏一整项」是该位置最常见的错——这个错**不是不会，是没画图**。

配比按 `教学协议-考法驱动.md` §五：查该考点的「选/填/解」比例，按比例分配练习量。例如参数方程求二阶导 0/5/0——**5 次全在填空**，就不要给它出解答题。

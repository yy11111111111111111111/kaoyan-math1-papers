# 方法族 · 高数 · 空间解析几何与场量（v1.0.0 · Batch 3 · calc.space-geometry.route-selection）

## 0. 家族定位

本族处理**空间解析几何与场量计算的路线选择**：旋转曲面方程、空间曲线投影、
点面距离、以及散度与旋度的计算。

**为什么把「旋度与散度的计算」放进来**：它们不属 `calc.vector-integral`
（该族的 objects 是四类积分），单开三题一族不划算；
而它们与解析几何同属「**认公式 → 定参数 → 代入算**」的路由结构——
本族的全部难点都在「认对公式、定对参数」，不在计算本身。
这条归属理由写在 `METHOD_FAMILY_HANDOFF.md` 的 batch3_plan.note。

        kind: constructed_counterexample
        ref: |
          点 (1,2,3) 到平面 2x + 2y + z − 1 = 0。

          · 漏归一化：d = **8** —— 错 3 倍。

          = √(1+4+4) = 3 ≥ d，与 2.6667 相容，而与 8 矛盾。
        verification: verified
      recovery: 写公式时把分母的根号一并写出，不要分两步

    - boundary_id: B3
      changed_condition: 把散度与旋度混用（或由其一为零推另一为零）
      effect: invalidates
      explanation: div 产标量、curl 产向量，是两个独立的微分算子，互不蕴含。
      witness:
        kind: constructed_counterexample
        ref: |
          · F = (x, y, z)：div F = 1+1+1 = **3 ≠ 0**，
            而 curl F = (0−0, 0−0, 0−0) = **(0,0,0)**。
            ⇒ curl = 0 不蕴含 div = 0。
          · F = (−y, x, 0)：div F = 0 + 0 + 0 = **0**，
            而 curl F = (0−0, 0−0, 1−(−1)) = **(0,0,2) ≠ 0**。
            ⇒ div = 0 不蕴含 curl = 0。
          两个方向都有反例 ⇒ 两量彼此独立。
        verification: verified
      recovery: 先看所求应是一个数还是三个分量，再选算子

      changed_condition: 求空间曲线的投影时直接令被投影的变量为零

      explanation: >

        而投影是把整条曲线沿 z 方向压下来得到的曲线。两者完全不同。

        ref: |

            （一个椭圆）。
            数值检验：在 C 上取 5 个参数点代入 x²+y²+xy，结果**均为 3** ✔
          · **错误（令 z=0）**：得 {x² + y² = 6, x + y = 0}，
            解出仅 **两个点** (±√3, ∓√3, 0) —— 那是 C 与 xOy 面的交点，
            不是那个椭圆。
        verification: verified
      recovery: 回到 A2，从两个方程中消去该变量得投影柱面

        ref: |

          平方引入了原本不该有的那一半。
        verification: verified

## 3. 本族的特殊之处

**它是六族里唯一「不分叉」的族。**对象一旦认清，公式是唯一的，
没有真正的路线竞争。因此：

- `minimal_probe` 写成**核对表**而非决策树；
- guard 密度最高（八条里七条 necessary），且全部指向**参数认定**而非路线选择；
- 四条 constructed_counterexample 对应四种参数认错：
  绕错轴（B1）、漏归一化（B2）、div/curl 混淆（B3）、投影当交点（B4）。

审查时应特别注意：本族是否**过度使用了 method-family 这套 schema**——
一个不分叉的领域是否值得建族，是一个合理的质疑。
我的判断是值得，因为 schema 的 failure_boundaries 部分恰好承载了
本族的全部价值（那四种参数认错）；但这个判断应由独立审查方复核。

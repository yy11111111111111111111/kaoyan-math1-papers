# 方法族 · 高数 · 空间解析几何与场量（v1.0.0 · Batch 3 · calc.space-geometry.route-selection）

## 0. 家族定位

本族处理**空间解析几何与场量计算的路线选择**：旋转曲面方程、空间曲线投影、
点面距离、以及散度与旋度的计算。

**为什么把「旋度与散度的计算」放进来**：空间解析几何主要落在高数第四章，
而 div/curl 属第六章的向量微分算子；它们不属 `calc.vector-integral`
（该族的 objects 是四类积分），但样本仅三题，单开一族会过碎，故在本族保留
一个独立的场量 cell。归属边界以题目是否含曲线/曲面积分为准，而不是以是否出现向量场为准。
这条归属理由写在 `METHOD_FAMILY_HANDOFF.md` 的 batch3_plan.note。

      witness:
        kind: constructed_counterexample
        ref: |

## 3. 本族的特殊之处

本族先按对象落格，再在格内作真实的合法性分流：旋转曲面要在 A1/A1b/A1c
之间按母线与轴的位置选择；场量要在直接定义计算 A5/A6 与复合恒等式 A7
之间按算子结构选择。投影格虽只有 A2，也必须区分「消元必要方程」与
「存在实数原像的充分条件」，不能把核对表当作完整路线。

因此 `minimal_probe` 是决策树；guards 同时承担参数校验、路线分流与
必要/充分条件复核。failure boundaries 则明确记录绕错轴、漏归一化、
div/curl 混淆、投影当交点以及消元超集等不同失效机制。

# 方法族 · 高数 · 一元微分学（v1.0.0 · Batch 3 · calc.diff1v.route-selection）

## 0. 家族定位

本族处理**一元函数微分学的路线选择**：给定一个一元函数与一个微分学设问，
选择「怎么算、怎么判」。schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`，
字段语义与 `方法族-高数-第一批.md` §0 一致（S1 执行顺序、S2 optional_any_of、S3 kind 标注）。

**本族不含极限计算本身**——那是 `calc.limit.method-selection`（已冻结）的辖区。
本族只在「用导数定义求极限」这一处与它接壤，接口写在 A2 的 `boundary_note`。

          - { kind: local_operation, operation: 在每个区间内取一点定符号，列表 }
      terminal_when: [各区间的单调性或凹凸性均已判定]
      role: primary
      applies_when: [在所考察区间内相应阶导数存在（可数个例外点单独处理）]

      produces: subproblems
      followup_actions:

        actions:

      eligible_cells: [抽象函数]

        本族的 B1/B2/B3 就是三个可直接复用的反例。

  selection_rule:
    guards:
      - condition: >-
          **分段点的导数必须用定义（左右导数）求**，不得对两侧表达式分别求导后取极限代入。
        logical_role: necessary
        check: 所问点是否为分段点或表达式换写法处；是则强制走 A5/A2
        explanation: >
          f′ 未必连续。B8 给出 f(x)=x²sin(1/x)（f(0)=0）：用定义得 f′(0)=0 存在，
          而导函数公式 2x·sin(1/x) − cos(1/x) 在 x→0 无极限。
          「求导公式的极限」与「导数」是两回事。
      - condition: "A4b 的二阶导公式是 [d/dt(y′/x′)] / x′(t)，**不是** y″(t)/x″(t)"
        logical_role: necessary
        check: 写出中间步骤，确认外层 d/dx 时又除了一次 x′(t)
      - condition: "A4 / A4b 要求 x′(t) ≠ 0"
        logical_role: necessary
        check: 先解 x′(t)=0；这些 t 处需单独讨论（可能是尖点或竖直切线）
      - condition: >-
          斜渐近线要求 **k = lim f/x 与 b = lim(f − kx) 两个极限都存在且有限**。
        logical_role: necessary
        check: 两个极限分别验；k 存在而 b 发散时**没有**斜渐近线（B5）
      - condition: "拐点的判据是 f″ **变号**，不是 f″ = 0"
        logical_role: necessary
        check: 必须考察两侧符号，不能只解 f″=0
        explanation: "f=x⁴ 在 0 处 f″=0 但不变号，非拐点（B2）；f=x^{1/3} 在 0 处 f″ 不存在却变号，是拐点（B3）。两个方向都会错。"
      - condition: "极值候选点须含 **f′ 不存在但函数连续**的点"
        logical_role: necessary
        check: 除解 f′=0 外，另找 f′ 不存在的连续点
        explanation: f=|x| 在 0 处取极小值而 f′(0) 不存在；只解 f′=0 会漏。
      - condition: >-
          **「f′(x₀) > 0」只给出该点的瞬时性质，不蕴含 x₀ 的任何邻域内单调增。**
          要得到邻域内单调，需要 f′ 在该邻域内**处处**为正（例如 f′ 连续时才可由保号性推出）。
        logical_role: necessary
        check: 区分「一点的导数符号」与「一个区间上的导数符号」
        explanation: 见 B1——这是 2004-8 的考点，也是本族最容易想当然的一处。
      - condition: "可导 ⇒ 连续；连续 ⇏ 可导"
        logical_role: necessary
        check: 单向使用，不要反用
      - condition: "第二充分条件（f′=0 且 f″≠0）在 f″(x₀)=0 时**无结论**，须退回第一充分条件"
        logical_role: necessary
        check: 先算 f″(x₀)；为零则该条件不适用，不是「非极值」
      - condition: 多因子连乘时 A3（对数求导）通常比逐次乘法法则短
        logical_role: supporting_heuristic
        check: 数一下因子个数；三个以上考虑 A3
      - condition: >-
          求 f′(x₀) 而 f 是多因子乘积、且只有一个因子在 x₀ 处为零时，
          直接用定义 A2 常常一步到位（其余因子整体代值）
        logical_role: supporting_heuristic
        check: 看是否恰有一个因子在 x₀ 处取零
        explanation: 2012-2 型（n 个因子连乘求 f′(0)）即属此类。

    minimal_probe:
      action: |
        ① 读第一轴：函数是显式、参数式、分段还是抽象？
        ② 读第二轴：问的是求值、判正则性、求切线、求渐近线，还是判形态？
        ③ 若所问点是分段点或表达式换写法处 → **强制 A2/A5（定义）**，不进 A1。
        ④ 若为抽象函数 → A13，并优先考虑构造反例否定选项。
      interpretation: >
        · 显式 + 求值 → A1；因子多或幂指 → A3；单点且恰有一因子为零 → A2 更快。
        · 参数式 → A4，要二阶导再 A4b（**注意不是 y″/x″**）。
        · 分段点 → A5（左右导数）；问连续性或间断类型 → A6。
        · 渐近线 → A7，三类分别查，斜渐近线两个极限都要验。
        · 判形态 → A8 定符号；极值 A9（候选集含 f′ 不存在的连续点）；
          拐点 A10（**变号**，不是 f″=0）。
    preference_rule: >

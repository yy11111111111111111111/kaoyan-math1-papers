# 方法族 · 高数 · 一元微分学（v1.1.0 · Batch 3 · calc.diff1v.route-selection）

## 0. 家族定位

本族处理**一元函数微分学的路线选择**：给定一个一元函数与一个微分学设问，
选择「怎么算、怎么判」。schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`，
字段语义与 `方法族-高数-第一批.md` §0 一致（S1 执行顺序、S2 optional_any_of、S3 kind 标注）。

**本族不重复实现极限族已纳入 scope 的一般极限路线**。
但导数定义产出的单侧、含绝对值或含取整的分段差商极限不在
`calc.limit.method-selection`（已冻结）的 scope 内，因而由 A2 在本族就地分支处理；
只有接收方 scope 内的极限才外送。

# 方法族 · 高数 · 多元微分（v1.0.0 · Batch 2 · calc.multivar.route-selection）

## 0. 家族定位

本族处理**多元微分学的求导路线选择**：给定一个多元函数（显式 / 复合 / 隐式 / 抽象）
与一个微分类设问（偏导、全微分、方向导数、梯度、切平面、可微性判定、由 PDE 反推
函数），选择「怎么求」。与 batch1 的 vector 族、batch2 的 ODE 族一样采用两级 router：
一级做对象与设问分类（不产生 solver），二级在格内给出候选动作。
schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`，字段语义与 `方法族-高数-第一批.md` §0 一致
（S1 执行顺序、S2 optional_any_of、S3 kind 标注）。

### 0.1 一级 router 的设计取舍（两条从 ODE 族审查中吸取的教训）

本族的一级 router 刻意避开了 `calc.ode.route-selection` v1.0.0 被判 challenged 的
两个结构缺陷（见 `分析/审查/Codex-audit-ode-240c1dc.md` BL-1 / BL-2）：

1. **一级分类只产生「并行候选集」，不做排他跳转。**
   ODE 族写「若缺项，**直接落** second_order_reducible」，而每个常系数齐次方程
   都不显含 x，于是特征方程 route 被整格切断。本族的对应风险是「隐式」与「复合」
   同时成立（如 2010-2 的 `F(y/x, z/x)=0`：既是隐函数又是复合函数）。
   本族的处理是：**信号命中即把对应格的 action 并入候选集，多格可同时命中**，
   由 preference_rule 排序，不由 router 排他。
2. **逆向 route 必须有回到正向的 `action_ref`。**
   ODE 族的 B7 在「参数已定」处 terminal，而真题要的是初值问题的解。
   本族的两条逆向 route（C3 由切平面条件反求、E1 由 PDE 反推 f）都显式声明了
   后继：C3 → C1/C2 复核，E1 → 导出 ODE 后交 `calc.ode.route-selection`。

### 0.2 scope 边界

- objects：显式二/三元函数 z=f(x,y)、u=f(x,y,z)；多元复合函数（含抽象 f(u,v)、
  含变限积分定义的函数、复合回一元的 y=f(φ(x),ψ(x))）；由单个方程 F=0 或方程组
  确定的隐函数（含一元隐函数 y=y(x)）；只给出可微性/连续性等性质的抽象函数。
- target_tasks：求一阶/二阶偏导与全微分；方向导数与梯度（含最大方向导数）；
  曲面的切平面与法向量（含由切平面条件反求点或参数）；可微性/偏导存在性/连续性的
  判定与反例构造；由 PDE 条件反推函数 f（逆向）。
- exclusions（每条附排除理由）：
  - 多元函数的极值/最值/条件极值 —— `out_of_scope`：归 `calc.extrema.constraint-selection`
    （batch1，**已冻结**）。本族**不认领**主考点为极值/最值的题。
  - 二重/三重/曲线/曲面积分 —— `out_of_scope`：归 vector 族与（尚未建立的）重积分族。
  - 一元函数的导数、泰勒/幂级数展开求高阶导 —— `out_of_scope`：见 §2.2 的边界裁定。
  - 多元函数的极限存在性本身（二重极限的求法）—— `dominated_not_excluded`：
    本族只在可微性判定（D1/D2）里把它当工具用，不单独建格。
  - 隐函数存在定理的证明、反函数定理 —— `out_of_scope`：数学一只考条件判定，不考证明。
  - 方向导数的高阶推广、Hesse 矩阵的谱性质 —— `out_of_scope`：超大纲。

  mechanism:
    statement: |
      链式法则：z=f(u(x,y),v(x,y)) ⟹ ∂z/∂x = f₁′·u_x + f₂′·v_x（变量依赖树上每条路径一项）。

        故对隐式与复合都可两端取全微分再读系数。
      隐函数求导：F(x,y,z)=0，F_z≠0 ⟹ ∂z/∂x = −F_x/F_z，∂z/∂y = −F_y/F_z。

        方程组 {F=0,G=0} ⟹ 两端取全微分得线性组，系数行列式为雅可比行列式。

        ∂u/∂l = lim_{t→0⁺}[u(P+te_l)−u(P)]/t（单侧）。
      切平面：F(x,y,z)=0 在 P 处的法向量为 ∇F(P)；

        上下限（乘 b_x、a_x）与被积函数（积分号下求导）——两者都要算。

        按中间变量整理消去 x、y，得到关于 f 的常微分方程。

      本族所有 route 服务于同一个目标：**把「多元的求导」化归为「一元的求导」**。

      隐函数求导是用「方程两端同时求导」把未知的因变量的导数解出来；

      或原参数——它们的支撑是同一套微分关系，不是搜索结论。

      effect: invalidates

        kind: constructed_counterexample
        ref: |

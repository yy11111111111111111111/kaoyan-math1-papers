# 方法族 · 高数 · 多元函数微分学（v1.0.0 · Batch 2 · calc.multivar.route-selection）

## 0. 家族定位

本族处理**多元函数微分学的解路线选择**：给定一个多元函数（显式 / 隐式 / 复合 /
变限积分定义）与一个设问（求偏导 / 求全微分 / 求方向导数与梯度 / 判可微性 /
求切平面法向量 / 用齐次函数欧拉定理证明），选择「走哪条路」。沿用
`CALC-METHOD-FAMILY-v1.3.1` 与两级 router：一级做**对象 × 设问**分类、不产生
solver，二级在格内给候选动作。字段语义与 `方法族-高数-第一批.md` §0、
`方法族-高数-微分方程.md` §0、`方法族-高数-级数.md` §0 一致
（S1 执行顺序、S2 optional_any_of 的 on_skip、S3 kind 标注）。

### 0.1 一级路由的两条设计决定

1. **对象轴（object_type）把「极值与最值」整体转交已冻结的 extrema 族，本族不产生极值 solver。**
   按 HANDOFF 的 `scope_boundary_rule`，归属一律看 `考点标注.tsv` 每行的**主考点**。
   主考点为「条件极值与拉格朗日乘数法 / 多元函数无条件极值 / 多元函数在有界闭区域上
   的最值」的 12 题（2006-10、2008-17、2009-15、2011-3、2012-16、2013-17、2018-16、
   2021-19、2020-15、2023-18、2026-17、2007-17）整体判归已冻结的
   `calc.extrema.constraint-selection`。本族只在 `level_1_router` 的对象轴里保留
   「极值与最值」这一取值，路由文本明确指向 extrema 族，不设本族格。
   这是 scope_boundary_rule 的直接推论，不是本族的自主裁量。

2. **「复合 / 隐函数 / 变限积分」三种给出方式合并在一个格内，但求导机制各自独立成 action。**
   三者的共同点是「z 不是直接以 x,y 显式写出」，设问都落到「求 z 对 x,y 的偏导/
   全微分」，可共用一条 minimal_probe；但 IC1–IC5 各自的链式路径、公式、Leibniz
   因子完全不同，漏任何一个都是独立的错误源（F1–F6）。合并在一个格内使一级路由
   简短，拆成独立 action 使二级错误边界各自有家。

### 0.2 scope 边界（遵守 HANDOFF 的 scope_boundary_rule）

归属一律按 `考点标注.tsv` 每行**考点列的第一个**（主考点）。次考点跨族不改变归属，
本族也不把次考点命中的题算进自己的 scope_problems。

- **认领**：主考点为 隐函数求偏导 / 隐函数求导 / 隐函数存在定理的条件判定 /
  多元复合函数的二阶偏导数 / 多元复合函数求偏导 / 变限积分求偏导 / 方向导数计算 /
  方向导数与梯度的最大值 / 梯度的计算 / 多元函数可微的充分必要条件 /
  曲面的切平面与法向量 / 齐次函数的欧拉定理 —— 共 **40 题**（清单见 §2）。
- **不认领极值/最值 12 题**：主考点为 条件极值与拉格朗日乘数法（4）/ 多元函数无条件
  极值（7）/ 多元函数在有界闭区域上的最值（1），按 scope_boundary_rule 归已冻结的
  `calc.extrema.constraint-selection`。其中 2004-19 / 2015-17 / 2019-16 / 2024-18
  的主考点属本族、在 extrema 族的旧 evidence 清单里仍挂着（旧口径遗留），见 §5 第 3 条。
- **不认领空间解析几何 7 题**：旋转曲面的方程（2009-17、2013-19、2025-20）/
  空间曲线在坐标面上的投影（2017-19）/ 二次曲面的标准方程与正负惯性指数
  （2008-6、2016-6、2026-7）——三者属空间解析几何 / 二次型（线性代数），
  不在多元函数微分学，`out_of_scope`。
- **不认领一元参数方程 5 题**：参数方程求二阶导数（2010-9、2013-11、2020-10、
  2021-12、2026-13）——dy/dx 是一元函数求导（一元微分学内容），`out_of_scope`。
- **不认领场论 3 题**：旋度与散度的计算（2016-10、2018-11、2026-11）——
  旋度/散度属向量场 / 多元积分学（场论）内容，不在多元函数微分学，`out_of_scope`。
- **无多元极限/连续主考点真题**：TSV 中极限/连续相关主考点全部是一元语境
  （等价无穷小替换、夹逼准则、分段函数的连续性等），本族 `limit_continuity` 格
  按大纲结构声明 route universe，LC1/LC2 以 `not_found` 记录，不因未出现而排除。
- objects：二元/三元实值函数及其偏导数、全微分、梯度；隐函数、复合函数、变限积分
  定义的函数；曲面（切平面/法向量）、齐次函数。
- target_tasks：求一阶/二阶偏导（含混合偏导）、求全微分、求方向导数与梯度、
  求最大方向导数、判可微性、求曲面的切平面方程与法向量、用齐次函数欧拉定理证明
  线积分为零、判多元极限与连续（结构上声明，无真题）。

        explanation: 显式曲面误取 (f_x,f_y,1) 会得到错误法向量与切平面（F11）

        explanation: 符号写反会把恒为零的旋度变成非零值（F13）

        explanation: 可微是更强的条件；反过来「偏导存在」或「连续」都不足以推可微（F7、F8）
      - condition: "「偏导数连续」⇒「可微」（可微的充分条件）"
        logical_role: sufficient
        check: 若各偏导在某邻域内连续，则直接判定可微
        explanation: 这是**充分条件**，不是必要条件；偏导不连续不蕴含不可微，故不得写成 necessary
      - condition: "「f(tx,ty)=t^λ f(x,y)（f 可微）」⇒「x f_x + y f_y = λ f」（欧拉定理）"
        logical_role: sufficient
        check: 齐次关系满足时直接引用欧拉恒等式
        explanation: 欧拉定理对可微齐次函数成立，是充分保证；不是必要条件
      - condition: "「lim f(x,y)/(|x|+|y|) 存在」⇒「f(0,0) 可微」（f(0,0)=0 时）"
        logical_role: sufficient
        check: "极限存在即 f=o(|x|+|y|)=o(ρ)，故可微且 f_x=f_y=0"
        explanation: 这是 2012-3 (A) 的机制：高阶小 ⟹ 可微；反向不成立（可微未必有该极限形式）

        explanation: 存在定理给出的是充分条件；偏导为零不代表一定不可解，只说明定理在此不给结论（F4 边界）

        explanation: 效率/防漏偏好。直接凭感觉写容易漏路径（F1）

        explanation: 书写顺序偏好；嵌套链式可系统化避免漏项（F2）
      - condition: "隐函数求导优先公式法（−F_x/F_z），直接法（两边对 x 求导）作等价备用"
        logical_role: supporting_heuristic

        explanation: 两种方法都合法，选择取决于书写习惯；选「不顺手」的不改变结果
      - condition: "方向导数与梯度类题先求梯度，再处理方向/模，避免重复计算"
        logical_role: supporting_heuristic
        check: 一次求出 ∇f，随后所有方向导数/最大方向导数都从它派生
        explanation: 效率偏好。多问共用一个梯度，重算浪费时间
      - condition: "切平面题先判断显式/隐式，再取法向量"
        logical_role: supporting_heuristic
        check: 看到 z=f(x,y) 用 (−f_x,−f_y,1)，看到 F(x,y,z)=0 用 ∇F
        explanation: 识别偏好；判断错直接导致法向量错（F11）

  mechanism:
    statement: |
      链式法则：z=f(u,v)、u=u(x,y)、v=v(x,y) ⇒ ∂z/∂x = f_u·u_x + f_v·v_x。
        二阶：∂²z/∂x∂y = (f_uu·u_y+f_uv·v_y)·u_x + f_u·u_xy + (f_vu·u_y+f_vv·v_y)·v_x + f_v·v_xy；
        f 二阶连续 ⇒ f_uv=f_vu，混合项按路径合并。
      隐函数求导：F(x,y,z)=0、F_z≠0 ⇒ ∂z/∂x = −F_x/F_z、∂z/∂y = −F_y/F_z。
        隐函数存在定理：F(x0,y0,z0)=0 且 F_v≠0 ⇒ v 在邻域内唯一表示为其余变量的
        连续可微函数。
      变限积分求偏导（Leibniz）：∂/∂x ∫_{a(x,y)}^{b(x,y)} f(x,y,t)dt =
        f(x,y,b)·b_x − f(x,y,a)·a_x + ∫_a^b f_x(x,y,t)dt。
      全微分：dz = f_x dx + f_y dy；df 的线性性 df = f_u du + f_v dv。
      方向导数与梯度：方向导数 ∂f/∂l = ∇f·e（e 为单位方向向量）；梯度
        grad f = (f_x,f_y,f_z)；最大方向导数 = |∇f|（沿梯度方向），最小 = −|∇f|。
      可微性：f 在 (x0,y0) 可微 ⟺ Δf = f_xΔx+f_yΔy+o(ρ)，ρ=√(Δx²+Δy²)。
        必要条件：可微 ⇒ 连续、偏导存在；充分条件：偏导连续 ⇒ 可微。
        反例：f=xy/√(x²+y²)（f(0,0)=0）偏导存在但不可微；f=|x|+|y| 连续但不可微。
      切平面与法向量：显式 z=f(x,y) 的法向量 (−f_x,−f_y,1)；隐式 F=0 的法向量
        ∇F=(F_x,F_y,F_z)。切平面与 xOy 面垂直 ⇔ 法向量 z 分量为 0。
      齐次函数欧拉定理：f(tx,ty)=t^λ f(x,y)（f 可微）⇒ x f_x + y f_y = λ f。
        2006-19：λ=−2 ⇒ x f_x + y f_y = −2f。
      格林公式：∮_L P dx+Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dσ（D 为单连通域、P,Q 连续可导）。
      多元极限与连续：多元极限与路径有关；「沿任何直线路径一致」不足证存在。
        连续 ⟺ lim_{(x,y)→(x0,y0)} f(x,y) = f(x0,y0)。
    why_action_follows: |
      本族的一切操作只服务于一个目标：**把「z 对 x,y 的偏导/微分」从函数的给出方式
      中解出来**。函数不外乎三种给出方式——显式、隐式（方程）、复合——外加
      变限积分定义；求偏导的机制也按给出方式分立：链式法则拆复合、公式法拆隐式、
      Leibniz 拆变限积分。因此「复合/隐函数」合并为一个格（给出方式），而每种
      求导机制独立成 action（错误边界各归其位）。
      方向导数与梯度、切平面与法向量是**同一套一阶偏导信息（梯度）的两个消费端**：
      方向导数 = 梯度点乘单位方向，切平面法向量 = 梯度（或显式的 −(f_x,f_y,−1)）。
      所以它们各成一格，但都从「先求梯度」起步，这也是 DG1/DG2/DG3 与 ST1 共享
      minimal_probe 的原因。
      可微性之所以单列一格，是因为它的判据不是「算出来」而是「核验一个高阶小
      条件 o(ρ)」——偏导存在与连续都不足以回答，必须回到定义（D1）或它的几何
      翻译（D2）。
      齐次函数欧拉定理是「应用」格：它不直接求偏导，而是把齐次关系翻译成一个
      恒等式（HE1），再把这个恒等式接进格林公式证明线积分为零（HE2）。这是一条
      与求导不同的路由，故独立成格。
      极值/最值不是微分学求导的延续而是另一族的路由（见 F15 的 changes_branch），
      故按 scope_boundary_rule 整体转交已冻结的 calc.extrema。

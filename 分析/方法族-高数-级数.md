# 方法族 · 高数 · 级数（v1.0.0 · Batch 2 · calc.series.route-selection）

## 0. 家族定位

本族处理**无穷级数的解路线选择**：给定一个级数（数项 / 幂级数 / 傅里叶级数）与一个
设问（判敛散 / 求和 / 求收敛域 / 展开 / 由级数反推），选择「走哪条路」。沿用
`CALC-METHOD-FAMILY-v1.3.1` 与两级 router：一级做**对象 × 设问**分类、不产生 solver，
二级在格内给候选动作。字段语义与 `方法族-高数-第一批.md` §0、`方法族-高数-微分方程.md`
§0 一致（S1 执行顺序、S2 optional_any_of 的 on_skip、S3 kind 标注）。

### 0.1 一级路由的两条设计决定

1. **设问轴（task）与对象轴同等重要，不是附属维度。**
   同一个幂级数，问「收敛域」走 D 格、问「和函数」走 G 格、问「由已知敛散反推」
   走 D5——三条是不同路由，不是一条路由的三个阶段。F15 给出了「判敛散 → 求和」
   这一步为什么是 `changes_branch` 而不是同一路线的延续。

2. **收敛域的端点判定被单独立为一个 action（D2），不并进求收敛半径（D1）。**
   D1 只产出 R 与开区间，D1 的 followup 以 `mode: sequence` **强制**转 D2——
   不是 `optional_any_of`，因为跳过端点判定不是「省一步」而是给出错误答案（F2）。
   同一个 R=1 可以对应 `(−1,1)`、`[−1,1)`、`[−1,1]` 三种收敛域，R 本身不决定收敛域。
   另有 F1：求 R 用的那一次比值判别法在端点必然给出 ρ=1，**该判别法在端点不给结论**，
   所以端点必须换判据重判，这是 `becomes_inconclusive` 而不是 `invalidates`。

### 0.2 scope 边界（遵守 HANDOFF 的 scope_boundary_rule）

归属一律按 `考点标注.tsv` 每行**考点列的第一个**（主考点）。次考点跨族不改变归属，
本族也不把次考点命中的题算进自己的 scope_problems。

- **认领**：主考点为 傅里叶级数的奇偶延拓 / 傅里叶级数的收敛定理 / 函数展开成幂级数 /
  幂级数的收敛半径与收敛域 / 幂级数系数递推与微分方程 / 数项级数求和 /
  正项级数敛散性的比较判别法 / 级数敛散性的判定与反例 / 绝对收敛与条件收敛 /
  逐项积分求和函数 —— 共 **27 题**（清单见 §2）。
- **不认领 2014-19**：主考点为「夹逼准则求极限」，归已冻结的
  `calc.limit.method-selection`；「正项级数敛散性的比较判别法」只是它的次考点。
- **认领 2019-3**：主考点为「级数敛散性的判定与反例」，属本族。
- **与多元微分族实测重叠 0 题**（HANDOFF 已实测），本族未认领任何多元微分主考点的题。
- **2007-20 / 2013-16 / 2020-17**（幂级数系数递推与微分方程）：ODE 族在其
  `exclusions` 中已把「级数-ODE 混合题的整体」判给本族，本族**接收**这三题，
  其中的 ODE 求解子步骤以 `action_ref` 之外的 `local_operation` 表达，不重复定义
  ODE 族的 action（两族不得对同一题给出竞争路由）。
- **2010-3 / 2016-1**（主考点「反常积分的敛散性判别」）：机制与正项级数比较判别法
  同源，但主考点不是级数，**本族不认领**；边界疑问写入 §5 open_questions 交
  integrator 裁定，不自行改 TSV。
- objects：数项级数（正项 / 交错 / 任意项）、幂级数、傅里叶级数。
- target_tasks：判敛散（含绝对/条件收敛的区分）、求和（数项与和函数）、求收敛半径
  与收敛域、函数展开成幂级数、傅里叶级数的系数与某点的和、由级数反推
  （由已知敛散数据反推 R/收敛域、由展开式反读系数、由系数递推反推和函数）。

  mechanism:
    statement: |
      必要条件：Σaₙ 收敛 ⇒ aₙ→0。逆否为发散判据；反向不成立（Σ1/n）。
      比较判别法（极限形式）：aₙ,bₙ>0 且 aₙ/bₙ→λ∈(0,∞) ⇒ 同敛散；
        参照物 Σ1/n^p 在 p>1 收敛、p≤1 发散。
      比值/根值：ρ=lim aₙ₊₁/aₙ 或 lim (aₙ)^{1/n}（必要时取上极限），
        ρ<1 收敛、ρ>1 发散、ρ=1 该判别法不给结论。
      积分判别法：f 在 [N,∞) 非负连续单调减、aₙ=f(n) ⇒ Σaₙ 与 ∫_N^∞ f 同敛散。
      莱布尼茨：aₙ>0 单调减且 aₙ→0 ⇒ Σ(−1)ⁿaₙ 收敛，且余项 |Rₙ|≤aₙ₊₁。
      绝对/条件：Σ|aₙ| 收敛 ⇒ Σaₙ 收敛（绝对收敛）；Σ|aₙ| 发散而 Σaₙ 收敛
        ⇒ 条件收敛；两者都发散 ⇒ 发散。三分，不是二分。
      阿贝尔定理：Σaₙ(x−x₀)ⁿ 在 x₁ 收敛 ⇒ 在 |x−x₀|<|x₁−x₀| 上绝对收敛；
        在 x₂ 发散 ⇒ 在 |x−x₀|>|x₂−x₀| 上发散。故存在 R，
        1/R = limsup|aₙ|^{1/n}（柯西–阿达玛）。**端点 |x−x₀|=R 上定理不给结论。**
      内闭一致收敛与逐项操作：幂级数在 (x₀−R,x₀+R) 的任一闭子区间上一致收敛，
        故在开区间内可逐项求导与逐项积分，所得级数的收敛半径仍为 R
        （**收敛域可变**）。和函数在**收敛域**上连续，故端点的和可由内部取单侧极限。
      四个基本展开式：1/(1−x)=Σxⁿ (|x|<1)；eˣ=Σxⁿ/n! (ℝ)；
        sin x=Σ(−1)ⁿx^{2n+1}/(2n+1)! (ℝ)；ln(1+x)=Σ(−1)ⁿ⁻¹xⁿ/n (−1<x≤1)。
        其余展开由换元、逐项求导/积分、部分分式从这四式派生。
      泰勒展开成立的条件：f 有各阶导数**且**余项 Rₙ(x)→0；
        仅有各阶导数不足以保证泰勒级数收敛到 f。
      系数递推 ⇄ 微分方程：两边乘 xⁿ 求和，Σn(n−1)aₙxⁿ⁻²=S″、Σn aₙxⁿ⁻¹=S′、
        Σaₙxⁿ=S；指标平移时落单的首项必须显式保留。
      傅里叶收敛定理（狄利克雷）：f 在一个周期上分段单调、只有有限个第一类间断点
        ⇒ 其傅里叶级数处处收敛，连续点收敛到 f(x)，间断点收敛到
        [f(x⁻)+f(x⁺)]/2。**求点值不需要系数。**
      奇偶延拓：[0,l] 上的 f 作奇延拓得正弦级数（只有 bₙ）、作偶延拓得余弦级数
        （只有 aₙ），两者延拓后周期均为 2l。
    why_action_follows: |
      本族的一切操作只服务于两个目标之一：**判定一个极限存在与否**（敛散），
      或**把级数凑成一个已知的闭式**（求和 / 展开）。
      判敛散的全部机制是「与已知敛散的参照物比较」——Σ1/n^p 之于比较判别法、
      几何级数之于比值与根值、∫f 之于积分判别法、交错的部分和夹逼之于莱布尼茨。
      求和与展开的全部机制是「凑成 Σxⁿ=1/(1−x) 及其三个亲戚」——逐项求导与
      逐项积分是把通项里的 n 搬掉的两个互逆操作，部分分式与拆项是把复合结构
      还原成这四式的线性组合，造辅助幂级数是把没有 x 的问题人为地放进有 x 的
      框架里以便使用这些操作。
      幂级数的收敛域之所以必须分两步（R 与端点），是因为阿贝尔定理只对
      |x−x₀|<R 与 |x−x₀|>R 两侧给结论，**在 |x−x₀|=R 上它沉默**——
      端点不是「顺带」的，是定理明确不覆盖的区域。
      傅里叶部分之所以把「求点值」与「算系数」分成两条 route，是因为收敛定理
      直接给出点值，不经过系数；把它们混成一条会让每道点值题都退化成积分计算。

# 方法族 · 高数 · 微分方程（v1.0.0 · Batch 2 · calc.ode.route-selection）

## 0. 家族定位

本族处理**微分方程的解路线选择**：给定一个（或一组）常微分方程，选择「怎么解」。
与 batch1 的 vector 族一样采用两级 router：一级做对象分类（不产生 solver），
二级在格内给出候选动作。schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`，字段语义与
`方法族-高数-第一批.md` §0 完全一致（S1 执行顺序、S2 optional_any_of、S3 kind 标注）。

### 0.1 与建议路由器的关系（采纳 + 两处修正）

任务给的一级建议链是 **阶数 → 是否线性 → 系数是否常数 → 齐次/非齐次**。本族采纳
其中四根轴，但做两处修正（理由如下，不是照抄）：

1. **一阶非线性需按「形式」在二级细分**（可分离 / 齐次型 u=y/x / 伯努利 / ax+by+c /
   全微分与积分因子）。这四条在数学上是并列的识别型 route，不能压成一格。
2. **二阶分支先查「缺项信号」（不含 y 或缺 x）再查线性**。可降阶路线对线性与非线性
   方程同样适用——2006-18 的 `f″+f′/u=0` 是**线性**方程，却走可降阶（缺 f）；
   若先按线性把它分进「变系数」格，欧拉（B3）对该题虽可用（乘 u² 即欧拉形
   u²f″+uf′=0，换元 u=e^t 得 D²f=0），但缺 f 的降阶（B4）更直接、不依赖识别欧拉形。
   因此「缺项」是比「线性」更早、更决定方法选择的信号。

### 0.2 scope 边界

- objects：一阶常微分方程（可分离、一阶线性、齐次型、伯努利、ax+by+c、全微分/积分因子）；
  二阶及可降阶高阶（常系数线性齐次/非齐次、欧拉方程、可降阶缺 y/缺 x、已知一特解降阶）；
  由解的结构反推方程（线性方程的逆向问题）。
- target_tasks：求通解/特解（含由初值条件定常数）；由解的结构反推方程、参数或通解（逆向）；
  判定解的性质（有界性、周期性、反常积分收敛性与取值）。
- 应用题的「列方程」步骤以 A0（应用建模）入册：本族路由从**已列出的方程**开始做
  方法选择，列方程是前置预处理，落在 A0。

  mechanism:
    statement: |
      一阶线性：y′+P(x)y=Q(x) ⟺ (μy)′=μQ，μ=e^{∫P dx}，故
        y = e^{−∫P dx}·( ∫ Q(x)·e^{∫P dx} dx + C )。
      可分离：dy/dx=f(x)g(y) ⟹ ∫ dy/g(y) = ∫ f(x)dx + C（g(y)≠0 支上）。
      齐次型：y′=f(y/x)，令 u=y/x，得 u′=(f(u)−u)/x（可分离）。
      伯努利：y′+P(x)y=Q(x)yⁿ（n≠0,1），令 u=y^{1−n}，得
        u′+(1−n)P(x)u=(1−n)Q(x)（一阶线性）。
      全微分：M dx+N dy=0 且 M_y=N_x（单连通）⟹ 存在 φ，dφ=M dx+N dy，
        通解 φ(x,y)=C。
      特征方程（常系数齐次）：y″+py′+qy=0 ⟹ r²+pr+q=0，
        Δ>0：C₁e^{r₁x}+C₂e^{r₂x}；Δ=0：(C₁+C₂x)e^{rx}；Δ<0：e^{αx}(C₁cosβx+C₂sinβx)。
      待定系数（常系数非齐次）：y″+py′+qy=P_n(x)e^{λx}，
        特解 y*=x^k·e^{λx}·Q_n(x)，k=λ 作为特征根的重数；
        右端为 e^{αx}(Acosβx+Bsinβx) 时设 y*=x^k·e^{αx}(Ccosβx+Dsinβx)。
      欧拉方程：x²y″+axy′+by=f(x)，令 x=e^t、D=d/dt：
        x²y″=D(D−1)y，xy′=Dy，化常系数方程。
      可降阶·缺 y：y″=f(x,y′)，令 p=y′（x 的函数），y″=p′ ⟹ p′=f(x,p)。
      可降阶·缺 x：y″=f(y,y′)，令 p=y′（y 的函数），y″=p·dp/dy ⟹ p·(dp/dy)=f(y,p)。
      已知一特解（刘维尔）：y″+P(x)y′+Q(x)y=0 已知非零解 y₁，令 y=y₁∫u dx，
        化为一阶线性方程。
      逆向反推：线性方程两个解之差是齐次解；由齐次解的通解形态读特征根 → 反推
        常系数与方程；变系数时由两个线性无关齐次解经 Wronskian 反推系数。
    why_action_follows: |
      所有 route 都服务于「把未知函数 y 求出来」这一个目标：
      一阶是「积分一次」，二阶常系数/欧拉是「化到代数条件（特征方程）或一阶」，
      可降阶是「把阶数降下来」，逆向是「从解的结构读回方程」。
      一阶线性公式的本质是 (μy)′=μQ 的凑导数观察；特征方程的本质是假设 y=e^{rx}
      代入得到的代数条件；欧拉变换的本质是 x^k 型系数在 x=e^t 下变为常数；
      可降阶的本质是利用缺项把 y″ 写成 (y′)′ 或 (1/2)(y′²)′ 型。
      逆向反推的支撑是解的结构定理（线性方程解集的仿射结构），不是搜索结论。

  failure_boundaries:
    - boundary_id: F1
      changed_condition: 把变系数线性方程当常系数用特征方程
      effect: invalidates
      explanation: 特征方程法要求 p、q 为常数；变系数时「特征根」变成 x 的函数，解无法写成常系数形式
      witness:
        kind: constructed_counterexample
        ref: |
          y″ + x·y′ = 0（变系数）。若按常系数写特征方程 r² + x·r = 0，
          得 r = 0 或 r = −x。「−x」随 x 变化，不是常数，无法形成 C₁e^{r₁x}+C₂e^{r₂x} 型通解。
          正确解法（B4 缺 y）：令 p=y′，p′ + x·p = 0 → dp/p = −x dx →
          p = C·e^{−x²/2} → y = C∫e^{−x²/2}dx + D（含误差函数，与任何常系数形式不符）。
          ⇒ 特征方程 route 在该条件下给不出正确结果，直接 invalidates。
        verification: verified
      recovery: 变系数只能走欧拉（若为欧拉形）、已知一特解降阶或幂级数（级数族）
    - boundary_id: F2
      changed_condition: 待定系数法设定特解时漏乘 x^k（λ 与特征根重复）
      effect: invalidates
      explanation: 特解与齐次解线性相关时，未乘 x^k 的特解代入非齐次方程左端恒为零，无法定出系数
      witness:
        kind: constructed_counterexample
        ref: |
          求 y″ − 2y′ + y = e^x 的一个特解。对应齐次方程 y″−2y′+y=0 的
          特征方程 (r−1)²=0，齐次通解 (C₁+C₂x)e^x，λ=1 是二重特征根。
          · 设 y*=Ae^x：y*″−2y*′+y* = (A−2A+A)e^x = 0 ≠ e^x，矛盾；
          · 设 y*=Axe^x：y*″−2y*′+y* = 0 ≠ e^x，仍矛盾；
          · 设 y*=Ax²e^x：y*″−2y*′+y* = 2Ae^x = e^x → A=1/2。
          只有乘 x² 的形式能成立。若漏乘 x^k（k=2），特解无法待定 → invalidates。
        verification: verified
      recovery: 先写齐次通解与全部特征根，再设定特解并核对重数
    - boundary_id: F3
      changed_condition: 欧拉变换把 x²y″ 错写成 D²y（漏 −D）
      effect: invalidates
      explanation: x²y″ 应换成 D(D−1)y；写成 D²y 会丢掉 −D 项，特征方程随之错误
      witness:
        kind: constructed_counterexample
        ref: |
          2004-4：x²y″+4xy′+2y=0（x>0）。令 x=e^t、D=d/dt：
          正确：x²y″=D(D−1)y=(D²−D)y，xy′=Dy，
            (D²−D)y+4Dy+2y=0 → (D²+3D+2)y=0 → r²+3r+2=0 → r=−1,−2
            → y=C₁e^{−t}+C₂e^{−2t}=C₁/x+C₂/x²。
          错误：把 x²y″ 写成 D²y → (D²+4D+2)y=0 → r²+4r+2=0 → r=−2±√2
            → 通解 y=C₁e^{(−2+√2)t}+C₂e^{(−2−√2)t}，代入原方程不成立。
          ⇒ 漏 −D 直接改变结果，invalidates。
        verification: verified
      recovery: 重写方程时逐项核对替换表 D(D−1)y ↔ x²y″、Dy ↔ xy′
    - boundary_id: F4
      changed_condition: 可分离变量时 g(y)=0 的常数解被公式整体丢掉
      effect: becomes_inconclusive
      explanation: 分离公式 ∫dy/g(y)=∫f(x)dx+C 只在 g(y)≠0 的支上成立；初值落在常数解上时公式给不出满足初值的解
      witness:
        kind: constructed_counterexample
        ref: |
          求 y′ = y² 满足 y(0)=0 的解。分离：dy/y² = dx → −1/y = x+C，
          任何有限 C 都不能满足 y(0)=0（−1/0 无定义）。
          而 y ≡ 0 是解（g(y)=y² 的零点，y′ = 0² = 0 ✓）。
          若只写公式解，会得出「无解满足初值」的错误结论；必须补检常数解 y≡0。
          ⇒ 仅靠分离公式无法确定完整解集，becomes_inconclusive。
        verification: verified
      recovery: 分离后补检 g(y)=0 的常数解并入解集
    - boundary_id: F5
      changed_condition: 缺 x 方程误用缺 y 换元（把 p 当 x 的函数）
      effect: becomes_inconclusive
      explanation: 缺 x 方程 y″=f(y,y′) 必须令 p=y′(y)、y″=p·dp/dy；若令 p=y′(x)、y″=p′，则 p′=f(y,p) 仍含 y 与 p 两个变量，降阶不彻底
      witness:
        kind: constructed_counterexample
        ref: |

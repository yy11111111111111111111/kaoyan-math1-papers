# GPT 接入包

> **给谁看**：你（用户）。这份告诉你**怎么把 `分析/` 这批资料交给 ChatGPT**，以及交完之后 GPT 该按什么规矩用它。
> **给 GPT 看的入口是 `交接说明-教学AI.md`**（那份是写给 AI 的、自足）；本文是操作手册。
> 本文件不是 `/analyze` 产物，重跑不会覆盖。

---

## 一、三种接法，按场景选

| 接法 | 适用 | 怎么做 | 代价 |
|---|---|---|---|
| **A. 建一个 Custom GPT** ✅推荐 | 长期当复习教练用 | 把 §二 的文件传进「知识库」，把 §三 的指令粘进「Instructions」 | 知识库**最多 20 个文件**，`分析/` 现有 26 个，必须挑 |
| **B. 普通对话里直接上传** | 只想问几次 | 一次传 §二 的档 1 + 档 2 | 每开新对话都要重传；上下文一满就开始忘 |
| **C. 给 GitHub 原始链接** | GPT 能联网时 | 给它 `raw.githubusercontent.com` 的文件链接 | **仓库是 private，这条现在用不了**；且联网读取不稳定 |

**默认走 A。**

## 三、粘进 Custom GPT「Instructions」的指令

以下整段复制。

```
你是我的考研数学（一）复习教练。你的全部依据是我上传的 2004–2026 年真题分析
资料（22 个年份、499 题、223 个考点）。以下规则优先于你的任何常识判断。

【第一步永远是查资料，不是讲知识】
我说「我要学 XX」时，你先从资料里查出六格再开口：
① XX 在 22 年里出现几次、哪些年、其中作主考点几次
② 题型落点：选 a / 填 b / 解 c；落在解答题时的职能（计算 / 积分 / 证明）
③ 新卷型 5 卷（2021、2023–2026）出现几次 → 标记（稳定·近年活跃 / 稳定 / 盲区 / 低证据）
④ 常和哪些考点同题出现（查《考试价值排序》的组合关系一节）
⑤ 要建立的认知模型（查《高数逐考点认知模型》的对应行）
⑥ 训练配比：按 ② 的选 / 填 / 解比例分配练习量，不平均分
查不到就说「资料里没有这一项」，不要用常识补。

【三条硬禁令】
1. 不押题。《命题模型》的检验 B 与检验 G 对考点层的时间结构**均未检出信号**：
   B（相邻年重复）p=0.154；G（空窗→下一场出现）风险比 0.92，95% 区间 [0.77, 1.11]。
   ⚠️ 这是「未检出」，不是「已证明无记忆」——小于约 11% 的效应本检验没有功率排除。在本数据下表现出样本内稳定性的只有「功能位」
   这一层：新卷型 5 个样本的 22 个题位科目归属逐位不变（引用须同时报 n=5 与 2021 的例外），17 计算型功能位、18 多元微分、
   19/20 一道多元积分 + 一道中值定理证明（顺序可换）、21 线代、22 概率。
   除此之外一律拒绝预测。
2. 不把《解法.md》的数值当标准答案。它 499 节全部标着 status: 待核对，是从题面
   独立推断的、没参考官方答案。你可以用它的思路和易错处；引用结论必须声明
   「这是推断路径，未经核对，以标准答案为准」。
3. 资料里没有的维度不许编。特别是：这批数据**没有**「定义 / 解释 / 案例分析各占
   多少百分比」这种考法占比（数学一也没有名词解释、简答、论述、案例题），只有
   题型（选择 / 填空 / 解答）和解答职能（计算 / 积分 / 证明）。**逐题分值也没有**，
   只能给到题型级：现行卷选填每题 5 分、解答 70 分 / 6 题。

【模考卷禁令】
2024、2025、2026 三套卷是我留作模考的，在 2026-11-29 之前不要向我展示这三年的
任何完整题目。单题引用作对比可以，成套不行。

【三道题不能用】
2023-9、2024-13、2025-10 题面残缺，出题和讲解一律跳过。另有 15 道题的解题路径
带题面假设（见《待确认》），讲之前先声明题面存疑。

【出题的四级优先，不许凭印象编题】
1. 直接用真题（从《考点标注.tsv》按考点或题型筛题号）——唯一保证题目本身没问题的方式
2. 用《同题识别》的 35 个确定同题组做变式（组内解题路径相同、包装不同）
3. 自己改编真题——必须声明是改编，且改完自己走一遍确认有解
4. 完全原创——只在前三条都不适用时用，必须声明
出题时给：题目、来源题号、所属功能位、分值与建议用时（选填 3–4 分钟、
解答 13–15 分钟）。不给：答案（除非我做完了）、该用哪个方法、难度预判。

【我做错题时】
先归错误类型再讲方法。只用这七类：概念混淆 / 条件遗漏 / 方向与符号 / 边界与端点 /
计算失误 / 审题 / 无思路。记录格式固定为「知识点 + 考法 + 错误类型」，
不是「第 N 题错了」。只讲方法不归类型，我下次还错同一处。

【给我学习任务时必须说明为什么选它】
格式：22 年出现 N 次 · 题型落点 · 新卷型 K 次 · 常见搭档 · 我的表现（有数据才写）
⇒ 优先级。缺依据就说缺，不要用感觉补。

【语气】
不要说「这题很简单 / 很难」——资料里没有难度字段。
不要因为某考点低频就说「不用学」——低频标记为「低证据」，不是「不重要」。
答不了就直接说「22 年数据无法支持这个结论」，不要猜。
```

## 四、传完之后，先用这三题验它是不是真读了

| 问它 | 合格 | 不合格 |
|---|---|---|
| 「泰勒公式重要吗？」 | 说出 **17 次（全库第一）、6/7/4 的题型落点**，并指出**不要解释它为什么高频**——检验 E 已作废，本库答不了；只报事实：17 次、6/7/4 | 「非常重要，一定要掌握」 |
| 「2027 年会考什么？」 | 给出卷面座位表与四个解答位的职能（**同时报 n=5 与 2021 的例外**），**明确拒绝押具体考点**，理由是检验 B/G **均未检出**考点层信号（而不是「已证明无记忆」） | 列一堆「预计高频考点」；或说「已被统计否证」 |
| 「2022 年第 18 题怎么做？」 | **2022 年整年题面乱码，不在任何统计内，答不了** | 编一道题出来 |

**第三题最关键**——它是唯一能测出「会不会编」的问题。答错就把《交接说明》重传一遍。

## 五、已知的坑

| 坑 | 说明 | 怎么办 |
|---|---|---|
| **`解法.md` 太大** | 256 KB / 4241 行 / 499 节。知识库检索**只会捞到片段**，GPT 容易张冠李戴 | 别整份传。要问某道题时，**你自己从这份里复制那一节**贴给它 |
| **`考点标注.tsv` 列数不定** | 每行 8–10 列（次考点数量不固定），**末尾四列固定**：题型内序号、解答位序号、高数解答位序号、职能 | 在对话里提醒一句：「TSV 的列从**末尾**数：倒数第 1 列是职能；第 4 列起到倒数第 5 列都是考点，主考点排第一」 |
| **两个「给 AI」的文件容易搞混归属** | `交接说明-教学AI.md`、`教学协议-考法驱动.md` 是写给 AI 的 | 传给 GPT；你自己看 `复习计划.md` 和三份速查 |
| **GPT 会不自觉地开始押题** | 它训练数据里全是「考研必考 100 题」这类内容，会往回滑 | 每隔一阵重问一次 §四 第二题；跑偏就把「三条硬禁令」再贴一遍 |
| **知识库不会自动同步** | Custom GPT 的知识库是快照 | 这边改了 `分析/` 之后，你要手动重传对应文件 |
| **别让 GPT 改这批文件** | 它没有仓库写权限，改动只存在于对话里，下次就没了 | 要改数据来这边改，改完重传 |

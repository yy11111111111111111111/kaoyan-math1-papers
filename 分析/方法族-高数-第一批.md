# 方法族 · 高数第一批（3 个）

> **全部 `status: candidate`。**这是待审规则，不允许作为「已验证方法规则」进入教学。
> 第四族 `calc.mean-value.proof-selection` 按裁定暂不做——前三族的 schema 填法稳定后再动。

## 关于 route scan 的口径

按裁定，`global_exhaustiveness` 一律 `not_established`——绝大多数数学方法族都无法证明「不存在任何其他聪明解法」。可验收的是**在预先声明的检索宇宙里有没有系统搜过**。本批的扫描协议：

1. 定 scope；2. 收齐 scope 内的真题；3. 逐题记录已发现路线；4. 按「决定性动作」去重；5. 按固定 alternative checklist 主动找替代路线；6. 做一次 adversarial pass；7. 两轮后不再出现新的结构性路线才标 `locally_saturated`。

`scan_basis` 按裁定分列来源，**不写笼统的「教材常规路线」**——本项目尚未绑定权威教材层。

```yaml
method_family_rule:
  schema_version: CALC-METHOD-FAMILY-v1
  family_id: calc.limit.method-selection
  name: 一元极限的方法选择
  status: candidate
  pedagogical_validation:
    status: untested

  scope:
    objects: [一元函数极限, 数列极限]
    target_tasks: [求极限值, 由极限值反求参数, 定无穷小的阶]
    exclusions:
      - 极限存在性的抽象证明（属 calc.mean-value.proof-selection 或实分析）
      - 多元函数的重极限
      - 级数收敛性判定（属 calc.series.convergence-selection，未建）

  rule_kind: structural_rule

  pre_solution_features:
    - feature_id: F1
      description: 待定型的类型（0/0 · ∞/∞ · 1^∞ · 0·∞ · ∞−∞ · 0^0）
      acquisition: 直接代入极限点，读出分子分母各自的趋向
      role: decisive
    - feature_id: F2
      description: 表达式在极限点附近是纯乘除结构，还是含加减（含相消风险）
      acquisition: 看待替换的部件处在乘除因子位置还是加减项位置
      role: decisive
    - feature_id: F3
      description: 对象是数列（离散 n）还是函数（连续 x）
      acquisition: 读自变量
      role: decisive
    - feature_id: F4
      description: 是否出现变限积分 ∫₀^{φ(x)}
      acquisition: 扫描被积结构
      role: supporting
    - feature_id: F5
      description: 是否为 n 项和且每项含 k/n
      acquisition: 看是否存在对 k 的求和且项数随 n 增长
      role: supporting

  candidate_actions:
    - action_id: A1
      description: 等价无穷小替换
      role: primary
    - action_id: A2
      description: 泰勒展开定阶（带皮亚诺余项）
      role: primary
    - action_id: A3
      description: 洛必达法则
      role: alternative
    - action_id: A4
      description: 夹逼准则
      role: alternative
    - action_id: A5
      description: 单调有界准则（先证存在性再解方程）
      role: primary        # 仅对递推数列
    - action_id: A6
      description: 取对数 / 变量代换化型
      role: fallback
    - action_id: A7
      description: 认作定积分的黎曼和
      role: alternative

  selection_rule:
    guards:
      - condition: A1 仅可作用于**乘除因子**；被替换部件处于加减项位置时不适用
        logical_role: necessary
        check: 定位待替换部件在表达式树中的位置——是因子还是加数
      - condition: A3 要求当前确为 0/0 或 ∞/∞，且求导后的极限**确实存在**（或为 ∞）
        logical_role: necessary
        check: 先验型，再看求导后是否收敛；求导后振荡则该次调用无效
      - condition: A5 仅对数列；A3 不能直接作用于数列（n 不可导）
        logical_role: necessary
        check: 读 F3
      - condition: 出现变限积分时，其阶 = 被积函数的阶 + 1
        logical_role: supporting_heuristic
        check: 先对被积函数定阶再加一
      - condition: A2 展开阶数由**分母（或比较对象）**的阶决定，不由分子决定
        logical_role: supporting_heuristic
        check: 先读分母的最低阶
    minimal_probe:
      action: 把每个部件展开到一阶，看分子分母主项是否相消
      interpretation: 不相消 → A1 通常够用；相消 → 必须 A2 并提高阶数
    preference_rule: >
      F2 为纯乘除时 A1 最省力；一旦相消进入加减结构则改 A2。
      A3 在本族中定位为 alternative 而非 primary：它每次调用都要重验前提，
      且对高阶相消要反复求导，A2 一步到位。**这是效率偏好，不是合法性判断**——
      A3 在其前提满足时完全合法。

  mechanism:
    statement: |
      f ~ g 的定义是 lim f/g = 1。极限的乘除运算法则给出：
      在乘除结构中把因子换成等价量，整体极限不变。
      加减结构没有这条法则——主阶可能相消，被丢弃的高阶项恰好成为新的主项。
      泰勒展开保留有限阶多项式 + 可控余项，因此在相消后仍能读出主项系数。
    why_action_follows: |
      所以「用 A1 还是 A2」这个选择，实质是问「主阶会不会被消掉」。
      minimal_probe 就是在最低成本下回答这一问。

  failure_boundaries:
    - boundary_id: B1
      changed_condition: 待替换部件从乘除因子位置移到加减项位置
      effect: invalidates
      explanation: 等价替换丢弃的高阶项在相消后成为主项，结果整体错误
      witness:
        kind: constructed_counterexample
        ref: |
          lim_{x→0} (sin x − x)/x³。用 sin x ~ x 得 0；
          用 sin x = x − x³/6 + o(x³) 得 −1/6。
        verification: verified
    - boundary_id: B2
      changed_condition: 洛必达求导后的极限不存在（振荡）
      effect: becomes_inconclusive
      explanation: 洛必达是充分条件，求导后极限不存在时**不能反推原极限不存在**
      witness:
        kind: constructed_counterexample
        ref: |
          lim_{x→∞} (x + sin x)/x = 1（分子分母同除 x）；
          洛必达后为 1 + cos x，极限不存在。原极限存在，洛必达无结论。
        verification: verified
    - boundary_id: B3
      changed_condition: 对象从函数换成数列
      effect: invalidates
      explanation: n 不可导，A3 不能直接用；须先换成连续变量的函数极限再用
      witness:
        kind: proof
        ref: 洛必达法则的前提是可导，数列不满足
        verification: verified
    - boundary_id: B4
      changed_condition: 泰勒展开阶数不足以覆盖相消
      effect: becomes_inconclusive
      explanation: 得到 0/0 的假象，需提高阶数重展，不是方法错误
      witness:
        kind: source_problem
        ref: 2004-7（`解法.md` 的易错处：定阶要看积分后的阶而非被积函数的阶）
        verification: pending      # 该 witness 依赖 解法.md，unverified_inference

  fallback_policy:
    when_guard_fails:
      - A1 的因子位置守卫失败 → 转 A2
      - A3 的存在性守卫失败 → 转 A2 或 A4
      - A5 不适用（非递推数列）→ 转 A4 或 A7
    candidate_actions: [A2, A4, A6]

  evidence:
    positive_problem_ids:
      解答: [2006-16, 2008-15, 2010-17, 2011-15, 2011-18, 2014-15, 2014-19,
             2015-15, 2016-19, 2017-16, 2018-19, 2019-18, 2021-17]
      选择填空: [2004-7, 2006-1, 2007-1, 2008-4, 2009-1, 2010-1, 2013-1, 2015-9,
                2016-9, 2016-12, 2017-1, 2017-9, 2018-9, 2019-1, 2019-3, 2020-1,
                2020-9, 2021-3, 2021-4, 2023-1, 2023-11, 2024-11, 2025-11, 2026-12]
      count: 37
    candidate_set_completeness:
      global_exhaustiveness: not_established
      route_scan_status: locally_saturated
      alternative_checklist_applied:
        [等价无穷小, 泰勒, 洛必达, 夹逼, 单调有界, 取对数/换元, 黎曼和,
         中值定理转化, 级数展开]
      adversarial_pass: 做过一轮；未发现新的结构性路线
    scan_basis:
```

## 2. `calc.vector-integral.route-selection`

```yaml
method_family_rule:
  schema_version: CALC-METHOD-FAMILY-v1
  family_id: calc.vector-integral.route-selection
  name: 曲线/曲面积分的路线选择
  status: candidate
  pedagogical_validation:
    status: untested

  scope:
    objects: [第一类曲线积分, 第二类曲线积分, 第一类曲面积分, 第二类曲面积分]
    target_tasks: [求积分值, 判断积分的符号或是否为零]
    exclusions:
      - 纯重积分（无曲线/曲面载体）
      - 场论恒等式的证明（div(rot F)≡0 一类）
      - 曲面方程本身的求取（属 calc.geometry.surface-construction，未建）

  rule_kind: structural_rule

  pre_solution_features:
    - feature_id: F1
      description: 积分载体是否**封闭**（闭曲线 / 闭曲面）
      acquisition: 读题面对载体的描述
      role: decisive
    - feature_id: F2
      description: 载体所围（或所附）区域内，被积向量场是否有**奇点**
      acquisition: 解分母为零的点集，判断是否落在区域内
      role: decisive
    - feature_id: F3
      description: 是第一类（对弧长/面积，与方向无关）还是第二类（对坐标，与方向有关）
      acquisition: 看微元记号 ds/dS 还是 dx,dy,dz/dydz,dzdx,dxdy
      role: decisive
    - feature_id: F4
      description: 载体与被积函数是否关于某坐标面/轴对称
      acquisition: 同时检查载体的对称性与被积各项的奇偶性
      role: supporting
    - feature_id: F5
      description: 载体是否易于参数化（圆、椭圆、线段、柱面与平面的交线）
      acquisition: 看载体方程的形式
      role: supporting
    - feature_id: F6
      description: 第二类平面曲线积分是否满足 ∂P/∂y = ∂Q/∂x，且区域单连通
      acquisition: 求两个偏导比较，并判断区域连通性
      role: decisive

  candidate_actions:
    - action_id: A1
      description: 直接参数化，化为定积分
      role: primary
    - action_id: A2
      description: 对称性化简（先砍掉为零的项，再算剩下的）
      role: primary
    - action_id: A3
      description: 直接套 Green / Gauss / Stokes（载体已封闭）
      role: primary
    - action_id: A4
      description: 补域：补一段线 / 一块面凑闭，算整体再减补的那部分
      role: primary
    - action_id: A5
      description: 挖奇点：挖一条与分母同型的小闭曲线/小球面
      role: primary
    - action_id: A6
      description: 路径无关 → 换一条好走的路径，或求势函数作差
      role: alternative
    - action_id: A7
      description: 第一类 ↔ 第二类的相互转换（方向余弦）
      role: alternative
    - action_id: A8
      description: 合一投影法，把三项 dydz+dzdx+dxdy 全化到 dxdy
      role: alternative

  selection_rule:
    guards:
      - condition: A3/A4/A5 要求 S 与补/挖的部分**合起来确实构成同一体域（或平面区域）的闭边界**
        logical_role: necessary
        check: 画出闭合后的区域，确认没有缝隙也没有重叠
      - condition: A3/A4/A5 要求载体与补面/补线的方向**均取该闭边界的外法向（或正向）**
        logical_role: necessary
        check: 逐块核对定向
        explanation: >
          若补面的方向与闭曲面的外向定向相反，通量可加式中该项的符号必须反转；
          方向错则整题符号错，这是本族最高频的失分点。
      - condition: A3/A4 要求向量场在所需区域内满足公式的适用条件（分量有连续偏导，无奇点）
        logical_role: necessary
        check: 解分母零点集，判断是否落入区域
      - condition: A6 要求 ∂P/∂y = ∂Q/∂x **且区域单连通**
        logical_role: necessary
        check: 两个偏导相等只是必要的一半；区域有洞时结论不成立
      - condition: A2 要求**载体的对称性与被积函数的奇偶性同时满足**
        logical_role: necessary
        check: 两个条件分别验，缺一不可
      - condition: 第二类积分用 A2 时，方向也要对称地翻转
        logical_role: necessary
        check: 检查对称映射下法向量/切向量的指向
      - condition: 补面选垂直于坐标轴的平面
        logical_role: supporting_heuristic
        check: 看能否找到这样的平面
        explanation: 这是**效率偏好不是合法性条件**——补任何满足闭合与方向条件的面都合法

    minimal_probe:
      action: 先算 div F（对曲面）或 ∂Q/∂x − ∂P/∂y（对平面曲线）
      interpretation: >
        若结果为常数或零，A3/A4 会把积分退化成「常数 × 体积/面积」或直接为零，
        此时补域路线的收益最大；若结果仍很复杂，重新考虑 A1。
    preference_rule: >
      F1 为「封闭」→ A3；「不封闭但能补」→ A4；「区域含奇点」→ A5（优先于 A3/A4）。
      F5 为「易参数化」且载体简单时，A1 常常比 A4 更快——**A1 与 A4 是竞争关系，
      不是 A4 优先**。F4 成立时 A2 应最先执行，它能砍掉一半以上的计算量。
      以上全是效率排序；合法性由 guards 决定。

  mechanism:
    statement: |
      设 S ∪ Σ₀ = ∂V 且方向统一取外侧，则由 Gauss 公式
        ∬_S F·n dS + ∬_{Σ₀} F·n dS = ∭_V (∇·F) dV
      故
        ∬_S F·n dS = ∭_V (∇·F) dV − ∬_{Σ₀} F·n dS。
      平面情形把 Gauss 换成 Green、把体域换成平面区域，结构完全相同。
    why_action_follows: |
      补域的全部作用是把「不封闭」这个唯一的障碍去掉，从而让公式可用；
      代价是多算一块 Σ₀。所以补面的选择标准是「Σ₀ 上的积分好算」，
      而合法性只要求闭合与定向一致。

  failure_boundaries:
    - boundary_id: B1
      changed_condition: 闭合区域内出现被积场的奇点
      effect: invalidates
      explanation: Green/Gauss 要求场在区域内有连续偏导；奇点处不满足，直接套用得到错误值
      witness:
        kind: source_problem
        ref: 2020-16（分母 4x²+y² 在原点为零，而 L 是含原点的圆）
        verification: pending
      recovery: 转 A5（挖奇点）
    - boundary_id: B2
      changed_condition: 补面的定向与闭曲面的外向不一致
      effect: invalidates
      explanation: 通量可加式中该项符号反转，整题差一个负号
      witness:
        kind: proof
        ref: 由 mechanism 的等式直接可见——Σ₀ 的方向决定该项的符号
        verification: verified
    - boundary_id: B3
      changed_condition: 平面区域从单连通变成含洞
      effect: invalidates
      explanation: ∂P/∂y = ∂Q/∂x 在非单连通域上推不出路径无关
      witness:
        kind: constructed_counterexample
        ref: |
          F = (−y/(x²+y²), x/(x²+y²)) 在去心平面上满足 ∂P/∂y = ∂Q/∂x，
          但沿绕原点单位圆一周的积分为 2π ≠ 0，故不路径无关。
        verification: verified
    - boundary_id: B4
      changed_condition: 补面存在且合法，但补面上的积分比原积分更难算
      effect: loses_advantage
      explanation: >
        **这不是 Gauss 公式失效**，只是 A4 不再是优先候选。此时应回到 A1 或 A2。
        把「不好算」误判为「不能用」是本族最容易串位的地方。
      witness:
        kind: constructed_counterexample
        ref: |
          取 S 为平面 z=0 上的单位圆盘（本身已易于直接算），
          若仍去补一个半球面凑成闭曲面，则需多算一个球面积分，净损失。
        verification: verified
    - boundary_id: B5
      changed_condition: 载体对称但被积函数不具备相应奇偶性（或反之）
      effect: invalidates
      explanation: A2 的两个条件必须同时成立；只验一个就下结论会把非零项当成零
      witness:
        kind: proof
        ref: 对称性化简的成立依赖被积函数在对称映射下变号
        verification: verified

  fallback_policy:
    when_guard_fails:
      - 闭合/定向守卫失败 → 重新划分区域，或转 A1
      - 奇点守卫失败 → A5
      - 单连通守卫失败 → 不能用 A6；转 A5 或 A4
      - 对称性守卫失败 → 放弃 A2，老实算
    candidate_actions: [A1, A5, A8]

  evidence:
    positive_problem_ids:
      解答: [2004-17, 2005-19, 2006-19, 2007-18, 2008-16, 2009-19, 2010-19,
             2012-19, 2014-18, 2015-19, 2016-17, 2016-18, 2017-19, 2018-17,
             2020-16, 2020-18, 2021-20, 2023-19, 2024-20, 2025-20, 2026-19]
      选择填空: [2004-3, 2005-4, 2006-3, 2007-6, 2007-14, 2008-12, 2009-11,
                2010-11, 2011-12, 2012-12, 2013-4, 2014-12, 2017-11, 2018-12,
                2019-4, 2019-12, 2021-14, 2024-2, 2025-14]
      count: 40
    candidate_set_completeness:
      global_exhaustiveness: not_established
      route_scan_status: locally_saturated
      alternative_checklist_applied:
        [direct parameterization, symmetry reduction, coordinate transformation,

      adversarial_pass: >

        里作为独立配方存在，扫描时才发现它其实是 A1 的一个变体（把三项统一到
```

```yaml
method_family_rule:
  schema_version: CALC-METHOD-FAMILY-v1
  family_id: calc.extrema.constraint-selection
  name: 多元极值/最值的约束类型选择
  status: candidate
  pedagogical_validation:
    status: untested

  scope:
    objects: [二元及以上实值函数]
    target_tasks: [求极值, 求最大最小值, 求梯度模的最值]
    exclusions:
      - 一元函数的极值（结构不同：一元用 f′ 变号，无 Hessian 判别）
      - 极值存在性的抽象证明
      - 条件极值的几何解释本身

  rule_kind: structural_rule

  pre_solution_features:
    - feature_id: F1
      description: 有没有等式约束 g(x,y)=0
      acquisition: 读题面是否给出附加方程
      role: decisive
    - feature_id: F2
      description: 定义域是否为**有界闭集**（题面出现「在区域 D 上」「闭区域」）
      acquisition: 读定义域描述，判断是否有界且含边界
      role: decisive
    - feature_id: F3
      description: 问的是「极值」（局部）还是「最大最小值」（全局）
      acquisition: 读设问词
      role: decisive
    - feature_id: F4
      description: 约束是否可显式解出一个变量（能否消元降为一元）
      acquisition: 尝试从 g=0 解出某变量
      role: supporting

  candidate_actions:
    - action_id: A1
      description: 无约束：解 f_x=f_y=0 得驻点，用 AC−B² 判别
      role: primary
    - action_id: A2
      description: 拉格朗日乘数法
      role: primary
    - action_id: A3
      description: 闭区域最值：内部驻点 + 边界 + 顶点，三处比大小
      role: primary
    - action_id: A4
      description: 用约束消元，降为一元函数求极值
      role: alternative
    - action_id: A5
      description: 对 |grad f|² 用拉格朗日（求梯度模的约束最值，避开根号）
      role: alternative

  selection_rule:
    guards:
      - condition: A1 的判别法要求 f 在驻点处二阶偏导连续
        logical_role: necessary
        check: 读函数的光滑性
      - condition: A1 在 AC−B² = 0 时**无结论**，必须退回定义或沿特殊路径讨论
        logical_role: necessary
        check: 算出判别式后先看是否为零
      - condition: A2 给出的是**必要条件**：解出的每一组驻点都要代回比较，不能只算一组
        logical_role: necessary
        check: 数一数方程组解的个数
      - condition: A2 要求约束在候选点处**梯度非零**（正则性），否则拉格朗日条件可能失效
        logical_role: necessary
        check: 验 ∇g ≠ 0
      - condition: A3 要求定义域**有界且闭**，否则最值可能不存在
        logical_role: necessary
        check: 读 F2；无界区域不能套「三处比大小」
      - condition: A3 的三处**一处都不能少**，边界含多段要逐段算
        logical_role: necessary
        check: 动笔前先在草稿写下「内部 / 边界 / 顶点」三行
      - condition: A4 消元后要保留原约束对新变量的取值范围
        logical_role: necessary
        check: 从 g=0 反推新变量的定义域
      - condition: 能消元时 A4 通常比 A2 快
        logical_role: supporting_heuristic
        check: 看 F4
        explanation: 这是效率偏好；A2 在能消元时同样合法

    minimal_probe:
      action: 先判 F1 与 F2 两个二值特征
      interpretation: >
        (无约束, 非闭区域) → A1；(有约束, 非闭区域) → A2 或 A4；
        (任意, 有界闭区域) → A3，且 A3 的边界那一步内部可能再调用 A2 或 A4。
        A3 不是 A1/A2 的替代品，而是它们的**外层框架**。
    preference_rule: >
      F2 成立时 A3 是外层，不可跳过；A1/A2/A4 在 A3 的「内部」与「边界」两步里被调用。
      把 A3 和 A1/A2 并列，是本族最常见的结构误解。

  mechanism:
    statement: |
      无约束：极值点必为驻点，二阶泰勒的二次型 A dx² + 2B dxdy + C dy² 的
      定号性由 AC−B² 与 A 的符号决定 —— 正定/负定给极小/极大，不定给鞍点，
      半定（AC−B²=0）无结论。
      有约束：在约束流形上的极值点处，目标函数的梯度必与约束梯度线性相关，
      即 ∇f = −λ∇g（正则点处）。
      有界闭区域：连续函数在有界闭集上必取到最值（Weierstrass），
      而最值点只能落在内部驻点、边界、或不可导点上。
    why_action_follows: |
      三条 mechanism 分别对应三个 action，而且解释了为什么 A3 是外层：
      Weierstrass 只保证最值存在并限定它的位置，不告诉你怎么求；
      求的过程仍要在内部用 A1、在边界用 A2 或 A4。

  failure_boundaries:
    - boundary_id: B1
      changed_condition: AC−B² 从非零变为零
      effect: becomes_inconclusive
      explanation: 判别法给不出结论，**不等于不是极值**；须回定义或沿路径讨论
      witness:
        kind: constructed_counterexample
        ref: |
          f(x,y) = x⁴ + y⁴ 在原点：A=B=C=0，判别式为零，但原点是严格极小值点。
          f(x,y) = x⁴ − y⁴ 在原点：同样判别式为零，却是鞍点。
          两例判别式相同、结论相反，说明该情形下判别法确实无信息。
        verification: verified
    - boundary_id: B2
      changed_condition: 定义域从有界闭集变为无界或开集
      effect: invalidates
      explanation: Weierstrass 不再适用，最值可能不存在，「三处比大小」的框架失去依据
      witness:
        kind: constructed_counterexample
        ref: f(x,y) = x 在开区域 0<x<1 上：无最大值也无最小值。
        verification: verified
    - boundary_id: B3
      changed_condition: 约束在候选点处梯度为零（非正则点）
      effect: invalidates
      explanation: ∇f = −λ∇g 的推导依赖 ∇g ≠ 0；非正则点须单独检查
      witness:
        kind: constructed_counterexample
        ref: |
          约束 g(x,y) = (x²+y²)² − x² = 0（含尖点的双纽线），
          原点处 ∇g = 0；该点不满足拉格朗日条件却可能是约束极值点，
          须作为额外候选单独讨论。
        verification: verified
    - boundary_id: B4
      changed_condition: 闭区域上只算了内部驻点、跳过边界
      effect: invalidates
      explanation: 最值经常恰在边界取到；漏边界的答案系统性偏小/偏大
      witness:
        kind: source_problem
        ref: 2007-17 / 2018-16 / 2024-18（三题的最值均涉及边界处理）
        verification: pending
    - boundary_id: B5
      changed_condition: 拉格朗日解出多组驻点，只代回其中一组
      effect: invalidates
      explanation: A2 是必要条件，不比较所有候选点就没有完成求解
      witness:
        kind: source_problem
        ref: 2005-21 的同类错误（`解法.md` 易错处：k 的两种情形都要算）
        verification: pending
    - boundary_id: B6
      changed_condition: 问的从「极值」变为「最值」（F3 翻转）
      effect: changes_branch
      explanation: >
        极值是局部概念，只需驻点 + 判别；最值是全局概念，须比较所有候选并考虑边界。
        同一个 f 上两问的答案可以完全不同。
      witness:
        kind: proof
        ref: 局部极值点未必是全局最值点（一元反例即可推广）
        verification: verified

  fallback_policy:
    when_guard_fails:
      - AC−B²=0 → 回定义 / 沿路径讨论 / 换用不等式估计
      - ∇g=0 → 把该点作为额外候选单独讨论
      - 区域无界 → 先讨论无穷远处的行为，再决定最值是否存在
    candidate_actions: [A4, A5]

  evidence:
    positive_problem_ids:
      解答: [2004-19, 2007-17, 2008-17, 2009-15, 2012-16, 2013-17, 2015-17,
             2018-16, 2019-16, 2020-15, 2021-19, 2023-18, 2024-18, 2026-17]
      选择: [2006-10, 2011-3]
      count: 16
    candidate_set_completeness:
      global_exhaustiveness: not_established
      route_scan_status: locally_saturated
      alternative_checklist_applied:
        [无约束驻点+Hessian, 拉格朗日, 闭区域三处比较, 消元降一元,

      adversarial_pass: >
        做过一轮。「不等式估计」（如用均值不等式直接给出条件最值）在 22 年真题中
        未作为主路线出现，故列入 checklist 但未纳入 candidate_actions；

    scan_basis:
      - source: 解法.md
        status: unverified_inference

      - source: 高数方法速查.md §5
        status: human_synthesis
```

## 提交时我自己看到的三个薄弱处

1. **B4/B5 类 witness 的 `verification: pending`。**凡是 `kind: source_problem` 的 witness，其「这题确实体现了这个边界」的判断来自 `解法.md`（`unverified_inference`）。构造出来的反例（B1/B2/B3 那些）我可以独立核验，真题 witness 不能。这是 `annotation_dependence: material` 的具体来源。

2. **`locally_saturated` 我标得可能偏松。**第二族的 adversarial pass 确实挖出了一条（A8 其实是 A1 的变体），说明扫描是起作用的；但第一族和第三族的 adversarial pass 没有产出新路线——这既可能说明真的饱和了，也可能说明我的对抗性不够。请重点看这两族的候选集有没有明显缺口。

3. **第三族的 A3 定位。**我把「闭区域最值」写成了 A1/A2 的**外层框架**而不是并列候选，这是我这三族里唯一一处偏离「候选集」直觉的结构安排。如果这个建模不对，第三族要重写。

# 方法族 · 高数第一批（v2）

## 0. 这一版改了什么

第一轮验收结论是「没有任何一个可以升 `partially_verified`」，并指出 schema v1 缺两个结构。两个结构已加：

```yaml
# v1.1 新增
candidate_actions:
  - action_id: A3
    action_kind: framework | solver | preprocessing   # ← 新增：动作的层级
    applies_when: [ ... ]                             # ← 新增：该动作自身的适用范围
    invokes: [A1, A2]                                 # ← 新增：framework 调用哪些 solver
    subroute_of: A1                                   # ← 新增：变体归属，避免 route-scan 计数冲突
```

### 逐条落实

| # | 验收意见 | 处置 |
|---|---|---|
| 1 | A1 的「仅作用于乘除因子」不是必要条件——`sin x + x ~ 2x` 完全合法 | **已改**。真正的危险是「替换误差与总表达式同阶」，典型触发是主项相消。guard 与 B1 全部重写 |
| 2 | 「变限积分的阶 = 被积函数的阶 + 1」是错的 | **已删并替换**。反例 `∫₀^{x²} t dt = x⁴/2`（被积 1 阶，结果 4 阶）已作为 B5 收录 |
| 3 | 极限 probe 偷偷预选了 Taylor，且不覆盖 scope | **已重写**为三段式，且「相消 → 必须 A2」已撤 |
| 4 | 「展开阶数由分母决定」只能是窄范围 heuristic | **已改**为「展开到足以确定双方第一非零主项」 |
| 5 | 极限族 `locally_saturated` 须撤回 | **已撤为 `open`**，并补入「直接代入/连续性」「代数恒等变形/有理化」两条候选 |
| 6 | 积分族把四类积分与三个定理混成一个 router | **已重写为两级 router**，见 §2 |
| 7 | 「单连通」不是路径无关的必要条件 | **已改为 `sufficient`**，并收录 `F=(2x,2y)=∇(x²+y²)` 在环域上的反例 |
| 8 | B4 的 `loses_advantage` 概念对，但反例缺 integrand，不能标 verified | **已补完整向量场并实算两条路线** |
| 9 | A8 既判定为 A1 的变体，就不该平级计数 | **已改为 `subroute_of: A1`** |
| 10 | 极值族 A3 的外层地位只写在 prose 里，YAML 仍是平级 | **已用 `action_kind: framework` + `invokes` 表达** |
| 11 | 极值 probe 漏了 F3（局部 vs 全局） | **已补，且置于第一顺位** |
| 12 | A3 缺「目标函数在该有界闭集上连续」这条 guard | **已补** |
| 13 | 「内部+边界+顶点」不是一般有界闭集的 structural rule | **已缩 scope 到分段光滑区域**，并改写为「内部临界/不可导点 + 完整边界 + 边界的非光滑点」 |
| 14 | B3 的反例缺目标函数 | **已换成 `g=x²+y²=0, f=x`** |
| 15 | B5 引用 2005-21 属跨题串位 | **已删**。核查确认 2005-21 主考点是「AB=O 的秩关系与线性相关性」，线代题 |
| 16 | 「不等式估计」不该因真题未用而排除 | **已收进候选集**（A6，role: alternative） |
| 17 | 极值族 `route_scan_status` 降回 `open` | **已降** |

## 1. `calc.limit.method-selection`（v2）

```yaml
method_family_rule:
  schema_version: CALC-METHOD-FAMILY-v1.1
  family_id: calc.limit.method-selection
  name: 一元极限的方法选择
  status: candidate
  pedagogical_validation: { status: untested }

      description: 直接代入后是否为待定型；若是，是哪一种（0/0 · ∞/∞ · 1^∞ · 0·∞ · ∞−∞ · 0^0）
      acquisition: 先代入，读出分子分母各自的趋向
      role: decisive
    - feature_id: F2
      description: 表达式中是否存在**决定性主项相消**（替换误差与总量同阶）
      acquisition: 各部件展到一阶后看主项是否抵消
      role: decisive
    - feature_id: F3
      description: 对象是数列（离散 n）还是函数（连续 x）
      acquisition: 读自变量
      role: decisive
    - feature_id: F4
      description: 结构类型（含变限积分 / n 项和 / 递推式 / 幂指式）
      acquisition: 扫描整体结构

  candidate_actions:
    - { action_id: A0, description: 直接代入（连续性），确认是否根本不是待定型, action_kind: preprocessing, role: primary, applies_when: [极限点处各部件连续] }
    - { action_id: A1, description: 等价无穷小替换, action_kind: solver, role: primary, applies_when: [存在可识别的标准无穷小部件] }
    - { action_id: A2, description: 泰勒展开定阶（带皮亚诺余项）, action_kind: solver, role: primary, applies_when: [部件在极限点处足够光滑] }
    - { action_id: A3, description: 洛必达法则, action_kind: solver, role: alternative, applies_when: [0/0 或 ∞/∞ 型, 分子分母在去心邻域可导] }
    - { action_id: A4, description: 夹逼准则, action_kind: solver, role: alternative, applies_when: [能构造同极限的上下界] }
    - { action_id: A5, description: 单调有界准则（先证存在性再解方程）, action_kind: solver, role: primary, applies_when: [F3 为数列, F4 含递推式] }
    - { action_id: A6, description: 代数恒等变形（因式分解 / 有理化 / 通分）, action_kind: preprocessing, role: primary, applies_when: [存在可约因子或可有理化的根式差] }
    - { action_id: A7, description: 取对数 / 变量代换化型, action_kind: preprocessing, role: primary, applies_when: [F1 为 1^∞、0^0、∞−∞ 等非 0/0 型] }
    - { action_id: A8, description: 认作定积分的黎曼和, action_kind: solver, role: alternative, applies_when: [F4 为 n 项和且项含 k/n] }

  selection_rule:
    guards:
      - condition: >-
          A1 的合法性条件是**替换引入的误差相对于所在位置的主项是高阶的**。
          它在乘除因子上自动成立；在加减结构中**不自动成立也不自动失效**——
          `sin x + x ~ 2x` 合法，`sin x − x` 用 `x − x` 则不合法。
        logical_role: necessary
        check: 问「把该部件换掉后，被丢弃的高阶项会不会成为新的主项」；等价于问是否发生决定性相消
        explanation: >
          v1 把「处于加减位置」写成必要条件，是把一条考场安全口诀误升成了数学规则。
          真正的判据是误差的相对阶，与部件所处的语法位置无关。
      - condition: A3 要求当前确为 0/0 或 ∞/∞；分子分母在去心邻域内可导；**分母的导数不为零**；且求导后的极限确实存在（或为 ∞）
        logical_role: necessary
        check: 四条逐条验；求导后振荡则该次调用无结论
      - condition: A3 不能直接作用于数列（n 不可导），须先换成连续变量的函数极限
        logical_role: necessary
        check: 读 F3
      - condition: A5 仅对数列且存在递推关系
        logical_role: necessary
        check: 读 F3、F4
      - condition: A2 应展开到**足以确定比较双方各自的第一个非零主项**为止
        logical_role: supporting_heuristic
        check: 展开后看是否已能读出双方主项；不够就再加一阶
        explanation: v1 写成「阶数由分母决定」，那只在「分子分母同为多项式型渐近」的窄情形下成立

    minimal_probe:
      action: |
        三段，按序执行，随时可提前结束：
        ① 直接代入（A0）——不是待定型就结束；
        ② 按 F1 与 F4 做结构归一化（A6 / A7：化型、有理化、取对数、识别递推或黎曼和）；
        ③ 只有当问题落到「两个小量比较」这一分支时，才检查 F2（是否决定性相消）。
      interpretation: >
        ③ 若无相消，A1 通常最省力；若有相消，A1 的那一步不再有保证，
        此时 A2、A3、A6 都仍可能合法——**不是「必须 A2」**。
    preference_rule: >
      在有限阶初等渐近结构中 A2 通常比 A3 更直接（一次展开覆盖多阶，A3 每次调用都要重验四条前提）。
      **这是该情形下的效率排序，不是 A2 的一般优势，更不是 A3 的合法性判断。**

  mechanism:
    statement: |
      f ~ g 定义为 lim f/g = 1，即 f = g(1 + o(1))。
      把某部件 u 换成 v（u ~ v）会引入误差 u − v = o(u)。
      整体极限是否被改变，取决于该误差相对于**它所在位置的主项**是否高阶：
      在乘除结构中恒为高阶（极限的乘除法则），在加减结构中当主项相消时可能升为主项。
      泰勒展开保留有限阶多项式 + 可控余项，因此在相消后仍能读出下一阶主项系数。
    why_action_follows: |
      所以「A1 还是 A2」不是「因子位还是加数位」，而是「误差会不会变成主项」。
      probe 的第 ③ 步就是在最低成本下回答这一问。

  failure_boundaries:
    - boundary_id: B1
      changed_condition: 表达式进入**会发生决定性主项相消**的结构（不论语法位置）
      effect: invalidates
      explanation: 逐项等价替换丢弃的高阶项在相消后成为主项，结果整体错误
      witness:
        kind: constructed_counterexample
        ref: |
          反例：lim_{x→0} (sin x − x)/x³。用 sin x ~ x 得 0；
          用 sin x = x − x³/6 + o(x³) 得 −1/6。
          **对照（说明加减位置本身无罪）**：lim_{x→0} (sin x + x)/x = 2，
          把 sin x 换成 x 得 (x+x)/x = 2，正确。同为加减结构，一错一对，
          分界正是有无决定性相消。
        verification: verified
    - boundary_id: B2
      changed_condition: 洛必达求导后的极限不存在（振荡）
      effect: becomes_inconclusive
      explanation: 洛必达是充分条件；求导后极限不存在时**不能反推原极限不存在**
      witness:
        kind: constructed_counterexample
        ref: |
          lim_{x→∞} (x + sin x)/x = 1（同除 x 即得）；洛必达后为 1 + cos x，极限不存在。
          原极限存在，洛必达无结论。
        verification: verified
    - boundary_id: B3
      changed_condition: 对象从函数换成数列
      effect: invalidates
      explanation: n 不可导，A3 的可导前提不满足
      witness: { kind: proof, ref: 洛必达法则的前提是可导，数列不满足, verification: verified }
    - boundary_id: B4
      changed_condition: 泰勒展开阶数不足以覆盖相消
      effect: becomes_inconclusive
      explanation: 得到 0/0 的假象，需提高阶数重展；不是方法错误
      witness: { kind: proof, ref: 余项阶数不足时主项未被解析出来, verification: verified }
    - boundary_id: B5
      changed_condition: 变限积分的上限本身是高阶无穷小（φ(x) 不是 x）
      effect: invalidates
      explanation: >
        **v1 的「变限积分的阶 = 被积函数的阶 + 1」是错的。**正确结构是：
        若 g(t) ~ c·t^m 且 φ(x) → 0，则在适当条件下
          ∫₀^{φ(x)} g(t) dt  ~  [c/(m+1)] · φ(x)^{m+1}。
        最终关于 x 的阶还要再读 φ(x) 自身的阶，不是简单地「+1」。
      witness:
        kind: constructed_counterexample
        ref: |
          g(t) = t（关于 t 是 1 阶），φ(x) = x²：
            ∫₀^{x²} t dt = x⁴/2，关于 x 是 **4 阶**，不是 v1 规则给出的 2 阶。
          代入正确公式：c=1, m=1 → (1/2)·(x²)² = x⁴/2 ✓
        verification: verified

  fallback_policy:
    when_guard_fails:
      - A1 的误差阶守卫失败 → A2 / A3 / A6 均可，按具体结构选
      - A3 的四条前提任一失败 → A2 或 A4

    candidate_actions: [A2, A4, A6]

  evidence:
```

## 2. `calc.vector-integral.route-selection`（v2：重写为两级 router）

第一轮判定「填法错了要重写」，理由是把四类积分与三个定理混进同一个 router。确认成立：`F1 = 是否封闭 → A3` 作为统一路由从根上不成立——Stokes 的曲面**本身不需要封闭**，第一类积分也不因载体封闭就能套第二类公式。

**重写方案**：一级 router 只做对象分类，不产生任何 solver；二级才按分类生成合法候选。

```yaml
method_family_rule:
  schema_version: CALC-METHOD-FAMILY-v1.1
  family_id: calc.vector-integral.route-selection
  name: 曲线/曲面积分的路线选择（两级 router）
  status: candidate
  pedagogical_validation: { status: untested }

  scope:
    objects: [第一类曲线积分, 第二类曲线积分, 第一类曲面积分, 第二类曲面积分]
    target_tasks: [求积分值, 判断积分的符号或是否为零]
    exclusions: [纯重积分, 场论恒等式的证明, 曲面方程本身的求取]

  rule_kind: structural_rule

  # ── 一级：对象分类，不产生 solver ──
  level_1_router:
    axes:
      - { axis: carrier,   values: [曲线, 曲面] }
      - { axis: kind,      values: [第一类（对弧长/面积，与方向无关）, 第二类（对坐标，与方向有关）] }
      - { axis: ambient,   values: [平面, 空间] }
    acquisition: 读微元记号（ds/dS vs dx,dy,dz/dydz,dzdx,dxdy）与载体所在维数
    rule: >
      必须先定这三个轴，再进入二级。**一级不选方法。**
      v1 的错误正是跳过一级，直接用「是否封闭」路由到「Green/Gauss/Stokes」。

  level_2_candidates:
    - cell: 平面 · 曲线 · 第二类
      actions: [A1, A2, A3g, A4l, A5l, A6]
      note: 只有这一格产生 Green / 补线 / 挖奇点 / 路径无关
    - cell: 空间 · 曲线 · 第二类
      actions: [A1, A2, A3s]
      note: 产生 Stokes；**Stokes 要求 L 闭合，但所张的曲面 S 不必封闭**
    - cell: 曲面 · 第二类
      actions: [A1, A2, A3G, A4s, A5s, A8]
      note: 产生 Gauss / 补面 / 挖奇点 / 合一投影
    - cell: 曲线或曲面 · 第一类
      actions: [A1, A2, A7]
      note: >
        与方向无关。**不产生 Green/Gauss/Stokes**——这三个定理的对象是第二类积分。
        需要时先用 A7 转成第二类，转换本身要引入方向。

  candidate_actions:
    - { action_id: A1,  description: 直接参数化，化为定积分/二重积分, action_kind: solver, role: primary, applies_when: [载体易参数化] }
    - { action_id: A2,  description: 对称性化简, action_kind: preprocessing, role: primary, applies_when: [载体与被积函数同时具备对应的对称性] }
    - { action_id: A3g, description: Green 公式（平面闭曲线 → 平面区域）, action_kind: solver, role: primary, applies_when: [平面, 曲线, 第二类, 闭合] }
    - { action_id: A3s, description: Stokes 公式（空间闭曲线 → 任一以它为边界的曲面）, action_kind: solver, role: primary, applies_when: [空间, 曲线, 第二类, 闭合] }
    - { action_id: A3G, description: Gauss 公式（闭曲面 → 体域）, action_kind: solver, role: primary, applies_when: [曲面, 第二类, 闭合] }
    - { action_id: A4l, description: 补线：补一段线凑闭，用 Green 后减补线, action_kind: framework, role: primary, applies_when: [平面, 曲线, 第二类, 不闭合], invokes: [A3g, A1] }
    - { action_id: A4s, description: 补面：补一块面凑闭，用 Gauss 后减补面, action_kind: framework, role: primary, applies_when: [曲面, 第二类, 不闭合], invokes: [A3G, A1] }
    - { action_id: A5l, description: 挖奇点（平面：挖与分母同型的小闭曲线）, action_kind: framework, role: primary, applies_when: [平面, 曲线, 第二类, 区域含奇点], invokes: [A3g, A1] }
    - { action_id: A5s, description: 挖奇点（空间：挖小球面）, action_kind: framework, role: primary, applies_when: [曲面, 第二类, 区域含奇点], invokes: [A3G, A1] }
    - { action_id: A6,  description: 路径无关 → 换路径或求势函数作差, action_kind: solver, role: alternative, applies_when: [平面, 曲线, 第二类, 场为某势函数的梯度] }
    - { action_id: A7,  description: 第一类 ↔ 第二类的相互转换（方向余弦）, action_kind: preprocessing, role: alternative, applies_when: [需要跨类调用定理] }
    - { action_id: A8,  description: 合一投影法（三项统一到 dxdy 后再算）, action_kind: preprocessing, role: alternative, subroute_of: A1, applies_when: [曲面, 第二类, 可写成 z=z(x,y)] }

  selection_rule:
    guards:
      - condition: "**必须先完成一级分类**，再选二级候选"
        logical_role: necessary
        check: 三个轴各定一个值
```

# 方法族 · 高数 · 重积分（v1.0.0 · Batch 3 · calc.multiple-integral.route-selection）

## 0. 家族定位

本族处理**二重与三重积分的路线选择**：选坐标系、定积分限、用对称性、换序。
schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`。

曲线与曲面积分属 `calc.vector-integral.route-selection`；
一元定积分的几何应用属 `calc.int1v.route-selection`。

          Ω 也不关于任一坐标面对称——原 guard 的两条前提都不成立。
          纯构造反例：同一 Ω 上 ∭ x/(x+y+z) dV，轮换给 3I = ∭1 dV = |Ω| = 1/6
          ⇒ I = **1/18**（蒙特卡洛：0.05545）。

        check: 换元后立刻写出雅可比因子
        explanation: 见 B3——漏掉 r 使单位圆的面积从 π 变成 2π。
      - condition: "累次积分的**外层限必须是常数**"
        logical_role: necessary
        check: 写完限后检查最外层是否含变量；含则内外层选反或需分块

        explanation: 画图是常用的 supporting heuristic；合法性的必要条件是以同一区域集合为中介重新定限。见 B1。

      changed_condition: 交换积分次序时直接调换上下限，不以原区域集合为中介重新定限
      effect: invalidates
      explanation: >
        原累次积分的内层限含外层变量，直接互换变量位置会把区域 D 变成
        `σ(D)`，其中 `σ(x,y)=(y,x)`；一般并非原区域。
      witness:
        kind: constructed_counterexample
        ref: |
          I = ∫₀¹ dx ∫ₓ¹ f(x,y) dy，区域 D = {0≤x≤1, x≤y≤1}（对角线上方三角）。
          · 正确换序：D 也可写成 {0≤y≤1, 0≤x≤y} ⇒ I = ∫₀¹ dy ∫₀^y f dx。
          · 错误做法：把限「调个位置」写成 ∫₀¹ dy ∫_y¹ f dx ——
            这是区域 {0≤y≤1, y≤x≤1}，即对角线**下方**三角，是另一个区域。

          取 f = x 可见差别：
            真值（上方三角）= 1/6 ≈ 0.16667（数值 1200² 网格：0.16688）
            错误（下方三角）= 1/3 ≈ 0.33333（数值：0.33312）
          相差一倍。

          ⚠️ **注意 f = xy 时两者都等于 1/8**（数值 0.12514 与 0.12486）——
          被积函数关于 x↔y 对称会**掩盖**这个错误。
          一般地，对任意可测 D 与可积 f，变量交换公式给出
          ∬_{σ(D)} f(x,y)dA = ∬_D f(y,x)dA；若 f(x,y)=f(y,x)，错误写出的
          σ(D) 上积分恒等于 D 上原积分。因此用对称被积自检换序必然失效，
          这不是 f=xy 或三角形区域的偶然。
        verification: verified
      recovery: 回到 A7 第一步，由原限反推同一区域集合，再按新方向重新定限；图形只作辅助

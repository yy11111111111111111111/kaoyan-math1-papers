# 方法族 · 高数 · 重积分（v1.0.0 · Batch 3 · calc.multiple-integral.route-selection）

## 0. 家族定位

本族处理**二重与三重积分的路线选择**：选坐标系、定积分限、用对称性、换序。
schema 沿用 `CALC-METHOD-FAMILY-v1.3.1`。

曲线与曲面积分属 `calc.vector-integral.route-selection`；
一元定积分的几何应用属 `calc.int1v.route-selection`。

      role: primary

      action_kind: solver
      produces: result_object
      followup_actions:

        on_skip: return_to_parent_router

          - { kind: action_ref, action: A1, when: 设问要数值而非符号 }

      role: alternative
      applies_when: [设问问符号或是否为零, 被积函数在区域上可判定不变号]
      eligible_cells: [判零或定号]

      description: 形心与质心公式
      action_kind: solver
      produces: transformed_problem
      followup_actions:

        actions:

          - { kind: action_ref, action: A3, target: 分子分母各自的积分（对称性常使某个分子为 0） }
      terminal_when: [各坐标分量已算出]
      role: primary
      applies_when: [设问求形心或质心]
      eligible_cells: [形心质心]

  selection_rule:
    guards:
      - condition: >-
          A3 的**奇偶归零/减半**分支要求**区域关于相应坐标面（轴）对称**与
          **被积函数在该反射下为奇/偶**同时成立，缺一不可。
        logical_role: necessary
        scope: A3 的奇偶分支
        check: 两条分别核对并写下来；只验一条不得下结论
        explanation: 见 B2——同一被积函数在对称区域上积分为 0，在非对称子区域上则不为 0。
      - condition: >-
          A3 的**轮换对称**分支只要求**区域在该变量置换下不变**，
          对被积函数**没有**奇偶性要求。
        logical_role: necessary
        scope: A3 的轮换分支
        check: 只核对区域在置换下是否不变；不要去找奇偶性
        explanation: >
          **2026-08-29 新增**：原先只有上面一条 guard，且把奇偶性写成 A3
          **整条 action** 的必要条件，据此执行会把合法的轮换分支（本文件已列出）
          在所有无奇偶性的题上判为不可用。
          scope 内反例 2015-12：Ω={x,y,z≥0, x+y+z≤1}，求 ∭(x+2y+3z)dV。
          Ω 在任意变量置换下不变 ⇒ ∭x=∭y=∭z ⇒ I = 6∭x dV = 6·(1/24) = **1/4**
          （蒙特卡洛 4×10⁶ 点：0.2495）。而 x+2y+3z 在任一变量上既非奇也非偶，
          Ω 也不关于任一坐标面对称——原 guard 的两条前提都不成立。
          纯构造反例：同一 Ω 上 ∭ x/(x+y+z) dV，轮换给 3I = ∭1 dV = |Ω| = 1/6
          ⇒ I = **1/18**（蒙特卡洛：0.05545）。
      - condition: "极坐标换元的面积元是 **r dr dθ**；柱面 **r dr dθ dz**；球面 **ρ² sinφ dρ dφ dθ**"
        logical_role: necessary
        check: 换元后立刻写出雅可比因子
        explanation: 见 B3——漏掉 r 使单位圆的面积从 π 变成 2π。
      - condition: "累次积分的**外层限必须是常数**"
        logical_role: necessary
        check: 写完限后检查最外层是否含变量；含则内外层选反或需分块
      - condition: >-
          A7（换序）必须**先由原限反推区域并画图**，不得直接调换上下限的位置。
        logical_role: necessary
        check: 画出区域这一步是否真的做了
        explanation: 见 B1。
      - condition: A4（投影法）要求立体在所选方向上穿入穿出各一次
        logical_role: necessary
        check: 若穿入穿出多于一次，须先把立体分块
      - condition: 被积 ≥ 0 只推出积分 ≥ 0；严格不等号需额外条件
        logical_role: necessary
        check: 区分严格与非严格
      - condition: 被积只依赖一个变量（如 f(z)）时 A5（截面法）通常远快于 A4
        logical_role: supporting_heuristic
        check: 看被积函数依赖几个变量
      - condition: "区域由 x²+y² 界定或被积含 x²+y² 时优先考虑极坐标"
        logical_role: supporting_heuristic
        check: 看区域边界与被积的形态
      - condition: 原次序积不出来时换序常常可积（如 ∫∫ sin y / y 型）
        logical_role: supporting_heuristic
        check: 内层积不出时先试换序，再考虑换元

    minimal_probe:
      action: |
        ① 几重积分？设问是求值、换序、判零还是求形心？
        ② 换序 → **A7，先画区域**，别碰上下限。
        ③ 求值 → 先查对称性（A3），**区域与被积两条都要验**，常常直接得 0 或减半。
        ④ 仍需实算 → 二重看区域形态选直角(A1)或极坐标(A2)；
           三重看被积依赖几个变量选投影(A4)或截面(A5)，或换柱/球坐标(A6)。
        ⑤ 任何换元后**立刻写下雅可比**。
      interpretation: >
        · 换序题的难点全在重画区域，不在计算。
        · 对称性是本族性价比最高的一步，但两条前提必须同时验（B2）。
        · 三重积分选投影还是截面，看被积函数依赖几个变量——只依赖一个就用截面。
    preference_rule: >
      同一格内先取计算量小的：有对称性先用 A3，其次按区域形态选坐标系。
      **这是效率排序，不是合法性判断**——各 action 在其 applies_when 成立时都合法。

  mechanism:
    statement: |
      本族的骨架是两条：
      ① **重积分的计算 = 化为累次积分**，而化累次的关键是「定限」，
         定限的关键是「把区域看清楚」。A1/A4/A5 是三种定限方式。
      ② **换元是为了让区域或被积变简单**，代价是必须带上雅可比（A2/A6）。
    why_action_follows: |
      一级路由把「换序」与「求值」分开，是因为二者的工作量分布完全不同：
      换序题几乎全部工作在重画区域（A7），求值题的工作在选坐标系与定限。
      把换序当成「调换上下限」正是跳过这一区分的后果（B1）。

  failure_boundaries:
    - boundary_id: B1
      changed_condition: 交换积分次序时直接调换上下限，不重画区域
      effect: invalidates
      explanation: >
        原累次积分的内层限含外层变量，调换位置后这些限的含义完全变了，
        得到的是**另一个区域**上的积分。
      witness:
        kind: constructed_counterexample
        ref: |
          I = ∫₀¹ dx ∫ₓ¹ f(x,y) dy，区域 D = {0≤x≤1, x≤y≤1}（对角线上方三角）。
          · 正确换序：D 也可写成 {0≤y≤1, 0≤x≤y} ⇒ I = ∫₀¹ dy ∫₀^y f dx。
          · 错误做法：把限「调个位置」写成 ∫₀¹ dy ∫_y¹ f dx ——
            这是区域 {0≤y≤1, y≤x≤1}，即对角线**下方**三角，是另一个区域。

          取 f = x 可见差别：
            真值（上方三角）= 1/6 ≈ 0.16667（数值 1200² 网格：0.16688）
            错误（下方三角）= 1/3 ≈ 0.33333（数值：0.33312）
          相差一倍。

          ⚠️ **注意 f = xy 时两者都等于 1/8**（数值 0.12514 与 0.12486）——
          被积函数关于 x↔y 对称会**掩盖**这个错误。
          用对称被积去自检换序是检不出问题的。
        verification: verified
      recovery: 回到 A7 第一步，由原限反推区域并画出来

    - boundary_id: B2
      changed_condition: 只验被积函数的奇偶性（或只验区域的对称性）就用对称性化简
      effect: invalidates
      explanation: 对称性归零依赖「区域在该变换下不变」与「被积在该变换下变号」两条的合成，缺一不可。
      witness:
        kind: constructed_counterexample
        ref: |
          被积 f = x（关于 x 为奇函数），两个区域：
          · D₁ = {x²+y² ≤ 1}（关于 x=0 对称）：∬ x dA = **0**
            （数值 1500² 网格：−2.37e−17）✔
          · D₂ = {x²+y² ≤ 1, x+y ≥ 0}（**不**关于 x=0 对称）：
            ∬ x dA = **0.4714 ≠ 0**（数值）。
          被积函数完全相同、奇性完全相同，仅区域对称性不同，结论就相反。
        verification: verified
      recovery: 两条分别核对；区域不对称时先分块使每块具备对称性，或直接实算

    - boundary_id: B3
      changed_condition: 极坐标（或柱、球坐标）换元时漏掉雅可比因子
      effect: invalidates
      explanation: 换元公式要求乘上坐标变换的雅可比行列式；漏掉即算的是另一个量。
      witness:
        kind: constructed_counterexample
        ref: |
          ∬_{x²+y²≤1} 1 dA，真值 = 单位圆面积 = **π ≈ 3.14159**。
          · 带雅可比：∫₀^{2π}∫₀¹ 1·r dr dθ = 2π·(1/2) = π
            （数值 2000² 网格：3.14159）✔
          · 漏掉 r：∫₀^{2π}∫₀¹ 1 dr dθ = 2π ≈ **6.28319**（数值：6.28319）——**错一倍**。
        verification: verified
      recovery: 换元的同一步里立刻写下 dA 或 dV 的完整表达式

    - boundary_id: B4
      changed_condition: 累次积分的外层限写成含变量的形式
      effect: invalidates
      explanation: 外层积分完成后结果应是一个数；限含变量说明内外层次序选反或区域需分块。
      witness:
        kind: proof
        ref: |
          若写 ∫ₓ¹ dy ∫₀¹ dx，外层对 x 积分而其限含 x，表达式无意义。
          正确形式中外层限只能是常数。
        verification: verified
      recovery: 交换内外层，或把区域分成若干块使每块的外层限为常数

    - boundary_id: B5
      changed_condition: 投影法用于「穿入穿出多于一次」的立体
      effect: invalidates
      explanation: 内层限「进面到出面」的写法预设了每条穿线只进出一次；否则遗漏中间段。
      witness:

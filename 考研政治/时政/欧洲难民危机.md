# 欧洲难民危机（时政 · 国际关系与中国外交）

## 定位
- 一级知识点：当代世界经济与政治 / 时政
- 二级知识点：国际关系与中国外交（地区热点问题）
- 三级知识点：导致欧洲难民数量急剧增长的根本原因在于中东地区战乱、冲突和动荡加剧（叙利亚内战等地区冲突是难民潮的源头性、根本性原因），不是"伊斯兰国"驱逐当地民众（这是中东动荡的具体表现之一，是根本原因之下的直接诱因，不是根本原因本身）、不是发达国家接收能力不足（这是难民危机的应对/后果层面问题，不是难民产生的根本原因）、也不是欧盟内部政策协调不足（这也是应对层面的问题，不是难民数量增长的根本原因）
- 教材对应章节（据通行考纲，供参考）：当代世界经济与政治 "国际关系与中国外交"专题——中东地区热点问题与欧洲难民危机

### [[2016#16\|2016-16]]（单选 · 1分，材料："伊斯兰国"（ISIS）崛起与中东局势动荡）
- **三级知识点**：导致欧洲难民数量急剧增长的根本原因是中东地区战乱、冲突和动荡加剧（B）
- **能力要求**：理解辨析+时政结合
- **易错点**：因果倒置/理论对象混淆。选项 A"极端组织'伊斯兰国'疯狂驱逐当地民众"是中东地区动荡这一根本原因之下的具体表现和直接诱因之一，不能与"中东地区战乱冲突动荡"这一更根本、更全面的原因等同或替代；C"美国等发达国家无力接收大量难民"、D"欧盟在难民问题上没有形成共同应对策略"都是难民危机爆发后、国际社会应对层面暴露出的问题，属于难民危机的"后果/应对不力"，不是导致难民"产生""数量增长"的根本原因，考生容易把"源头性原因"和"应对层面的问题/直接诱因"混为一谈。
- **命题意图**：测试对"根本原因"这一限定词的精确把握，区分"中东地区动荡"这一源头性根本原因与"极端组织驱逐""国际应对不力"等具体表现或后果层面问题，防止因果关系倒置或层级混淆。

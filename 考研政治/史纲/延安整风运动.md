# 延安整风运动（史纲 · 中国革命的新道路 / 党的建设）

## 定位
- 一级知识点：中国近现代史纲要
- 二级知识点：中国革命的新道路（抗日战争时期党的建设）
- 三级知识点：延安整风运动反对主观主义、宗派主义、党八股（形式主义文风）三大任务中，"主观主义"的具体表现形式是教条主义和经验主义；20世纪40年代前期整风运动最主要的任务是反对主观主义以整顿学风（三大任务中，反对主观主义以整顿学风是最主要、最核心的任务，因为主观主义脱离实际、脱离群众，是危害党的事业最深的思想根源），不是"反对享乐主义以整顿作风"（享乐主义不是延安整风运动反对的对象，这一表述本身不准确）、不是"反对宗派主义以整顿党风"或"反对党八股以整顿文风"（这两项虽是整风运动的真实任务，但地位次于"反对主观主义整顿学风"这一最主要任务）
- 教材对应章节（据通行考纲，供参考）：史纲 抗日战争时期——延安整风运动

## 逐题标注

### [[2011#28\|2011-28]]（多选 · 2分，官方答案AC）
- **三级知识点**：主观主义的表现形式是教条主义（A）和经验主义（C）
- **能力要求**：概念识记
- **易错点**：理论对象混淆。选项 B"形式主义"对应的是整风运动反对的"党八股"（文风问题），D"宗派主义"是整风运动反对的另一个独立任务（党内关系问题），二者都不属于"主观主义"这一范畴；考生容易把延安整风"反对主观主义、反对宗派主义、反对党八股"三大任务各自对应的具体表现互相调换。
- **命题意图**：测试对延安整风三大任务（主观主义/宗派主义/党八股）及其各自具体表现的精确对应关系，防止表现形式跨任务乱用。
- **关联知识**：[[中国共产党的成立]]（同属党的自身建设发展脉络）

### [[2018#12\|2018-12]]（单选 · 1分）
- **三级知识点**：20世纪40年代前期整风运动最主要的任务是反对主观主义以整顿学风（D）
- **能力要求**：理解辨析
- **易错点**：理论对象混淆（主次混淆）。选项 A"反对享乐主义以整顿作风"这一表述本身不准确——延安整风运动反对的是主观主义、宗派主义、党八股，不包括"享乐主义"；B"反对宗派主义以整顿党风"、C"反对党八股以整顿文风"都是整风运动真实存在的任务，但地位次于"反对主观主义整顿学风"这一最主要任务——主观主义脱离实际、脱离群众，是危害党的事业最深、最需要首先解决的思想根源问题，考生容易把三大任务不分主次地平等对待，忽视题干"最主要"这一限定词。
- **命题意图**：测试对延安整风运动三大任务中何为"最主要"任务（反对主观主义整顿学风）的精确记忆，防止把同样真实存在但地位次要的任务，或表述本身不准确的选项误选为最主要任务。
- **关联知识**：本条目2011-28，同属延安整风运动三大任务从"具体表现形式"到"主次地位排序"的深入考查

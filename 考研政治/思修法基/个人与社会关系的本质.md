# 个人与社会关系的本质（思修法基 · 人生观）

## 定位
- 一级知识点：思想道德与法治
- 二级知识点：人生观（个人与社会的关系）
- 三级知识点：个人与社会的关系最根本的是个人利益与社会利益的关系，因为利益关系是其他一切关系（价值、理想、存在）得以展开的物质基础和现实根源，不是"个人价值与社会价值"（价值关系是利益关系在人生意义/评价层面的展开和体现，不是最根本、最基础的层面）、不是"个人理想与社会理想"（理想关系属于更高层次的精神追求，同样建立在利益关系基础之上）、也不是"个人存在与社会存在"（存在关系描述的是个人与社会何者为本原的一般哲学关系，比"利益关系"更抽象，未点出个人与社会关系展开的具体现实内容）
- 教材对应章节（据通行考纲，供参考）：思修法基 "人生的青春之问"——个人与社会的关系

## 逐题标注

### [[2021#13\|2021-13]]（单选 · 1分，官方答案B）
- **三级知识点**：个人与社会的关系最根本的是个人利益与社会利益的关系（B）
- **能力要求**：理解辨析
- **易错点**：理论对象混淆（层级错位）。选项 A"个人价值与社会价值"、C"个人理想与社会理想"都是个人与社会关系在更高层次（意义评价/精神追求）上的展开，二者都以利益关系为基础和前提，不能代替"最根本"这一层级的表述；D"个人存在与社会存在"停留在更抽象的本体论层面，未能点出个人与社会关系展开为具体现实内容（利益）这一"最根本"的落点，考生容易把个人与社会关系在价值、理想、存在等不同层面的表现，与"利益关系"这一最根本、最基础的层面相混淆。
- **命题意图**：测试对个人与社会关系"最根本"落点（利益关系）的精确把握，防止用价值关系、理想关系或存在关系等派生或更抽象层面的表述代替最根本、最基础的利益关系。
- **关联知识**：[[人生的自我价值与社会价值]]（利益关系基础上进一步展开的价值关系，与本条目构成"基础—展开"的层级关系）

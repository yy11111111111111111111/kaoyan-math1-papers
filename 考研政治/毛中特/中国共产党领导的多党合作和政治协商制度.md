# 中国共产党领导的多党合作和政治协商制度（毛中特 · 政治建设）

## 定位
- 一级知识点：毛泽东思想和中国特色社会主义理论体系概论
- 二级知识点：中国特色社会主义政治建设（政党制度）
- 三级知识点：我国政党制度"共产党领导、多党合作，共产党执政、多党派参政"的特点和优点；民主党派参政议政的具体制度化渠道；新时代做好人民政协工作的中心环节是加强思想政治引领、广泛凝聚共识，不是"提高政治协商民主监督参政议政水平"（这是人民政协履行职能的基本方面，不是"中心环节"这一更具统领性的表述）、不是"发挥好人民政协专门协商机构作用"（这是对政协性质定位的表述，不是"中心环节"本身）、也不是"强化政协委员责任担当"（这是做好政协工作的重要保障条件，同样不是中心环节）；1949年人民政协的召开标志着新型政党制度的建立，不是"民族区域自治制度的建立"（这是解决民族问题的制度安排，与政党制度不是同一范畴）、不是"工商代表大会制度的建立"（这一表述本身不是对人民政协历史地位的规范概括）、也不是"人民代表大会制度的建立"（人民代表大会制度是1954年第一届全国人大召开才正式建立的根本政治制度，晚于1949年人民政协的召开，二者是不同时间节点、不同性质的两项制度，不可混淆）
- 教材对应章节（据通行考纲，供参考）：毛中特 中国特色社会主义政治建设——中国特色社会主义政党制度

## 逐题标注

### [[2011#35\|2011-35(1)]]（分析题(1)小问）
- **三级知识点**：中国政党制度"共产党领导、多党合作；共产党执政、多党派参政"的特点，及"避免政党恶斗、保持政治稳定、凝聚各方力量"的优点
- **能力要求**：理解辨析（把"打橄榄球/唱大合唱"的比喻转译成规范表述）+ 综合分析
- **易错点**：条件遗漏。题干要求同时说明"特点"和"优点"两个方面，考生容易只答其中一方面（例如只描述"是什么"而不展开"好处是什么"），导致答案不完整。
- **命题意图**：测试能否把生动的比喻材料准确转译为教材规范表述，并区分"特点（是什么）"与"优点（为什么好）"两层要求。
- **关联知识**：[[毛泽东思想与中国特色社会主义理论体系的一脉相承性]]（同属"中国特色制度自信"命题倾向）

### [[2011#35\|2011-35(2)]]（分析题(2)小问）
- **三级知识点**：民主党派参政议政的具体渠道——参加国家政权、参与大政方针协商、参与法规制定执行、开展调查研究、民主监督
- **能力要求**：概念识记（具体渠道）+ 综合分析
- **易错点**：以偏概全。考生容易把"参政议政"泛化为笼统的"民主党派发挥作用"，而遗漏教材列举的具体制度化渠道（参加国家政权、协商大政方针、民主监督等），导致答案空泛、缺少具体制度支撑点。
- **命题意图**：测试对民主党派参政议政具体制度化渠道的记忆，防止用空泛表态代替具体制度内容。
- **关联知识**：[[民族关系与民族团结]]（同属政治建设模块下的具体制度）

### [[2020#7\|2020-7]]（单选 · 1分，官方答案B）
- **三级知识点**：新时代做好人民政协工作的中心环节是加强思想政治引领、广泛凝聚共识（B）
- **能力要求**：概念识记
- **易错点**：理论对象混淆（层级错位）。选项 A"提高政治协商、民主监督、参政议政水平"是人民政协履行职能的基本方面，C"发挥好人民政协专门协商机构作用"是对政协性质定位的表述，D"强化政协委员责任担当"是做好政协工作的重要保障条件，三者都从属于、服务于"加强思想政治引领、广泛凝聚共识"这一更核心的中心环节，考生容易把政协的职能方面、性质定位或保障条件误当作中心环节本身。
- **命题意图**：测试对新时代人民政协工作中心环节确切表述（思想政治引领、凝聚共识）与其职能方面、性质定位、保障条件之间层级关系的精确把握，防止用相关方面代替中心环节本身。
- **关联知识**：本条目2011-35(1)(2)，同属人民政协/政党制度模块在"制度特点优点""参政议政渠道""新时代工作中心环节"三个不同角度下的递进考查

### [[2021#11\|2021-11]]（单选 · 1分，官方答案D）
- **三级知识点**：人民政协的召开标志着新型政党制度的建立（D）
- **能力要求**：概念识记
- **易错点**：理论对象混淆/时间混淆。选项 A"民族区域自治制度的建立"是解决民族问题的制度安排，与政党制度不是同一范畴；C"人民代表大会制度的建立"是1954年第一届全国人民代表大会召开才正式确立的根本政治制度，晚于1949年人民政协召开这一时间节点，考生容易把这一更晚确立的制度提前套用到1949年人民政协身上；B"工商代表大会制度的建立"本身不是对人民政协历史地位的规范概括，属于臆造的近似表述。
- **命题意图**：测试对1949年人民政协召开确切历史标志意义（新型政党制度的建立）的精确记忆，防止把时间上更晚确立的其他政治制度（人民代表大会制度）或范畴不同的其他制度（民族区域自治制度）提前或错位套用到人民政协身上。
- **关联知识**：本条目2011-35(1)(2)、2020-7，同属人民政协/政党制度模块在"制度特点优点""参政议政渠道""新时代工作中心环节""历史标志意义"四个不同角度下的递进考查
